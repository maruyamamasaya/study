## システム監査の点検・評価

システム監査では、情報システムに関する主に次の観点を**点検・評価**する。

```text id="9fw97v"
① ガバナンス（Governance）
② マネジメント（Management）
③ コントロール（Control）
```

簡単にいうと、

| 項目     | 意味           | 一言             |
| ------ | ------------ | -------------- |
| ガバナンス  | 組織全体の方向付け・監督 | **方向を決める**     |
| マネジメント | 目標達成のための管理   | **計画して実行する**   |
| コントロール | リスクを抑えるための統制 | **ルール・仕組みで守る** |

---

# 1. ガバナンス

**組織として、情報システムをどの方向に進めるかを決定・監督すること。**

経営者などの視点が強い。

例えば、

```text id="y4r4go"
経営戦略
「クラウドを積極的に活用する」
        ↓
IT戦略
「3年間で基幹システムを
クラウドへ移行する」
```

など。

### 主なポイント

* 経営戦略とIT戦略の整合
* 方針・方向性の決定
* 責任体制
* IT投資の評価
* リスクの監督

> **ガバナンス = 経営・組織として方向を決め、監督する**

---

# 2. マネジメント

決められた方針・目標を達成するために、**具体的に計画・実行・管理すること**。

例えば、

```text id="89f5r2"
目標
「クラウドへ移行する」
        ↓
マネジメント

・移行計画を作成
・予算を管理
・人員を配置
・進捗を管理
・リスクを管理
```

> **マネジメント = 目標達成のために計画して実行・管理する**

---

# 3. コントロール

リスクを適切な範囲に抑え、業務を正しく行うための**具体的な統制・仕組み**。

例えば、

```text id="fahv3s"
不正アクセスのリスク
        ↓
コントロール

・アクセス権限
・パスワード
・多要素認証
・ログ監視
```

ほかにも、

```text id="4ljbgn"
誤操作防止
→ ダブルチェック

データ消失対策
→ バックアップ

不正処理防止
→ 職務分掌
```

などがコントロールに該当する。

> **コントロール = リスクを抑える具体的な仕組み**

---

# 3つの関係

例えば「情報セキュリティを強化する」という場合、

```text id="2qf1nq"
【ガバナンス】

経営者
「セキュリティを重要な
経営課題として強化する」

        ↓

【マネジメント】

管理者
「セキュリティ計画を作成して
予算・人員を配置する」

        ↓

【コントロール】

現場・システム
「MFAを導入」
「アクセス権を管理」
「ログを監視」
```

つまり、

```text id="l3sj35"
ガバナンス
「どこへ向かう？」

      ↓

マネジメント
「どう進める？」

      ↓

コントロール
「どう守る？」
```

というイメージ。

---

# システム監査では

監査人は、

```text id="at6hyx"
ガバナンス
マネジメント
コントロール
      ↓
点検
「実際どうなっている？」
      ↓
評価
「適切・有効に機能している？」
      ↓
問題があれば改善を促す
```

という観点で確認する。

---

# 具体例：アクセス管理の監査

## ガバナンス

```text id="s7ypdq"
情報セキュリティ方針が
経営方針と整合しているか？
```

## マネジメント

```text id="xj69yv"
アクセス管理の責任者・手順・
運用体制が適切か？
```

## コントロール

```text id="rs4a7g"
・退職者IDが削除されているか
・権限が適切か
・定期的に棚卸ししているか
```

そして監査人が、

```text id="66mt1p"
点検
→ 証拠・実態を確認

評価
→ 適切か判断
```

する。

---

# 試験用まとめ

| 用語         | 覚え方         |
| ---------- | ----------- |
| **ガバナンス**  | 方針・方向を決めて監督 |
| **マネジメント** | 計画・実行・管理    |
| **コントロール** | リスクを抑える統制   |
| **点検**     | 実態・事実を確認    |
| **評価**     | 適切か判断       |

## 超短縮版

```text id="6xgxgq"
ガバナンス
→ 方向を決める

マネジメント
→ 計画して動かす

コントロール
→ 仕組みで守る

        ↓

システム監査

点検
→ 実際どうなっている？

評価
→ 適切に機能している？
```

**「ガバナンス → マネジメント → コントロール」を監査人が独立した立場から点検・評価する**と覚えると整理しやすい。
