## 全体比較

| 契約  | お金の考え方       | 指揮命令     | 完成責任   | 著作権          |
| --- | ------------ | -------- | ------ | ------------ |
| 派遣  | 時間・人月など      | **派遣先**  | 基本なし   | 職務著作等のルールによる |
| 請負  | 成果物に対して○万円など | **受注者側** | **あり** | 原則は創作者側※     |
| 準委任 | 時間・人月・期間など   | **受任者側** | 基本なし   | 原則は創作者側※     |

※契約によって著作権を発注者へ譲渡することがある。

---

# 1. 派遣

**人・労働力を提供するイメージ。**

```text
派遣元
  ↓ 雇用
派遣社員
  ↑
  │ 指揮命令
派遣先
```

## 費用イメージ

例えば、

```text
エンジニア1名
月額 80万円

3か月
↓
約240万円
```

など、稼働時間・期間などを基準に料金が設定される。

### ポイント

> **派遣先が作業者へ直接指揮命令できる**

---

# 2. 請負

**成果物を完成させることに対してお金を支払う。**

例えば、

```text
「このシステムを500万円で作ってください」
```

という契約。

```text
発注者
  ↓ 500万円
受注者
  ↓
システム完成
```

## ポイント

* 仕事の**完成責任がある**
* 発注者から作業者への直接の指揮命令はしない
* 成果物単位などで金額を決めやすい

> **請負 = 完成させて○万円**

---

# 3. 準委任

**業務を適切に遂行することに対してお金を支払う。**

例えば、

```text
システム開発支援
月額80万円 × 3か月
```

など。

```text
発注者
  ↓
「3か月間、開発を支援してください」
  ↓
受任者
```

請負との大きな違いは、原則として**成果物を完成させること自体が目的ではない**こと。

```text
請負
→ 「システムを完成させて」

準委任
→ 「開発業務をお願いします」
```

> **準委任 = 業務を遂行して○万円**

---

# 準委任でも成果物はある？

**ある。**

ここは重要。

準委任だから、

```text
成果物がない
```

とは限らない。

例えば開発支援なら、

* ソースコード
* 設計書
* 調査資料
* テスト結果

などを作成することがある。

ただし、

> **成果物が存在すること**
>
> と
>
> **成果物の完成を契約上約束していること**

は別。

```text
準委任
→ 成果物が発生することはある
→ しかし基本は「業務の遂行」が目的

請負
→ 「仕事の完成」が目的
```

---

# 準委任と著作権

準委任でプログラムや設計書などの**著作物**を作成した場合、著作権が発生する可能性がある。

重要なのは、

> **準委任だから自動的に発注者へ著作権が移るわけではない**

ということ。

例えば、

```text
A社
 ↓ 準委任
B社
 ↓
プログラム作成
```

B社側で著作物が作られた場合、

```text
お金を払ったA社
↓
自動的に著作権取得

ではない
```

原則的な帰属を確認した上で、発注者へ著作権を移したい場合は**契約で著作権譲渡について定める**ことが重要。

---

# 請負でも同じ

請負についても、

```text
500万円払って
システムを作ってもらった

↓

著作権も自動的に発注者へ

とは限らない
```

請負契約と著作権の帰属は別問題。

そのため契約書で、

```text
成果物の著作権を
受注者から発注者へ譲渡する
```

などと定めることがある。

---

# 試験用まとめ

```text
派遣
→ 人・労働力
→ 時間・期間などで料金
→ 派遣先が指揮命令

請負
→ 成果物・仕事の完成
→ 「完成させて○万円」
→ 完成責任あり

準委任
→ 業務の遂行
→ 「月○万円で支援」
→ 完成責任は基本なし
→ 成果物が発生することはある
```

## 著作権

```text
請負だから発注者
準委任だから発注者

というわけではない。

↓

原則として著作者に発生
（職務著作の場合などは法人が著作者となり得る）

↓

発注者へ移す場合
→ 著作権譲渡などを契約で定める
```

# 超短縮版

|         | お金       | 責任・特徴            |
| ------- | -------- | ---------------- |
| **派遣**  | 働いた時間・期間 | 派遣先が指示           |
| **請負**  | 完成した仕事   | 完成責任あり           |
| **準委任** | 業務・工数・期間 | 業務遂行、完成責任は基本なし   |
| **著作権** | ―        | 契約形態だけでは帰属は決まらない |

**派遣＝人
請負＝完成
準委任＝業務
著作権＝契約内容も確認**

と覚えると分かりやすい。
