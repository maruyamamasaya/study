## 1. 桁落ち

**ほぼ同じ大きさの数同士を引き算したとき、有効数字が大きく失われる現象。**

### 例

```text
1.234567
-1.234566
---------
0.000001
```

元の値には多くの有効数字があっても、差を取ることで有効数字が少なくなる。

### 覚え方

> **桁落ち = 近い値どうしの引き算で桁が消える**

---

# 2. 情報落ち

**非常に大きな数と非常に小さな数を足したとき、小さい方の値が計算結果に反映されなくなる現象。**

### 例

```text
100000000
+       0.1
-----------
100000000
```

コンピュータで扱える有効桁数に限界があるため、小さい値が無視されることがある。

### 覚え方

> **情報落ち = 大きい数 + 小さい数で、小さい方が消える**

---

# 3. 丸め誤差

**有限の桁数で数値を表すために、四捨五入や切捨てなどを行うことで発生する誤差。**

### 例

```text
1 ÷ 3
= 0.333333...

↓ 4桁で表現

0.3333
```

本来の値との差が丸め誤差。

### 例：2進数

10進数の `0.1` などは、2進数では有限桁で正確に表せない。

そのためコンピュータ内部では近似値として保持される。

> **丸め誤差 = 表現できる桁数に丸めることで発生**

---

# 4. 打切り誤差

**本来は無限回続ける計算を、途中で打ち切ることで発生する誤差。**

### 例

円周率を、

```text
π = 3.1415926535...
```

と無限に続く値として扱えないため、

```text
π ≒ 3.14
```

など途中で計算を打ち切る。

また、無限級数を有限回で終了する場合などにも発生する。

```text
1 + 1/2 + 1/4 + 1/8 + ...
```

本来は無限に続くが、

```text
1 + 1/2 + 1/4
```

で計算を終了すると、その分の誤差が生じる。

> **打切り誤差 = 計算を途中でやめることで発生**

---

# 4つの違い

| 誤差    | 発生する場面       | 覚え方      |
| ----- | ------------ | -------- |
| 桁落ち   | 近い値同士の引き算    | 桁が消える    |
| 情報落ち  | 大きい数と小さい数の加算 | 小さい値が消える |
| 丸め誤差  | 有限桁で表現する     | 数値を丸める   |
| 打切り誤差 | 無限計算を途中で終了   | 計算を打ち切る  |

---

# 試験での見分け方

```text
ほぼ等しい2数の差
→ 桁落ち

非常に大きな数 + 非常に小さな数
→ 情報落ち

有限桁数に四捨五入・切捨て
→ 丸め誤差

無限級数・反復計算を途中で終了
→ 打切り誤差
```

---

# 一言で覚える

```text
桁落ち
→ 引き算で桁が消える

情報落ち
→ 小さい数が消える

丸め誤差
→ 桁数制限で丸める

打切り誤差
→ 計算を途中でやめる
```

## 特に重要な対比

```text
桁落ち
→ 「近い数 − 近い数」

情報落ち
→ 「大きい数 + 小さい数」
```

この2つは特に混同しやすいので、セットで覚えるとよい。
