## EVMとは

**EVM（Earned Value Management：アーンドバリューマネジメント）**は、

> プロジェクトの「予定」「実績」「実際にかかったコスト」を比較して、進捗やコスト状況を管理する方法。

基本となる3つの値が、

- **PV：予定ではどこまで進んでいるはずか**
- **EV：実際にはどこまで進んだか**
- **AC：実際にいくら使ったか**

である。

---

# 1. PV（Planned Value：計画価値）

## 意味

**現時点までに完了する予定だった作業の予算額。**

簡単に言うと、

> 「予定では、今までに何円分の仕事が終わっているはず？」

### 例

プロジェクト全体の予算が100万円。

現時点で予定では60%完了しているはずなら、

    PV = 100万円 × 60%
       = 60万円

つまり、

**PV = 60万円**

---

# 2. EV（Earned Value：出来高）

## 意味

**実際に完了した作業を、予算額に換算したもの。**

簡単に言うと、

> 「実際には何円分の仕事が終わった？」

### 例

全体予算100万円のプロジェクトで、
実際には50%の作業が完了している。

    EV = 100万円 × 50%
       = 50万円

つまり、

**EV = 50万円**

重要なのは、

**EVは実際に支払った金額ではない。**

あくまで、

**「完了した仕事を予算ベースで金額にしたもの」**

である。

---

# 3. AC（Actual Cost：実コスト）

## 意味

**実際に発生したコスト。**

簡単に言えば、

> 「実際にいくら使った？」

### 例

50万円分の仕事を完了するために、
実際には55万円かかった。

    AC = 55万円

---

# PV・EV・ACを並べる

例えば、

    PV = 60万円
    EV = 50万円
    AC = 55万円

だったとする。

意味は、

    予定
    60万円分まで終わる予定
           ↓
    実際
    50万円分しか終わっていない
           ↓
    しかも
    55万円使っている

という状態。

つまり、

**予定より遅れていて、さらにコストも余計にかかっている。**

---

# 4. スケジュール差異（SV）

SV（Schedule Variance）は、

**予定と実際の進捗の差**

を表す。

## 計算式

    SV = EV - PV

### 例

    EV = 50万円
    PV = 60万円

    SV = 50 - 60
       = -10万円

マイナスなので、

**予定より遅れている。**

## 判定

| SV | 状況 |
|---:|---|
| プラス | 予定より進んでいる |
| 0 | 予定どおり |
| マイナス | 予定より遅れている |

### 覚え方

    実際の進捗 - 予定の進捗

    EV - PV

---

# 5. コスト差異（CV）

CV（Cost Variance）は、

**出来高と実際にかかったコストの差**

を表す。

## 計算式

    CV = EV - AC

### 例

    EV = 50万円
    AC = 55万円

    CV = 50 - 55
       = -5万円

つまり、

**50万円分の仕事をするのに55万円使っている。**

→ 予算超過。

## 判定

| CV | 状況 |
|---:|---|
| プラス | 予算より安く済んでいる |
| 0 | 予算どおり |
| マイナス | 予算超過 |

### 覚え方

    仕事の価値 - 実際に払った金額

    EV - AC

---

# 6. スケジュール効率指数（SPI）

SPI（Schedule Performance Index）は、

**予定に対して、どのくらいのペースで進んでいるか**

を表す。

## 計算式

    SPI = EV ÷ PV

### 例

    EV = 50万円
    PV = 60万円

    SPI = 50 ÷ 60
        ≒ 0.83

予定の約83%のペースでしか進んでいない。

## 判定

| SPI | 状況 |
|---:|---|
| 1より大きい | 予定より進んでいる |
| 1 | 予定どおり |
| 1より小さい | 予定より遅れている |

---

# 7. コスト効率指数（CPI）

CPI（Cost Performance Index）は、

**使ったお金に対して、どのくらいの仕事ができたか**

を表す。

## 計算式

    CPI = EV ÷ AC

### 例

    EV = 50万円
    AC = 55万円

    CPI = 50 ÷ 55
        ≒ 0.91

1円使って、約0.91円分の仕事しかできていないイメージ。

## 判定

| CPI | 状況 |
|---:|---|
| 1より大きい | コスト効率が良い |
| 1 | 予算どおり |
| 1より小さい | コスト効率が悪い・予算超過 |

---

# 8. BAC（Budget at Completion）

BACは、

**プロジェクト完成時点での当初の総予算**

を表す。

例えば、

    プロジェクト全体の予算 = 100万円

なら、

    BAC = 100万円

---

# 9. EAC（Estimate at Completion）

EACは、

**現在の状況から予測した、完成時の総コスト見積り**

を表す。

つまり、

> 「この調子で最後までやったら、結局全部でいくらかかる？」

という値。

---

# EACの代表的な計算

## 現在のコスト効率が今後も続く場合

試験では、この考え方が重要。

    EAC = BAC ÷ CPI

CPIは、

    CPI = EV ÷ AC

なので、

    EAC = BAC ÷ (EV ÷ AC)

となる。

整理すると、

    EAC = BAC × AC ÷ EV

---

## 例

プロジェクト全体の予算が、

    BAC = 100万円

現在、

    EV = 50万円
    AC = 55万円

だった。

まずCPIを求める。

    CPI = EV ÷ AC

        = 50 ÷ 55

        ≒ 0.91

このコスト効率が最後まで続くと考えると、

    EAC = BAC ÷ CPI

        = 100 ÷ 0.91

        ≒ 110万円

したがって、

**完成時の総コスト見積りは約110万円。**

当初予算100万円だったが、

**最終的には約110万円かかりそう**

と予測できる。

---

# EACのもう一つの考え方

問題によっては、

> 「今までのコスト超過は一時的なもので、残りの作業は当初予算どおり進む」

という条件が出ることがある。

この場合は、

    EAC = AC + (BAC - EV)

となる。

意味を分解すると、

    AC
    = 今まで実際に使った金額

    BAC - EV
    = 残っている仕事の予算

なので、

    完成時総コスト
    =
    今まで使った金額
    +
    残りの仕事に必要な予算

となる。

---

# EACは問題文の条件を見る

## 「現在のコスト効率が今後も続く」

    EAC = BAC ÷ CPI

または、

    EAC = BAC × AC ÷ EV

---

## 「残りの作業は当初の予算どおり」

    EAC = AC + (BAC - EV)

---

# ETC（Estimate to Complete）

ETCは、

**これから完成までに必要になるコスト**

を表す。

    ETC = EAC - AC

例えば、

    EAC = 110万円
    AC  = 55万円

なら、

    ETC = 110 - 55
        = 55万円

あと55万円必要になると予測する。

---

# 全体の関係

    ┌─────────────────────┐
    │ BAC：完成までの当初総予算 │
    └─────────────────────┘

             現在

    PV = 予定では何円分終わる？
    EV = 実際には何円分終わった？
    AC = 実際に何円使った？

             ↓

    SV = EV - PV
    → スケジュールの遅れ・進み

    CV = EV - AC
    → コスト超過・節約

             ↓

    SPI = EV / PV
    → スケジュール効率

    CPI = EV / AC
    → コスト効率

             ↓

    EAC = 完成時の総コスト予測

    ETC = あといくら必要か

---

# 試験向け公式まとめ

| 指標 | 計算式 | 意味 |
|---|---|---|
| **PV** | 計画進捗 × 予算 | 予定ではどこまで？ |
| **EV** | 実際の進捗 × 予算 | 実際どこまで終わった？ |
| **AC** | 実際の支出 | 実際いくら使った？ |
| **SV** | EV - PV | スケジュール差異 |
| **CV** | EV - AC | コスト差異 |
| **SPI** | EV / PV | スケジュール効率 |
| **CPI** | EV / AC | コスト効率 |
| **BAC** | ― | 当初の完成時総予算 |
| **EAC** | BAC / CPI | 完成時総コスト予測 |
| **ETC** | EAC - AC | 今後必要なコスト |

---

# 最低限の覚え方

## 3つの基本

    PV = Plan
       = 予定

    EV = Earned
       = 実際にできた仕事

    AC = Actual Cost
       = 実際に使った金額

---

## 差を見るなら「引き算」

    EV - PV
    = スケジュール差異

    EV - AC
    = コスト差異

**マイナスなら基本的に悪い状態。**

---

## 効率を見るなら「割り算」

    EV / PV
    = スケジュール効率

    EV / AC
    = コスト効率

**1未満なら基本的に悪い状態。**

---

## 完成時にいくらかかる？

現在のコスト効率が続くなら、

    EAC = BAC / CPI

**「このままの金遣いで最後まで行ったら、結局いくら？」**

と考えると分かりやすい。
