# システム監査人による監査手法

## システム監査とは

システム監査では、監査人が情報システムについて、

- 適切に管理されているか
- ルールどおり運用されているか
- セキュリティ対策が機能しているか

などを確認・評価する。

重要なのは、担当者の説明だけを信じるのではなく、  
**監査証拠を収集して客観的に判断すること。**

---

# 主な監査手法

| 監査手法 | 何をする？ | 例 |
|---|---|---|
| **インタビュー（質問）** | 担当者に質問する | 「障害発生時はどう対応しますか？」 |
| **文書・記録の閲覧** | 資料やログなどを確認する | 操作ログ、申請書、設計書を確認 |
| **観察** | 実際の作業を見る | バックアップ作業を実際に見る |
| **再実施** | 監査人自身が同じ処理を行う | 計算や処理を再度実行して結果を確認 |
| **突合・照合** | 複数の資料を比較する | 申請書とアクセス権一覧を比較 |
| **現物確認** | 実際の設備・資産を見る | サーバや端末が実在するか確認 |
| **サンプリング** | 一部を抽出して確認する | 1万件の記録から100件を抽出して確認 |

---

# 1. インタビュー（質問）

担当者や責任者に質問して、業務やシステムの運用状況を確認する。

### 例

> 「障害が発生した場合、誰に連絡しますか？」

> 「退職者のアカウントはどのように削除していますか？」

ただし、

**「担当者がそう言っていた」だけでは証拠として弱い場合がある。**

そのため、文書やログなどと組み合わせて確認することが重要。

---

# 2. 文書・記録の閲覧

実際に存在する資料や記録を確認する。

### 例えば

- システムログ
- アクセスログ
- 設計書
- 運用マニュアル
- 作業記録
- 申請書
- 承認記録
- 障害報告書

などを確認する。

### 例

「アクセス権の変更には上司の承認が必要」

というルールがある場合、

実際の**アクセス権変更申請書・承認記録**を確認する。

---

# 3. 観察

担当者が行っている作業を、**監査人が実際に見て確認する**。

### 例

バックアップ作業について、

    担当者
      ↓
    バックアップ実施
      ↓
    監査人が横で確認

実際に手順どおり作業しているか確認する。

### ポイント

> 「実際の作業状況を監査人がその場で確認する」

→ **観察**

---

# 4. 再実施

担当者が実施した処理などを、**監査人自身がもう一度実施して結果を確認する**。

### 例

システムによって、

    100件 → 合計500万円

という計算結果が出ている。

監査人が同じデータを使って再計算し、

    監査人の計算
        ↓
    合計500万円

となることを確認する。

### ポイント

> 「監査人自身が同じ手続・処理を実施する」

→ **再実施**

---

# 5. 突合・照合

異なる資料やデータを比較して、内容が一致しているか確認する。

### 例

    アカウント一覧
          ↕ 照合
    従業員一覧

退職した従業員のアカウントが残っていないか確認する。

ほかにも、

    アクセス権変更申請書
          ↕
    実際のアクセス権設定

などを比較する。

---

# 6. 現物確認

帳簿や管理表だけではなく、**実際の設備や資産が存在するか確認する**。

### 例

資産管理台帳に、

    サーバA
    サーバB
    PC-001
    PC-002

と書かれている。

監査人が実際の機器を確認して、

**本当に存在するか、管理番号が一致するか**

などを確認する。

---

# 7. サンプリング

すべてのデータを確認するのが難しい場合に、  
**一部を抽出して監査する方法。**

### 例

アクセス権変更記録が、

    10,000件

存在する場合、

その中から、

    100件を抽出
        ↓
    申請・承認が正しいか確認

といった方法を取る。

---

# 監査で重要な「監査証拠」

システム監査人は、監査結果を自分の感覚だけで判断するのではなく、

**監査証拠**

に基づいて判断する。

監査証拠には、

- ログ
- 設計書
- 申請書
- 承認記録
- インタビュー結果
- 実際のシステム設定
- 操作結果

などがある。

---

# 監査証拠で重要なポイント

監査証拠は、

**十分かつ適切な監査証拠**

を入手することが重要。

### 十分性

> 証拠の「量」は足りているか？

1件だけではなく、必要な量の証拠を集める。

### 適切性

> 証拠の「質・信頼性」は高いか？

担当者の口頭説明だけではなく、

- システムログ
- 承認記録
- 実際の設定

など、より客観的な証拠も確認する。

---

# 試験での見分け方

| 問題文 | 監査手法 |
|---|---|
| 担当者に質問した | **インタビュー・質問** |
| ログや申請書を確認した | **閲覧** |
| 作業しているところを見た | **観察** |
| 監査人自身が処理を行った | **再実施** |
| 二つの資料を比較した | **突合・照合** |
| 実際の機器を確認した | **現物確認** |
| 全体から一部を抽出した | **サンプリング** |

---

# 最低限これだけ覚える

**質問**
→ 人に聞く

**閲覧**
→ 資料・ログを見る

**観察**
→ 作業しているところを見る

**再実施**
→ 監査人が自分でやってみる

**突合・照合**
→ 二つの情報を比較する

**現物確認**
→ 実物を見る

**サンプリング**
→ 一部を抽出して調べる

---

## 特に「観察」と「再実施」の違い

    担当者が作業
        ↓
    監査人が見る

    → 観察


    監査人自身が作業
        ↓
    結果を確認

    → 再実施

**「見るだけ」なら観察、  
「監査人が自分でやる」なら再実施**

と覚えると分かりやすい。
