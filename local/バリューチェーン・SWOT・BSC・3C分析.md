## 全体の違い

| 手法         | 何を見る？     | 一言                |
| ---------- | --------- | ----------------- |
| バリューチェーン   | 企業内部の活動   | **どこで価値を生んでいる？**  |
| SWOT分析     | 内部＋外部環境   | **強み・弱み・機会・脅威は？** |
| 3C分析       | 市場・競合・自社  | **顧客・ライバル・自社は？**  |
| バランススコアカード | 経営戦略・業績評価 | **戦略を4つの視点で管理**   |

---

# 1. バリューチェーン

**Value Chain（価値連鎖）**

企業の活動を、

> **「どの活動で顧客への価値が生み出されているか？」**

という視点で分析する手法。

企業活動を大きく、

* 主活動
* 支援活動

に分ける。

---

## 主活動

製品・サービスを顧客へ届けるまでに直接関係する活動。

```text id="zhw9na"
購買物流
  ↓
製造
  ↓
出荷物流
  ↓
販売・マーケティング
  ↓
サービス
```

例えばEC企業なら、

```text id="43tfua"
商品を仕入れる
 ↓
商品を管理する
 ↓
配送する
 ↓
販売する
 ↓
アフターサービス
```

---

## 支援活動

主活動を支える活動。

代表的なものは、

```text id="0o0l09"
・全般管理
・人事・労務管理
・技術開発
・調達活動
```

例えば、

```text id="6yb0qt"
人事
 ↓
優秀なエンジニアを採用
 ↓
商品開発力が向上
 ↓
顧客への価値向上
```

という関係。

> **バリューチェーン = 企業活動を分解して「どこで価値が生まれるか」を分析**

---

# 2. SWOT分析

企業の内部環境と外部環境を4つに分けて分析する。

```text id="r5w37a"
S = Strength
    強み

W = Weakness
    弱み

O = Opportunity
    機会

T = Threat
    脅威
```

## 内部・外部が重要

|      | プラス  | マイナス |
| ---- | ---- | ---- |
| 内部環境 | S：強み | W：弱み |
| 外部環境 | O：機会 | T：脅威 |

### 例

スマートフォンメーカーなら、

```text id="vk3fej"
S：強み
→ 高い技術力

W：弱み
→ ブランド認知度が低い

O：機会
→ 市場が拡大している

T：脅威
→ 海外メーカーの参入
```

> **SWOT = 自社の内外の状況を4分類**

---

# 3. 3C分析

企業の事業環境を3つの「C」から分析する。

```text id="v9yj8a"
Customer
→ 顧客・市場

Competitor
→ 競合

Company
→ 自社
```

## Customer

```text id="m5a11h"
市場規模は？
顧客は何を求めている？
市場は成長している？
```

## Competitor

```text id="04idgq"
競合企業は？
競合商品の価格は？
競合の強みは？
```

## Company

```text id="q2l0tb"
自社の強みは？
技術力は？
ブランド力は？
```

> **3C = 顧客・競合・自社を分析**

---

# SWOTと3Cの違い

どちらも経営環境を分析するが、切り口が違う。

### SWOT

```text id="q8zsv4"
内部
├─ 強み
└─ 弱み

外部
├─ 機会
└─ 脅威
```

### 3C

```text id="tbab2l"
市場・顧客
競合
自社
```

つまり、

> **SWOT = プラス・マイナス × 内部・外部**

> **3C = 誰を分析するか**

---

# 4. バランススコアカード（BSC）

**Balanced Scorecard**

企業の戦略を、財務だけではなく**4つの視点から評価・管理する手法**。

## 4つの視点

```text id="l7saxk"
① 財務

② 顧客

③ 内部ビジネスプロセス

④ 学習と成長
```

---

## 財務の視点

```text id="0ppc9a"
売上
利益
ROI
コスト
```

> 株主・経営の観点

---

## 顧客の視点

```text id="9h42bh"
顧客満足度
リピート率
市場シェア
```

> 顧客からどう見られているか

---

## 内部ビジネスプロセスの視点

```text id="9o0gjv"
生産時間
品質
業務効率
納期
```

> 社内業務をどう改善するか

---

## 学習と成長の視点

```text id="m2ojjd"
社員教育
技術力
資格取得
組織能力
```

> 将来に向けてどう成長するか

---

# BSCの関係

例えば、

```text id="05mtu3"
学習と成長
「社員を教育する」
       ↓
内部プロセス
「開発効率が上がる」
       ↓
顧客
「サービス品質が上がる」
       ↓
財務
「売上・利益が増える」
```

のように、戦略目標同士の因果関係を考える。

> **BSC = 戦略を4つの視点から具体化・評価する**

---

# 4つを同じ会社で考える

例えば「ネット通販会社」なら、

## 3C

```text id="8nkvll"
顧客は何を求めている？
競合Amazonはどうしている？
自社の強みは？
```

→ **事業環境を見る**

## SWOT

```text id="0gc07g"
強み：配送が速い
弱み：知名度が低い
機会：EC市場拡大
脅威：競合参入
```

→ **内外環境を整理**

## バリューチェーン

```text id="8ng6ew"
仕入 → 在庫 → 配送 → 販売 → サポート

「配送の速さが強みだ」
```

→ **どの企業活動が価値を生んでいるか分析**

## BSC

```text id="8z3dp2"
財務 → 売上10%増

顧客 → 満足度90%

業務 → 配送時間20%短縮

学習 → 社員教育を強化
```

→ **戦略を目標・指標に落とし込む**

---

# 試験での見分け方

```text id="3j5guh"
「主活動・支援活動」
「価値を生み出す活動」
→ バリューチェーン


「強み・弱み・機会・脅威」
→ SWOT


「顧客・競合・自社」
→ 3C


「財務・顧客・内部プロセス・学習と成長」
→ バランススコアカード
```

# 超短縮版

| 手法           | 覚え方         |
| ------------ | ----------- |
| **バリューチェーン** | どの活動が価値を生む？ |
| **SWOT**     | 強み・弱み・機会・脅威 |
| **3C**       | 顧客・競合・自社    |
| **BSC**      | 財務・顧客・業務・成長 |

特に試験では、

**バリューチェーン →「主活動・支援活動」**

というキーワードが出たらすぐ判断できるようにしておく。
