## 1. レベニューシェア契約

**事業によって得られた売上・収益を、発注者と受注者で分配する契約。**

最初から固定額を支払うのではなく、サービスの成果に応じて受注者の報酬が変わる。

### 例

ECサイトを開発会社に作ってもらい、

```text id="g3bdmc"
ECサイト売上：1,000万円

発注者：80% → 800万円
開発会社：20% → 200万円
```

のように売上を分配する。

売上が増えれば、開発会社の報酬も増える。

### ポイント

* 売上・収益を分配する
* 成果によって報酬が変わる
* 発注者と受注者が事業リスクを分担する

> **レベニューシェア = 売上を分け合う**

---

# 2. サブスクリプション

商品を買い切るのではなく、**一定期間利用する権利に対して料金を支払う方式**。

### 例

```text id="gupjxu"
業務システム

月額：5,000円
      ↓
毎月料金を支払って利用
```

SaaSや動画・音楽サービスなどでよく利用される。

### ポイント

* 月額・年額などで継続的に料金を支払う
* 所有ではなく「利用する権利」に対して支払う
* SaaSなどで多く利用される

> **サブスクリプション = 定期料金で利用する**

---

# 3. 実費償還契約

業務で**実際に発生した費用を発注者が支払う契約**。

英語では **Cost Reimbursable Contract**。

### 例

システム開発で、

```text id="0ucw9b"
人件費：300万円
機材費： 50万円
その他： 20万円
----------------
実費　：370万円
```

実際に発生した370万円などを発注者が負担する。

契約によっては、これに受注者の報酬などを加える。

### ポイント

* 実際に発生した費用を支払う
* 最終的な金額を事前に確定しにくい
* 費用増加のリスクは発注者側が比較的大きい

> **実費償還 = かかった分を払う**

---

# 4. 定額契約

あらかじめ決めた**固定金額で業務を行う契約**。

英語では **Fixed Price Contract**。

### 例

```text id="p2pdqa"
「このシステムを500万円で開発します」

実際の開発費
400万円 → 契約金額500万円

実際の開発費
600万円 → 契約金額500万円
```

原則として契約した金額が基準になる。

### ポイント

* 契約時に金額を決める
* 発注者は予算を管理しやすい
* コスト超過のリスクは受注者側が比較的大きい

> **定額契約 = 最初に値段を決める**

---

# 定額契約と実費償還契約

試験ではこの違いが重要。

|          | 定額契約        | 実費償還契約      |
| -------- | ----------- | ----------- |
| 支払額      | あらかじめ決める    | 実際の費用による    |
| コスト超過リスク | 受注者側が大きい    | 発注者側が大きい    |
| 発注者の予算管理 | しやすい        | しにくい        |
| 例        | 「500万円で作って」 | 「かかった費用を払う」 |

```text id="otfqfi"
定額契約
→ 500万円で完成させて
→ 受注者のリスク大

実費償還契約
→ かかった分を払います
→ 発注者のリスク大
```

---

# 5. タイム・アンド・マテリアル契約

**作業時間や投入した資源に応じて料金を支払う契約。**

T&M（Time and Material）とも呼ばれる。

### 例

```text id="ahh4a7"
エンジニア
1時間：5,000円

100時間作業
↓
50万円
```

作業時間などに応じて支払額が変化する。

### ポイント

* 作業時間・投入資源に応じて支払う
* 作業量が事前に確定しにくい場合に利用
* 定額契約と実費償還契約の中間的な性質を持つ

> **T&M = 働いた時間・使った資源に応じて払う**

---

# 6. 従量課金

**実際に利用した量に応じて料金を支払う方式。**

クラウドサービスなどでよく利用される。

### 例

```text id="5x4vqw"
サーバ利用時間
100時間
  ×
1時間100円
  ↓
10,000円
```

AWSなどのクラウドサービスでも、利用量に応じた料金体系が広く使われている。

> **従量課金 = 使った分だけ払う**

---

# サブスクリプションと従量課金

```text id="0uqkmd"
サブスクリプション

月額5,000円
↓
どれだけ使っても基本5,000円
```

```text id="j32kh8"
従量課金

100回利用 → 1,000円
500回利用 → 5,000円

↓
使った量で変わる
```

|      | サブスクリプション | 従量課金      |
| ---- | --------- | --------- |
| 基準   | 期間        | 使用量       |
| 料金   | 月額・年額など   | 利用量によって変化 |
| イメージ | 定額制       | 使った分だけ    |

---

# 試験用まとめ

| 用語        | 内容               | 一言            |
| --------- | ---------------- | ------------- |
| レベニューシェア  | 売上・収益を分配         | **儲けを分ける**    |
| サブスクリプション | 一定期間の利用権に料金を払う   | **定期料金**      |
| 実費償還契約    | 実際に発生した費用を支払う    | **かかった分**     |
| 定額契約      | 契約時に固定価格を決める     | **最初に値段を決める** |
| T&M       | 作業時間・投入資源に応じて支払う | **働いた分**      |
| 従量課金      | サービスの利用量に応じて支払う  | **使った分**      |

---

# 見分け方

```text id="a1ynmx"
「売上の○%を支払う」
→ レベニューシェア

「月額○円・年額○円」
→ サブスクリプション

「実際に発生した費用を支払う」
→ 実費償還契約

「500万円で完成させる」
→ 定額契約

「作業1時間につき○円」
→ T&M

「利用量に応じて課金」
→ 従量課金
```

→ 最初に金額を決める

**T&M**
→ 作業時間・資源に応じて払う
