## 概要

**サービスポートフォリオ**とは、サービス提供者が管理する**全てのITサービスをまとめたもの**。

現在提供しているサービスだけでなく、

* 開発・検討中
* 現在提供中
* 廃止済み

のサービスも含む。

```text id="r9we1a"
サービスポートフォリオ
│
├─ サービスパイプライン
│   → 開発・検討中
│
├─ サービスカタログ
│   → 現在提供中
│
└─ 廃止済みサービス
    → 提供終了
```

---

# サービスパイプライン

**将来提供する予定・検討中のサービス**。

```text id="b34uvd"
企画
 ↓
開発
 ↓
将来提供予定
```

> **パイプライン = これからのサービス**

---

# サービスカタログ

**現在、顧客に提供可能なサービスの情報**。

例えば、

```text id="86zg5e"
社内ITサービス

・メールサービス
・ファイル共有
・VPN
・クラウド環境
```

など。

利用者が「現在どんなサービスを利用できるか」を確認できる。

> **サービスカタログ = 今使えるサービス**

---

# 廃止済みサービス

以前提供していたが、現在は提供を終了したサービス。

履歴として管理する。

> **廃止済み = 過去のサービス**

---

# 試験用まとめ

| 分類         | 状態      |
| ---------- | ------- |
| サービスパイプライン | 将来・開発中  |
| サービスカタログ   | 現在提供中   |
| 廃止済みサービス   | 過去・提供終了 |

これら全体が、

**サービスポートフォリオ**

となる。

```text id="xjj0pf"
         サービスポートフォリオ
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
パイプライン   カタログ    廃止済み
   ↓            ↓          ↓
 未来           現在        過去
```

## 一言で覚える

**サービスポートフォリオ = サービスの一生を全部管理**

```text id="0h2xge"
パイプライン → 未来
カタログ     → 現在
廃止済み     → 過去
```
