# ハイプ曲線と技術のSカーブ

## 1. 違い

| 項目   | ハイプ曲線             | 技術のSカーブ       |
| ---- | ----------------- | ------------- |
| 見るもの | **世間の期待・注目度**     | **技術の性能・成熟度** |
| 縦軸   | 期待度               | 技術性能・成果       |
| 横軸   | 時間                | 時間・開発努力       |
| 特徴   | 期待が急上昇し、一度落ちてから安定 | 徐々に成長し、最後は頭打ち |
| 用途   | 流行・市場の期待を見る       | 技術の成長・限界を見る   |

---

## 2. ハイプ曲線

**「その技術が世間からどれくらい期待されているか」**を表す。

```text
期待度
 ↑
 │        ／＼  ← 過度な期待
 │       /   \
 │      /     ＼
 │     /        ＼___
 │ ___/              ＼____ ← 現実的な普及
 └──────────────────→ 時間
```

### 流れ

**技術登場 → 注目 → 過度な期待 → 幻滅 → 現実的な普及**

例：生成AI

* 「AIですべて自動化できる！」
* 実際には限界があることが分かる
* 「この業務ならAIが有効」と現実的な活用が進む

### 試験キーワード

* 期待
* 注目
* 過度な期待
* 幻滅
* 普及

→ **期待度の話なら「ハイプ曲線」**

---

## 3. 技術のSカーブ

**「技術そのものがどれくらい成長・成熟したか」**を表す。

```text
技術性能
 ↑
 │                    ───── 成熟・限界
 │                ___/
 │             __/
 │          __/
 │      ___/
 │_____/
 └──────────────────→ 時間・開発努力
```

### 流れ

**導入期 → 急成長 → 成熟 → 技術的限界**

成熟すると、いくら開発しても性能が伸びにくくなる。

そこで、

```text
旧技術        ______
            /
         __/
________/

                 新技術       ______
                           ___/
                       ___/
______________________/________→ 時間
```

のように、**新しい技術のSカーブへ移行する「技術革新」**が起こる。

### 試験キーワード

* 技術性能
* 成熟
* 技術的限界
* 開発努力
* 技術革新
* 新技術への移行

→ **技術そのものの成長なら「Sカーブ」**

---

## 4. 試験での見分け方

```text
「期待・注目・幻滅」
        ↓
   ハイプ曲線

「性能・成長・成熟・限界」
        ↓
   技術のSカーブ
```

### 一言で覚える

> **ハイプ曲線 = 世間の期待の上下**
> **Sカーブ = 技術そのものの成長**
