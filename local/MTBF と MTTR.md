システムの**信頼性・保守性・可用性**を表す代表的な指標。

## MTBF（Mean Time Between Failures）

**平均故障間隔**

> 「故障してから、次に故障するまで平均どれくらい動くか」

* 単位：時間
* **長いほど良い**
* システムの**信頼性**を表す
* 「壊れにくさ」の指標

### 例

```text
100時間稼働 → 故障 → 修理 → 120時間稼働 → 故障
```

平均すると約110時間。

→ **MTBF = 110時間**

---

## MTTR（Mean Time To Repair）

**平均修復時間**

> 「故障してから、復旧するまで平均どれくらいかかるか」

* 単位：時間
* **短いほど良い**
* システムの**保守性**を表す
* 「直しやすさ・復旧の速さ」の指標

### 例

```text
故障 → 2時間で復旧
故障 → 4時間で復旧
```

→ **MTTR = 3時間**

---

## MTBFとMTTRの違い

| 指標       | 意味     | 良い状態 | 関係する性質 |
| -------- | ------ | ---- | ------ |
| **MTBF** | 平均故障間隔 | 長い ↑ | 信頼性    |
| **MTTR** | 平均修復時間 | 短い ↓ | 保守性    |

覚え方：

```text
MTBF → Failure（故障）まで → 長い方がいい
MTTR → Repair（修理） → 短い方がいい
```

---

## 可用性（稼働率）

試験では**MTBF・MTTRから可用性を求める問題**が重要。

```text
可用性 = MTBF ÷ (MTBF + MTTR)
```

### 例

```text
MTBF = 100時間
MTTR = 2時間

可用性
= 100 ÷ (100 + 2)
= 約0.9804
= 約98.04%
```

つまり可用性を高めるには、

```text
MTBFを長くする ↑  → 壊れにくくする
MTTRを短くする ↓  → 早く復旧する
```

---

## 試験での切り分け

```text
「故障しにくさ」      → MTBF
「故障までの時間」    → MTBF
「信頼性」            → MTBF

「復旧の速さ」        → MTTR
「修理にかかる時間」  → MTTR
「保守性」            → MTTR

「システムが使える割合」→ 可用性
```

### 一言で覚える

**MTBF = 壊れるまでの長さ**

**MTTR = 壊れてから直るまでの短さ**
