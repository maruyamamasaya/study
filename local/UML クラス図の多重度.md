## 多重度とは

**クラス同士が「何個対何個」の関係になるか**を表す。

例えば、

```text id="c2k0fa"
顧客 1 ───────── 0..* 注文
```

これは、

> 1人の顧客は、0件以上の注文を持つことができる

という関係。

---

# 基本的な表記

| 表記     | 意味     |
| ------ | ------ |
| `1`    | 必ず1つ   |
| `0..1` | 0または1つ |
| `*`    | 0個以上   |
| `0..*` | 0個以上   |
| `1..*` | 1個以上   |
| `2..5` | 2～5個   |

---

# 1：1

```text id="g3q6zn"
社員 1 ───────── 1 社員証
```

1人の社員に対して、社員証が必ず1つ。

```text id="oc17v4"
社員 ←→ 社員証

1   ：   1
```

> **1 = 必ず1つ**

---

# 0..1

```text id="q5z6xu"
社員 1 ───────── 0..1 社用車
```

社員は、

* 社用車を持っていない
* 1台持っている

のどちらか。

> **0..1 = あってもなくてもよい。ただし最大1つ**

---

# 0..* または *

```text id="m9a2rt"
顧客 1 ───────── 0..* 注文
```

1人の顧客は、

```text id="lhf6yf"
注文なし   → OK
注文1件    → OK
注文10件   → OK
```

となる。

`*`だけでも基本的に`0..*`と同じ意味。

> **0..* = 0個以上、いくつでも**

---

# 1..*

```text id="82xbjo"
注文 1 ───────── 1..* 注文明細
```

1件の注文には、

**1件以上の注文明細が存在する。**

```text id="vddfxl"
0件 → ×
1件 → ○
2件 → ○
100件 → ○
```

> **1..* = 最低1つ必要、上限なし**

---

# 範囲指定

例えば、

```text id="99asxa"
チーム 1 ───────── 2..5 メンバー
```

なら、

1チームには、

**2～5人のメンバーが所属する**

という意味。

---

# 1対多

よく出てくる関係。

```text id="9idjq6"
顧客 1 ───────── 0..* 注文
```

意味は、

```text id="v67d09"
1人の顧客
   ↓
注文0件以上
```

つまり、

**1対多（1:N）**

の関係。

---

# 多対多

```text id="qtr6tz"
学生 0..* ───────── 0..* 講義
```

学生は複数の講義を受講でき、

講義には複数の学生が参加できる。

```text id="jdohvb"
学生A → 講義1
      → 講義2

学生B → 講義1
      → 講義3
```

これは、

**多対多（N:M）**

の関係。

---

# 多重度の読み方

ここが特に重要。

```text id="2zdmdw"
顧客 1 ───────── 0..* 注文
```

`0..*`は**注文側**に書かれている。

これは、

> 1人の顧客に対して、注文はいくつ存在できるか？

と読む。

答えは、

```text id="htnyfl"
0～複数
```

逆方向に読むと、

> 1件の注文に対して顧客はいくつ存在するか？

顧客側を見るので、

```text id="rdnry3"
1
```

となる。

---

# 具体例

## 顧客と注文

```text id="z5gdxl"
顧客 1 ───────── 0..* 注文
```

意味：

```text id="cmlggd"
顧客 → 注文
1人 → 0件以上

注文 → 顧客
1件 → 必ず1人
```

---

## 注文と注文明細

```text id="9isg3h"
注文 1 ───────── 1..* 注文明細
```

意味：

```text id="k7v3ad"
1注文
 ↓
1件以上の注文明細
```

例えば、

```text id="i2pttg"
注文001
├─ 商品A × 2
├─ 商品B × 1
└─ 商品C × 3
```

---

# 試験用まとめ

```text id="c3f5oj"
1
→ 必ず1つ

0..1
→ 0または1

*
0..*
→ 0個以上

1..*
→ 1個以上

2..5
→ 2～5個
```

---

# 最重要

```text id="uqz70q"
顧客 1 ───────── 0..* 注文
```

を見たら、

```text id="47j0lr"
顧客1人
→ 注文は0件以上

注文1件
→ 顧客は1人
```

と読む。

## 覚え方

**「相手1つに対して、こちら側が何個あるか」**

と考える。

```text id="bdnvyb"
顧客 1 ───────── 0..* 注文
     ↑              ↑
注文から見る       顧客から見る
顧客の数           注文の数
```

多重度は、**数字が書いてある側のクラスが何個存在できるか**を表している。
