Pythonのライブラリは、基本的に **`site-packages` というフォルダ**に保存されます。

保存先は、`pip` をどの環境で実行したかによって変わります。

## 1. 仮想環境を使っている場合

たとえば、

```
python -m venv .venv
source .venv/bin/activate
pip install requests
```

とした場合、`requests` はプロジェクト内の仮想環境に保存されます。

```
my-project/
├── app.py
└── .venv/
    └── lib/
        └── python3.12/
            └── site-packages/
                ├── requests/
                ├── urllib3/
                └── certifi/
```

つまり、概ね次のような場所です。

```
.venv/lib/python3.x/site-packages/
```

Windowsでは、次のようになります。

```
.venv\Lib\site-packages\
```

プロジェクトごとにライブラリを分けられるため、実務ではこの方法が一般的です。

---

## 2. 仮想環境を使わずにインストールした場合

仮想環境を有効にせず、

```
pip install requests
```

を実行すると、Python本体側の `site-packages` に保存されます。

LinuxやmacOSでは、環境によって次のような場所です。

```
/usr/local/lib/python3.x/site-packages/
```

または、

```
/usr/lib/python3/dist-packages/
```

ユーザー単位でインストールした場合は、次のような場所になることもあります。

```
~/.local/lib/python3.x/site-packages/
```

Windowsでは、たとえば次のような場所です。

```
C:\Users\ユーザー名\AppData\Local\Programs\Python\Python312\Lib\site-packages\
```

---

## 3. 実際の保存場所を確認する方法

ライブラリの一覧と保存場所は、次のコマンドで確認できます。

```
pip show requests
```

表示例：

```
Name: requests
Version: 2.32.3
Location: /home/user/project/.venv/lib/python3.12/site-packages
```

`Location` が実際の保存先です。

Pythonから確認することもできます。

```
python -c "import requests; print(requests.__file__)"
```

表示例：

```
/home/user/project/.venv/lib/python3.12/site-packages/requests/__init__.py
```

---

## 4. `pip` と `python` の組み合わせに注意

PCに複数のPythonが入っていると、

```
pip install requests
```

で入れた場所と、

```
python app.py
```

で使っているPythonが別になることがあります。

そのため、実務では次の書き方が安全です。

```
python -m pip install requests
```

これなら、

> この `python` が使う場所に `requests` をインストールする

という意味になります。

確認する場合も、

```
python -m pip show requests
```

とすると分かりやすいです。

---

## まとめ

```
Python
└── site-packages
    ├── requests
    ├── pandas
    ├── boto3
    └── Flask
```

仮想環境を使う場合は、

```
プロジェクト
└── .venv
    └── site-packages
```

に保存されます。

実務では、ライブラリ同士のバージョン競合を防ぐため、**プロジェクトごとに `.venv` を作り、その中へ保存する**のが基本です。
