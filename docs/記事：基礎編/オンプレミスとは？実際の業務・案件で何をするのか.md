## 概要

**オンプレミス（On-Premises）**とは、会社が自社でサーバーやネットワーク機器を所有し、自社の建物内（データセンター含む）で運用するシステム形態です。

AWSやAzureなどのクラウドとは異なり、**サーバーを自分たちで購入・設置・保守する**必要があります。

# あなたの経験とのつながり

これまで話してくれた経験でいうと、保険系システムでの運用保守はオンプレミス案件に近い内容です。

- **Windows Server・AIX・DB2** の運用
- **JP1** によるジョブ監視・障害対応
- データベースの再編成（REORG）などの定常作業
- サーバー監視、障害一次対応、手順書に沿った運用

これらはオンプレミス環境で非常によくある業務であり、インフラ運用・保守の実務経験として評価されます。

# まとめ

オンプレミス案件では、単にサーバーを動かすだけでなく、**「設計 → 構築 → テスト → リリース → 運用保守」**まで幅広い工程があります。

実務では、サーバー・ネットワーク・データベース・仮想化・監視・バックアップ・セキュリティなどを組み合わせてシステム全体を支える仕事が中心です。特に金融・官公庁・製造業・医療など、高い安定性やセキュリティが求められる分野では、現在でもオンプレミス環境が多く採用されています。
