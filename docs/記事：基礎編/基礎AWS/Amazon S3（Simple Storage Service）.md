# 1. S3とは？

S3（Simple Storage Service）は、

**AWSが提供するオブジェクトストレージサービス**です。

簡単にいうと、

> **「インターネット上の巨大なファイル置き場」**

です。

例えば

- 画像
- PDF
- 動画
- バックアップ
- ログ
- HTMLファイル

などを保存できます。

---

# 2. なぜS3が必要なの？

例えばEC2だけで画像を保存すると…

```
EC2

├─画像
├─動画
├─PDF
└─ログ
```

問題点

- ディスク容量が足りなくなる
- EC2を削除するとファイルも失われる可能性がある
- 複数のEC2で共有しづらい

そこで

```
EC2

↓

S3
```

へ保存します。

---

# 4. S3の基本用語

S3では

```
Bucket（バケット）

↓

フォルダのようなもの
```

その中に

```

↓

ファイル
```

があります。

例えば

```
Bucket

yasukari-images

├─bike.jpg
├─logo.png
├─movie.mp4
└─manual.pdf
```

# 5. オブジェクトストレージとは？

初心者が混乱しやすい部分です。

### パソコン

```
C:

↓

↓

ファイル
```

---

### S3

```
Bucket

↓

Object
```

実際には「フォルダ」はなく、

**ファイル名（キー）に `/` を含めることで、フォルダのように見せています。**

例えば

```

bike.jpg
```

実際には

```
images/bike.jpg
```

という1つの名前です。

# 21. S3・EC2・IAM・CloudWatchの関係

```
             開発者
                │
         IAM User + MFA
                │
                ▼
      AWS Management Console
                │
────────────────────────────────

             EC2(Node.js)
                │
          IAM Role
        ┌───────┴────────┐
        ▼                ▼
     DynamoDB           S3
        │                │
        └──────┬─────────┘
               ▼
         CloudWatch
```

ポイント

- **EC2**：アプリを動かす
- **S3**：画像・動画・PDFなどを保存する
- **IAM**：アクセス権限を管理する
- **CloudWatch**：システムを監視する

# 22. S3とEBSの違い

初心者が混同しやすいので整理します。

|項目|S3|EBS|
|---|---|---|
|用途|ファイル保存|EC2のディスク|
|データ形式|オブジェクト|ブロックストレージ|
|EC2への接続|不要|必要|
|容量|ほぼ無制限|サイズを指定|
|代表例|画像・動画・PDF・バックアップ|OS・アプリ・データベース|

例えると…

- **EBS = パソコンのSSD**
- **S3 = Google DriveやDropboxのようなクラウドストレージ**

---

# 23. まとめ

- **S3はAWSのオブジェクトストレージサービス**
- **画像・動画・PDF・ログ・バックアップなどの保存に最適**
- **データは「Bucket」と「Object」で管理する**
- **EC2からはIAM Roleを使って安全にアクセスする**
- **CloudFrontと組み合わせることで世界中へ高速配信できる**
- **耐久性が非常に高く、バックアップ用途にも広く利用される**

# 次に学ぶと理解が深まる内容

S3を理解したら、次は以下の順番がおすすめです。

1. **CloudFront**（S3のコンテンツを高速配信）
2. **AWS Certificate Manager（ACM）**（HTTPS証明書）
3. **Application Load Balancer（ALB）**（負荷分散）
4. **VPC**（ネットワーク）
5. **AWS Backup**（バックアップの一元管理）
6. **Lifecycle・Versioning・暗号化**（S3運用の実践）

## EC2・S3・DynamoDBの役割を一言でまとめると

```
EC2       = アプリケーションを動かす
S3        = ファイル（画像・動画・PDFなど）を保存する
DynamoDB  = データ（予約・ユーザー情報など）を保存する
```

この3つはWebアプリケーションで非常によく組み合わせて利用されるAWSサービスです。
