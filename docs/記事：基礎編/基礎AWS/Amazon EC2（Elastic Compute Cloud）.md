# 1. EC2とは？

EC2（Elastic Compute Cloud）は、**AWS上で仮想サーバーを作るサービス**です。

簡単にいうと、

> **「AWSの中に、自分専用のWindowsやLinuxサーバーを借りるサービス」**

です。

例えば、

- Webサイト
- APIサーバー
- データ処理
- 開発環境

などを動かします。

イメージすると

```
AWS

┌────────────────────┐
│ EC2                │
│                    │
│ Ubuntu Linux       │
│ nginx              │
│ Node.js            │
│ Java               │
│ Python             │
│ MySQL              │
└────────────────────┘
```

普通のPCと同じように

- OS
- CPU
- メモリ
- ディスク

を持っています。

# 18. EC2のメリット・デメリット

|メリット|デメリット|
|---|---|
|自由度が高い|OS管理が必要|
|好きなソフトを入れられる|セキュリティ管理が必要|
|ほぼ何でも動く|障害対応は自分たち|
|他社への移行もしやすい|サーバー知識が必要|

---

# 19. EC2と他のAWSサービスとの違い

|サービス|特徴|
|---|---|
|EC2|自分でサーバーを管理する|
|Lambda|サーバー管理不要。イベント実行向け|
|ECS|Dockerコンテナを実行・管理する|
|EKS|Kubernetesでコンテナを大規模運用する|
|Elastic Beanstalk|アプリのデプロイを簡単にするPaaS|

---

# 20. まとめ

- **EC2はAWS上で仮想サーバーを作るサービス**
- LinuxやWindowsを自由に利用できる
- Webサイト・API・バッチ・管理画面など幅広く利用される
- セキュリティグループやEBSなど、周辺サービスと組み合わせて運用する
- 実務では **「SSH接続 → デプロイ → ログ確認 → 監視 → 障害対応」** が日常的な作業になる

# 次に学ぶと理解が深まる内容

EC2を理解したら、次は以下の順番で学ぶとAWS全体の流れがつながります。

1. **VPC**（EC2を置くネットワーク）
2. **Security Group**（通信制御）
3. **ALB（Application Load Balancer）**（アクセスの振り分け）
4. **Route 53**（DNS・ドメイン管理）
5. **EBS**（ディスク）
6. **IAM**（権限管理）
7. **CloudWatch**（監視・ログ）
8. **Auto Scaling**（アクセス増加時の自動スケール）
9. **RDS・DynamoDB**（データベース）
10. **AWS全体アーキテクチャ**（実務での構成例）

この順番で学ぶと、「EC2単体」ではなく「実際のAWSシステム全体」を理解しやすくなります。
