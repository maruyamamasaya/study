# 1. AWS Certificate Manager（ACM）とは？

AWS Certificate Manager（ACM）は、

**SSL/TLS証明書を発行・管理・更新するサービス**です。

簡単にいうと、

> **「HTTPS通信を安全に行うための証明書を管理するサービス」**

です。

例えば

```
https://yasukari.com
```

この

```
https
```

を実現しているのが

SSL/TLS証明書です。

---

# 2. HTTPとHTTPSの違い

まずはHTTP

```
ブラウザ

↓

HTTP

↓

EC2
```

通信内容は

そのまま流れます。

つまり

途中で見られる可能性があります。

---

HTTPS

```
ブラウザ

↓

暗号化

↓

EC2
```

途中で見られても

読めません。

---

# 3. なぜHTTPSが必要なの？

例えば

ログイン

```
ID

Password
```

これが

HTTPなら

盗まれる可能性があります。

HTTPSなら

```
************
```

となり

安全です。

---

# 4. SSL/TLS証明書とは？

証明書とは

> **「このサイトは本物ですよ」**

という身分証明書です。

例えば

```
https://amazon.co.jp
```

ブラウザは

証明書を確認して

本物かどうか

判断しています。

---

---

# 16. よくあるエラー

### HTTPSにならない

原因

ACM未設定

---

### 証明書が出ない

原因

DNS確認失敗

---

### 保留中

原因

DNSレコード未設定

---

### CloudFrontで選べない

原因

CloudFrontで使う証明書は **米国東部（バージニア北部 / us-east-1）** リージョンに作成する必要があります。

---

### ALBで選べない

原因

ALBと同じリージョンに

証明書がない。

# 20. ACM・CloudFront・ALBの役割

|サービス|役割|
|---|---|
|ACM|SSL/TLS証明書を管理する|
|CloudFront|世界中へ高速配信する|
|ALB|EC2へリクエストを振り分ける|
|Route53|ドメインを管理する|

---

# 21. ACMのメリット・デメリット

|メリット|デメリット|
|---|---|
|証明書が無料（AWSで利用する場合）|AWS外では利用できないケースがある|
|自動更新|リージョンの制約がある|
|AWSサービスとの連携が簡単|DNS設定の理解が必要|
|HTTPSを簡単に導入できる|直接EC2にインストールする用途には向かない|

---

# 22. まとめ

- **ACMはSSL/TLS証明書を発行・管理するサービス**
- **HTTPS通信を安全に実現するために利用する**
- **CloudFrontやALBと組み合わせるのが一般的**
- **DNS認証を使うと更新も自動化しやすい**
- **証明書の有効期限管理をAWSが自動で行ってくれる**

---

# 次に学ぶと理解が深まる内容

ACMを理解したら、次は以下の順番がおすすめです。

1. **AWS WAF**（Webアプリケーションへの攻撃を防ぐ）
2. **AWS Shield**（DDoS攻撃対策）
3. **Secrets Manager**（パスワード・APIキーの管理）
4. **AWS KMS**（暗号化キーの管理）
5. **Amazon Cognito**（ログイン・認証）
6. **VPC・Security Group・NACL**（ネットワークセキュリティ）
