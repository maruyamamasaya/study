# Bedrockとの違い

|Bedrock|SageMaker|
|---|---|
|AIを利用する|AIを開発・学習する|
|Claudeが使える|自分のAIを作る|
|APIを呼ぶだけ|データ学習が必要|
|チャットボット向き|機械学習向き|
|RAGが得意|モデル開発が得意|

---

# Amazon Qとの違い

|Amazon Q|Bedrock|
|---|---|
|AIアシスタント|AI開発基盤|
|ChatGPTに近い|OpenAI APIに近い|
|そのまま質問できる|自分でアプリを作る|
|AWS操作を支援|システムにAIを組み込む|

# 3つの違い

|サービス|一言でいうと|
|---|---|
|Amazon Q|AI秘書・AIエンジニア|
|Bedrock|AIを組み込むための基盤|
|SageMaker|AIそのものを開発する|

# あなたならどれを使う？

あなたがこれまで開発してきた **Yasukari** のようなWebサービスを例にすると、

### Amazon Q

- AWSの設定方法を質問する
- TerraformやCloudFormationを書く
- IAMポリシーやLambdaコードを生成する
- エラー解析やコードレビューを支援してもらう

### Amazon Bedrock

- AIチャットボットを追加する
- 「おすすめの自転車は？」に回答する
- 外国人向けに多言語案内をする
- 利用ガイドをAIに質問できるようにする

### SageMaker

- 過去の予約データから需要予測をする
- 「この日は混雑しそう」と予測する
- 故障しやすい車両を予測する
- 利用者ごとにおすすめ車種を学習モデルで提案する

## 実務で一番使われるのは？

Webエンジニアやクラウドエンジニアであれば、触れる機会が多い順番は次のようなイメージです。

1. **Amazon Q**（開発支援・AWS運用）
2. **Amazon Bedrock**（生成AI機能の組み込み）
3. **Amazon SageMaker**（機械学習モデルの開発）

特に近年は生成AIの活用が広がっているため、**「Amazon Qで開発を効率化し、必要に応じてBedrockでAI機能を実装する」**というケースが増えています。一方、SageMakerはデータサイエンティストや機械学習エンジニアが中心となって利用することが多いサービスです。
