**初心者向け勉強会資料（AWSの高性能リレーショナルデータベース）**

---

# 1. Amazon Auroraとは？

Amazon Auroraは、

> **AWSが開発した高性能なリレーショナルデータベース（RDB）**

です。

MySQLやPostgreSQLと互換性があり、既存のアプリケーションを大きく変更せずに利用できます。

---

# 2. Auroraが生まれた理由

通常のMySQLでは

- 大量アクセスに弱い
- 障害対応を自分で考える必要がある
- レプリケーション設定が必要

などの課題があります。

AuroraはこれらをAWSが改善しています。

---

# 3. イメージ

```
Webアプリ

↓

Aurora

↓

高速にデータ保存
```

普通のRDSよりも

- 高速
- 高可用性
- 自動復旧

が特徴です。

---

# 4. Auroraの特徴

✅ MySQL互換

✅ PostgreSQL互換

✅ 高速処理

✅ 自動バックアップ

✅ 自動復旧

✅ 最大15台のリードレプリカ

---

# 5. 実務では

例えば

- ECサイト
- 銀行システム
- SaaS
- 会員サービス
- 予約システム

など、大量アクセスがあるサービスで利用されます。

---

# 6. Auroraの構成

```
EC2

↓

Aurora Writer
（書き込み）

↓

Aurora Reader
（読み込み）
```

読み込みを複数台へ分散できます。

---

# 7. AuroraとRDSの違い

|RDS|Aurora|
|---|---|
|MySQLそのもの|AWS独自に最適化|
|一般的な性能|より高性能|
|小〜中規模向け|中〜大規模向け|
|コストは比較的安い|高機能な分やや高価|

---

# 8. こんな時に選ぶ

Auroraが向いている

- アクセス数が多い
- 高可用性が必要
- 高速な読み書きが必要

RDS(MySQL)が向いている

- 小〜中規模
- コスト重視
- シンプルなWebサービス

---

# まとめ

Auroraは

> **「RDSの上位版」のような位置付け**

と考えると理解しやすいでしょう。

---

# Amazon Redshiftとは？

**初心者向け勉強会資料（AWSのデータ分析サービス）**

---

# 1. Redshiftとは？

Amazon Redshiftは、

> **大量データを分析するためのデータウェアハウス（DWH）**

です。

ポイントは

**「保存」より「分析」が得意**

ということです。

---

# 2. データウェアハウスとは？

普通のデータベース

```
注文する

↓

保存
```

Redshift

```
何年分もの売上

↓

分析
```

---

# 3. 例えば

全国1000店舗

毎日100万件の売上

5年間

これを分析したい。

RDSではかなり重くなります。

Redshiftなら高速です。

---

# 4. 得意な処理

例えば

```
売上ランキング

月別売上

都道府県別売上

商品ランキング
```

こういう集計です。

---

# 5. 実務例

ECサイト

```
注文データ

↓

Redshift

↓

BIツール

↓

売上分析
```

---

銀行

```
取引履歴

↓

Redshift

↓

不正分析
```

---

# 6. データの流れ

```
RDS

↓

毎日コピー

↓

Redshift

↓

分析
```

通常は

業務データをコピーして分析します。

---

# 7. BIツールと連携

例えば

- QuickSight
- Tableau
- Power BI

などと組み合わせます。

```
Redshift

↓

QuickSight

↓

グラフ表示
```

---

# 8. RedshiftとRDSの違い

|RDS|Redshift|
|---|---|
|データ保存|データ分析|
|日々の業務処理|レポート・集計|
|INSERT・UPDATEが多い|SELECT・集計が多い|
|Webサービス向け|BI・分析向け|

---

# 9. Redshiftはどんな会社で使う？

- Amazon
- 楽天
- メルカリ
- 銀行
- 保険会社
- 通信会社

大量データを分析する企業で多く利用されています。

---

# まとめ

Redshiftは

> **「分析専用の巨大データベース」**

です。

---

# Aurora・RDS・Redshiftの違い

|サービス|一言で説明|主な用途|
|---|---|---|
|RDS|一般的なリレーショナルDB|会員・予約・注文管理|
|Aurora|高性能なRDS|大規模Webサービス|
|Redshift|データ分析専用DB|売上分析・BI・レポート|

---


---

### 大規模サービス

```
EC2
```

---

### 経営分析・売上分析

```
RDS

```

---

# 覚えておきたいポイント

|サービス|覚え方|
|---|---|
|**RDS**|日常業務で使うデータベース|
|**Aurora**|高性能・高可用性なRDS|
|**Redshift**|分析・集計専用のデータウェアハウス|

> **実務では**、Webサービスは **RDSまたはAurora** にデータを保存し、そのデータを定期的に **Redshift** へ取り込んで分析・ダッシュボード作成を行う、という構成がよく採用されます。
