# 1. Amazon SESとは？

SES（Simple Email Service）は、

**AWSが提供するメール送信サービス**です。

簡単にいうと、

> **「アプリケーションからメールを送るためのサービス」**

です。

例えば

- 会員登録完了メール
- パスワードリセットメール
- 注文完了メール
- お問い合わせ通知

などを送信できます。

---

# 2. なぜSESが必要なの？

例えば

会員登録したとき

```
利用者

↓

会員登録

↓

メール送信
```

このメールを送るのがSESです。

# 5. SMTPとAPI

SESには2つの使い方があります。

### API

Node.jsなどから直接送信

```
Node.js

↓

SES API

↓

メール
```

現在はこちらが主流です。

---

### SMTP

メールサーバーとして利用

```
アプリ

↓

SMTP

↓

SES
```

WordPressなどで利用されることがあります。

# 8. Sandboxとは？

SESには最初

**Sandbox（サンドボックス）**

があります。

この状態では

送信できる相手が制限されます。

例えば

```
自分

OK

他人

NG
```

となります。

本番利用するには

Sandbox解除を申請します。

---

```

MX
```

# 10. DKIMとは？

メールが

改ざんされていないことを証明します。

```
SES

↓

電子署名

↓

メール
```

受信側は

安全なメールだと判断しやすくなります。

---

# 11. SPFとは？

「このサーバーは、このドメインのメールを送ってよい」という宣言です。

```
example.com

↓

SESから送信OK
```

をDNSに登録します。

---

# 12. DMARCとは？

SPFやDKIMの結果をもとに、

不正なメールをどう扱うかを決める仕組みです。

例えば

```
偽物メール

↓

拒否
```

など。

---

# 19. まとめ

- **SESはAWSのメール送信サービス**
- **会員登録・予約完了・お問い合わせなどのメール送信によく使われる**
- **APIまたはSMTPで利用できる**
- **本番利用前にはSandbox解除とドメイン認証が必要**
- **SPF・DKIM・DMARCを設定するとメールの信頼性が向上する**

# 次に学ぶと理解が深まる内容

SESを理解したら、次は以下を学ぶとメール配信の仕組みがよく分かります。

1. **SMTP**（メール送信プロトコル）
2. **DNS（MX・TXTレコード）**
3. **SPF・DKIM・DMARC**（メール認証）
4. **Amazon SNS**（メールだけでなくSMSや通知）
5. **Amazon SQS**（メール送信処理のキューイング）
6. **Lambda**（イベントに応じた自動メール送信）

---

# SES・SNS・SQSの違い

初心者が混同しやすいので整理すると、

|サービス|役割|
|---|---|
|**SES**|メールを送るサービス|
|**SNS**|メール・SMS・Lambdaなどへ通知するサービス|
|**SQS**|処理待ちのメッセージをためるサービス|

例えば予約システムでは、

```
利用者が予約
      │
      ▼
EC2が予約情報を保存
      │
      ▼
SES
      │
      ▼
「予約が完了しました」
```

というように、**ユーザーへメールを届ける最後の役割**をSESが担当しています。
