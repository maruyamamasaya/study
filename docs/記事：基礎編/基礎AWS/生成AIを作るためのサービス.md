# 1. Amazon Bedrock（一番おすすめ）

一番有名なのがこれです。

> **「ChatGPTやClaudeのようなAIを、AWS上で簡単に使えるサービス」**

例えば

```

↓

回答
```

これをAPIで呼び出せます。

# 14. AWS生成AIサービスまとめ

|サービス|役割|
|---|---|
|Amazon Bedrock|生成AIを利用する（LLMのAPI）|
|SageMaker|AI・機械学習モデルを作成・学習する|
|Lambda|AIを呼び出す処理を書く|
|S3|PDF・画像・データを保存する|
|DynamoDB|チャット履歴・設定を保存する|
|CloudWatch|AIアプリを監視する|
|IAM|AIが利用する権限を管理する|

---

## 一言でまとめると

- **Amazon Bedrock** = 「ChatGPTやClaudeなどの生成AIをAWSで安全に利用するサービス」
- **SageMaker** = 「AIモデルを自分で作る・学習させるサービス」
- **Lambda・S3・DynamoDB** = 「AIアプリを支える周辺サービス」

現在、多くの企業では**「Bedrock + Lambda + S3 + DynamoDB」**という組み合わせで、社内チャットボット、FAQ、文書検索、要約、AIエージェントなどを構築しています。
