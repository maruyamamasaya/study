# 1. フェイルオーバーとは？

フェイルオーバー（Failover）とは、

> **「システムに障害が起きたとき、自動的に別のサーバーへ切り替える仕組み」**

のことです。

つまり、

**「壊れたら、予備に自動で交代する」**という考え方です。

---

# 2. イメージ

普段はメインのサーバーが動いています。

```
利用者
   │
   ▼
メインサーバー
```

しかし、メインサーバーが故障すると…

```
利用者
   │
   ▼
予備サーバー
```

自動的に切り替わります。

---

# 3. 身近な例

電車で例えると、

```
通常

A線

↓

目的地
```

事故で止まったら

```
A線 ×

↓

B線へ切り替え

↓

目的地
```

これがフェイルオーバーです。

---

# 4. AWSではどうなる？

例えばEC2を2台用意します。

```
           ALB
         /     \
        ▼       ▼
    EC2①     EC2②
```

通常は両方が動いています。

もしEC2①が故障すると、

```
           ALB
             │
             ▼
          EC2②
```

ALB（Application Load Balancer）が正常なEC2だけに通信を送ります。

---

# 5. RDSの場合

データベースでもよく使われます。

```
プライマリDB
      │
      ▼
スタンバイDB
```

通常はプライマリDBが使われます。

故障すると、

```
スタンバイDB

↓

プライマリへ昇格
```

自動で切り替わります。

---

# 6. Route 53でもできる

リージョン全体が使えなくなった場合は、

```
東京リージョン
      │
      ▼
大阪リージョン
```

というように、Route 53のフェイルオーバールーティングを使って別リージョンへ切り替える構成もあります。

---

# 7. フェイルオーバーとロードバランサーの違い

混同しやすいので整理すると、

|用語|役割|
|---|---|
|**ロードバランサー（ALB）**|通信を複数サーバーへ分散する|
|**フェイルオーバー**|障害時に正常なサーバーへ切り替える|

ALBは普段から負荷を分散しつつ、障害が起きたサーバーを自動的に外すことができます。

---

# 8. フェイルオーバーとフェイルバック

フェイルオーバー後、故障したサーバーが復旧したら元に戻すことがあります。

```
通常
EC2①

↓

障害

↓

EC2②へ切り替え（フェイルオーバー）

↓

復旧

↓

EC2①へ戻す（フェイルバック）
```

---

# 9. 実務でよくある構成

```
利用者
   │
Route 53
   │
CloudFront
   │
ALB
 ┌─┴─────┐
 ▼        ▼
EC2      EC2
AZ-a    AZ-c
```

- EC2が1台故障 → ALBがもう1台へ切り替える
- AZ全体が障害 → 別AZのEC2が処理を続ける

これがAWSでよく採用される高可用性構成です。

---

# 10. Yasukariのようなサービスで考えると

例えば予約サイトで、

```
利用者

↓

予約

↓

EC2①（故障）
```

となっても、

```
利用者

↓

ALB

↓

EC2②
```

へ自動的に切り替われば、利用者は予約を続けられます。

---

# 11. フェイルオーバーが重要な理由

もしフェイルオーバーがなければ、

```
EC2故障

↓

サイト停止

↓

予約できない
```

となります。

フェイルオーバーがあれば、

```
EC2故障

↓

予備へ切り替え

↓

サービス継続
```

となり、利用者への影響を最小限にできます。

---

# 12. まとめ

- **フェイルオーバー** = 障害時に予備のシステムへ自動で切り替える仕組み
- **目的** = サービスを止めないこと（高可用性）
- **AWSでは** ALB、RDS Multi-AZ、Route 53などで実現できる
- **複数AZ・複数リージョン**を組み合わせることで、より障害に強いシステムを構築できる

---

# 一言でまとめると

> **フェイルオーバーは「故障したら、予備へ自動で交代する仕組み」です。**

サーバーやデータベースに障害が起きてもサービスを継続するために、AWSではALB・RDS・Route 53などを組み合わせてフェイルオーバーを実現することが一般的です。
