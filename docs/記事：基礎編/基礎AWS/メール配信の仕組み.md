# 全体の流れ

メールは、郵便とよく似た仕組みで届きます。

```
送信者
   │
   ▼
メールサーバー（送信）
   │
   ▼
インターネット
   │
   ▼
メールサーバー（受信）
   │
   ▼
受信者（Gmailなど）
```

例えば、

あなたが予約サイトで予約すると

```
予約完了

↓

メール送信

↓

あなたのGmail
```

という流れになります。

---

# 郵便に例えると

```
自分
 │
 ▼
郵便局
 │
 ▼
配送センター
 │
 ▼
相手の郵便局
 │
 ▼
相手の家
```

メールもほぼ同じです。

---

# 実際の流れ

例えば

```
maru@example.com
```

へ送る場合

```
EC2

↓

Amazon SES

↓

Gmail

↓

受信箱
```

となります。

# メール配信に登場するもの

## ① アプリ

まず

Webサイト

```
会員登録

↓

送信
```

となります。

---

## ② メール送信サービス

例えば

```
Amazon SES
```

や

- Gmail
- Outlook
- SendGrid

など。

ここで

メールを送ります。

---

## ③ DNS

送信先を調べます。

例えば

```
example.com
```

なら

```
このメールサーバーへ送ってね
```

という情報を

DNSから取得します。

---

## ④ 相手のメールサーバー

例えば

```
Gmail
```

なら

Googleのメールサーバーへ届きます。

---

## ⑤ 受信者

最後に

```
スマホ

PC

Gmail
```

で見られます。

# 一言でまとめると

**メール配信は、「アプリがメール送信サービス（SESなど）へ依頼し、メール送信サービスが宛先のメールサーバー（Gmailなど）へ届ける仕組み」です。**

郵便で例えると、

- **EC2（アプリ）** = 手紙を書く人
- **Amazon SES** = 郵便局
- **DNS** = 住所録
- **Gmail** = 相手の郵便局
- **受信者** = 手紙を受け取る人

というイメージで覚えると理解しやすいです。
