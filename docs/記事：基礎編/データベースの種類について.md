## 1. データベースとは

データベース（Database / DB）とは、

> **アプリやシステムで使うデータを保存・管理する仕組み**

です。

例えばWebサービスでは、

```text
ユーザー情報

商品情報

予約情報

注文情報

売上情報
```

などを保存します。

イメージすると、

```text
Webアプリ
   ↓
API
   ↓
Database
```

です。

---

# 2. データベースはなぜ必要？

例えば予約システムなら、

```text
誰が予約した？

何時から何時まで？

どの商品を予約した？

支払いは済んでいる？
```

といった情報を、ずっと保存しておく必要があります。

そのため、

```text
ブラウザを閉じても消えない

サーバーを再起動しても残る

あとから検索できる
```

仕組みとしてDBを使います。

---

# 3. MySQLとは

MySQLは、

> **代表的なリレーショナルデータベース（RDB）**

です。

例えば、

```text
users テーブル

id | name | email
1  | 田中 | tanaka@example.com
2  | 佐藤 | sato@example.com
```

のように、表形式でデータを管理します。

---

# 4. SQLとは

MySQLなどのRDBでは、

**SQL**

という言語を使います。

例えば、

```sql
SELECT * FROM users;
```

でユーザー一覧を取得できます。

追加するなら、

```sql
INSERT INTO users
(name, email)
VALUES
('田中', 'tanaka@example.com');
```

です。

つまり、

```text
SQL
→ DBを操作するための言語
```

です。

---

# 5. RDBとは

RDBは、

**Relational Database**

の略です。

簡単に言うと、

> **表同士を関連付けて管理するデータベース**

です。

例えば、

```text
users
↓
ユーザー情報

reservations
↓
予約情報
```

を、

```text
user_id
```

でつなげます。

```text
users
id = 1
田中

   ↓

reservations
user_id = 1
予約A
予約B
```

という関係です。

---

# 6. 代表的なRDB

よく使われるものは、

|DB|特徴|
|---|---|
|**MySQL**|Webサービスで非常によく使われる|
|**PostgreSQL**|高機能で複雑な処理にも強い|
|**MariaDB**|MySQLと互換性が高い|
|**Oracle Database**|大企業・基幹システムで多い|
|**SQL Server**|Microsoft製。企業システムで多い|

初心者ならまず、

```text
MySQL
または
PostgreSQL
```

を理解すれば十分です。

---

# 7. MySQLとPostgreSQL

簡単に比較すると、

```text
MySQL
→ シンプルでWebサービスでよく使われる

PostgreSQL
→ 高機能で複雑な処理にも強い
```

です。

どちらも、

```text
SQL

テーブル

JOIN

トランザクション
```

などの基本的な考え方は共通しています。

---

# 8. NoSQLとは

すべてのDBが表形式ではありません。

**NoSQL**

という種類もあります。

代表例は、

```text
MongoDB

DynamoDB

Redis
```

などです。

RDBが、

```text
行と列
```

で管理するのに対して、

NoSQLはもっと柔軟な形でデータを保存します。

---

# 9. DynamoDB

DynamoDBはAWSのNoSQLデータベースです。

例えば、

```json
{
  "userId": "100",
  "name": "田中",
  "status": "active"
}
```

のようなデータを保存できます。

特徴は、

```text
高速

自動でスケールしやすい

サーバー管理がほぼ不要
```

です。

---

# 10. MongoDB

MongoDBもNoSQLの代表です。

JSONに近い形式で、

```json
{
  "name": "田中",
  "age": 30,
  "tags": [
    "user",
    "premium"
  ]
}
```

のようなデータを保存します。

構造が柔軟なことが特徴です。

---

# 11. Redis

Redisは少し特殊です。

主に、

```text
キャッシュ

Session

一時データ

ランキング
```

などに使われます。

例えば、

```text
user:100
↓
田中さんのSession
```

のような高速アクセスが必要なデータに向いています。

---

# 12. RDSとは

AWSでよく登場するのが、

**Amazon RDS**

です。

RDSはデータベースそのものの名前ではありません。

> **AWSがRDBの運用を代わりに管理してくれるサービス**

です。

例えばRDS上で、

```text
MySQL

PostgreSQL

MariaDB

Oracle

SQL Server
```

などを動かせます。

---

# 13. RDSとMySQLの違い

ここは混同しやすいです。

```text
MySQL
↓
データベース製品


RDS
↓
AWS上でDBを運用するサービス
```

です。

つまり、

```text
Amazon RDS

   ↓

MySQL
```

という使い方ができます。

---

# 14. 自分でMySQLを動かす場合

例えばEC2へMySQLを入れる場合、

```text
EC2

↓

MySQLインストール

↓

設定

↓

バックアップ

↓

アップデート

↓

障害対応
```

などを自分で管理します。

---

# 15. RDSを使う場合

RDSなら、

```text
AWS

↓

RDS

↓

MySQL
```

として使えます。

AWSが、

```text
バックアップ

障害復旧

バージョン管理支援

監視

冗長化
```

などをサポートしてくれます。

そのため実務ではRDSを使うケースが多いです。

---

# 16. Auroraとは

AWSでは、

**Amazon Aurora**

もよく使われます。

Auroraは、

> **AWSが開発したRDB**

です。

MySQLやPostgreSQLとの互換性があります。

例えば、

```text
Aurora MySQL

Aurora PostgreSQL
```

があります。

特徴は、

```text
高可用性

高速

AWSとの連携が強い
```

ことです。

---

# 17. DBの全体像

簡単に整理すると、

```text
Database
│
├── RDB
│   │
│   ├── MySQL
│   ├── PostgreSQL
│   ├── MariaDB
│   ├── Oracle
│   └── SQL Server
│
└── NoSQL
    │
    ├── DynamoDB
    ├── MongoDB
    └── Redis
```

AWSでは、

```text
RDS
↓
MySQL / PostgreSQLなど

DynamoDB
↓
NoSQL

ElastiCache
↓
Redis
```

という形で利用できます。

# 22. まとめ

データベースは、

> **アプリのデータを保存・検索・管理する仕組み**

です。

簡単に整理すると、

```text
MySQL
→ RDB製品

PostgreSQL
→ RDB製品

RDS
→ AWSでRDBを管理するサービス

Aurora
→ AWS製のRDB

DynamoDB
→ AWSのNoSQL DB

MongoDB
→ JSON系NoSQL DB

Redis
→ 高速な一時データ・キャッシュ
```

という違いがあります。

Webアプリ全体では、

```text
ユーザー

↓

React / Next.js

↓

API

↓

Node.js

↓

Database

├── MySQL
├── PostgreSQL
├── DynamoDB
└── その他
```

という位置になります。

まずは、

```text
Database
↓
RDB
↓
MySQL
↓
SQL
↓
RDS
```

という順番で理解すると、データベースの全体像がつかみやすいです。
