― Web画面を作るだけではなく、ユーザー体験まで設計する仕事 ―

## 1. フロントエンドエンジニアとは

フロントエンドエンジニアとは、

> **ユーザーが実際に見る・触るWeb画面を作るエンジニア**

です。

例えば、Webサービスには次のような画面があります。

```text
ログイン画面

商品一覧

予約画面

決済画面

マイページ

管理画面
```

これらを作るのが主な役割です。

ただし、単にデザイン通りに画面を作るだけではありません。

実際には、

```text
ボタンを押したらどう動くか

APIからどうデータを取得するか

スマホでも使いやすいか

エラー時にどう表示するか

表示速度は遅くないか

セキュリティ上問題ないか
```

まで考える必要があります。

# 3. HTML

まず最初に必要なのが、

**HTML**

です。

HTMLは、

> **Webページの構造を作る言語**

です。

例えば、

```html
<h1>商品一覧</h1>

<p>おすすめの商品です。</p>

<button>購入する</button>
```

というコードを書くと、

```text
商品一覧

おすすめの商品です。

[購入する]
```

という画面になります。

HTMLでは、

```text
見出し

文章

画像

リンク

フォーム

ボタン
```

などを定義します。

---

# 4. HTMLを学ぶ理由

ReactやNext.jsを使うようになっても、最終的にブラウザへ表示されるのはHTMLです。

例えばReactで、

```tsx
return (
  <div>
    <h1>商品一覧</h1>
    <button>購入</button>
  </div>
);
```

と書いていても、

基本になる考え方はHTMLです。

そのため、

```text
Reactを使うからHTMLはいらない
```

ではなく、

> **Reactを理解するためにもHTMLの基礎が必要**

です。

# 7. JavaScript

JavaScriptは、

> **Webページに動きや処理を追加するプログラミング言語**

です。

例えば、

```javascript
const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("クリックされました");
});
```

という処理を書けます。

JavaScriptによって、

```text
ボタンクリック

フォーム入力

画面切り替え

API通信

データ処理
```

などを実装できます。

---

# 8. JavaScriptで特に重要な知識

フロントエンドでは、JavaScriptの中でも次の知識が重要です。

```text
変数

配列

オブジェクト

関数

if文

map

filter

Promise

async / await

import / export
```

例えばReactでは、

```javascript
users.map(user => (
  <p>{user.name}</p>
))
```

というコードをよく書きます。

この `map` はReactの機能ではなく、JavaScriptの機能です。

そのため、

> **Reactを学ぶ前にJavaScriptを理解することが重要**

です。

# 9. TypeScript

現在のフロントエンド開発では、

**TypeScript**

も非常によく使われます。

TypeScriptは、

> **JavaScriptに型を追加した言語**

です。

例えば、

```typescript
type User = {
  id: number;
  name: string;
};
```

と定義できます。

そして、

```typescript
const user: User = {
  id: 1,
  name: "田中"
};
```

と書けます。

しかし、大規模なアプリになると、

```text

文字列？

nullになる？

このAPIは何を返す？

この関数には何を渡す？
```

という問題が増えてきます。

TypeScriptを使うことで、

```text

↓

型チェック

↓

間違いを発見

↓

実行前に修正
```

ということができます。

そのため実務では、

```text
JavaScript
+
TypeScript
```

という構成が一般的です。

# 12. Component

Reactで最も重要なのが、

**Component**

です。

例えば、

```tsx
function Button() {
  return (
    <button>
      購入する
    </button>
  );
}
```

という部品を作れば、

```tsx
<Button />
<Button />
<Button />
```

のように再利用できます。

これによって、

```text

再利用しやすい

修正しやすい

チーム開発しやすい
```

というメリットがあります。

# 13. Props / State

Reactでは、

```text

State
```

## Props

> **親コンポーネントから渡されるデータ**

です。

```tsx

```

## State

Stateは、

> **画面の中で変化するデータ**

です。

例えば、

```text

ログイン状態

入力フォーム

モーダルの表示状態
```

などです。

