## SEO運用の必須ツール 〜検索順位とサイトの健康状態を管理する〜

---

# 概要

Google Search Console（サーチコンソール）は、

**Google検索から見た自社サイトの状態を確認・改善するための無料ツール**です。

Google Analytics（GA4）が

> **「サイトに来た後のユーザー行動」を分析するツール**

なのに対して、

Search Consoleは

> **「サイトへ来る前の検索状況」を分析するツール**

になります。

---

# GA4との違い

この違いは非常に重要です。

| ツール | 分かること |
|---------|-----------|
| Search Console | Google検索での状況 |
| GA4 | サイト訪問後の行動 |

例えば

```text
Google検索

↓

Search Console

↓

Webサイト

↓

GA4

↓

購入・予約
```

つまり

Search Consoleは

**検索エンジン側**

GA4は

**Webサイト側**

を担当しています。

---

# Search Consoleでできること

大きく分けると

```
検索順位

表示回数

クリック数

CTR

インデックス

クロール

サイトエラー

ページ品質
```

を確認できます。

---

# ① 検索パフォーマンス

最もよく見る画面です。

ここでは

- 表示回数
- クリック数
- CTR
- 平均順位

を確認できます。

---

## 表示回数（Impression）

Google検索結果に

表示された回数です。

例えば

```
1000回表示

↓

100人クリック
```

なら

表示回数は

```
1000
```

になります。

表示されただけでもカウントされます。

---

## クリック数

実際に

クリックされた回数です。

```
1000回表示

↓

100クリック
```

クリック数は

```
100
```

になります。

---

## CTR（クリック率）

CTRとは

```
クリック数

÷

表示回数
```

です。

例

```
表示1000回

クリック100回

↓

CTR 10%
```

CTRが低い場合は

タイトルや説明文を改善することで向上することがあります。

---

## 平均掲載順位

検索順位の平均です。

例えば

```
3位

4位

5位

↓

平均4位
```

となります。

順位だけでなく、

CTRと合わせて確認することが重要です。

---

# 検索クエリ

Search Consoleでは

ユーザーが実際に検索した言葉

を見ることができます。

例

```
東京 レンタルバイク

レンタルバイク 品川

大型バイク レンタル
```

これを見ることで

新しい記事やページのアイデアが生まれます。

---

# ページ分析

どのページが

検索されているか

も分かります。

例

```
料金ページ

車両一覧

店舗ページ

ブログ記事
```

人気ページをさらに改善することで

アクセスを伸ばせます。

---

# デバイス分析

検索は

- PC
- スマホ
- タブレット

別に確認できます。

最近では

ほとんどのサイトが

スマホ中心です。

---

# 国別分析

海外向けサービスなら

どこの国から検索されているか

も確認できます。

例えば

```
日本

アメリカ

台湾
```

などです。

---

# インデックスとは？

Googleは

ページを保存して

検索結果へ表示します。

これを

**インデックス**

と言います。

```
ページ公開

↓

Google巡回

↓

インデックス

↓

検索結果へ表示
```

インデックスされなければ

検索されません。

---

# URL検査

新しいページを公開した時は

URL検査を利用します。

```
URL入力

↓

Google確認

↓

インデックス登録をリクエスト
```

SEO担当者が頻繁に使います。

---

# sitemap.xml

サイトマップとは

Googleへ

```
このページがあります
```

と教える一覧です。

例

```
トップ

料金

店舗

予約

FAQ
```

新しいページを作ったら

Search Consoleへ送信します。

---

# robots.txt

Googleへ

```
ここは巡回しないでください
```

と伝える設定です。

例えば

```
管理画面

テストページ

開発環境
```

などを除外できます。

---

# クロール

Googleのロボットが

サイトを巡回することを

クロール

と言います。

```
Google

↓

ページ確認

↓

インデックス
```

クロールされないと

検索結果へ表示されません。

---

# カバレッジ

Googleが

問題なくインデックスできたか

確認できます。

例えば

```
404

500

リダイレクトエラー

robotsでブロック
```

などが表示されます。

---

# Core Web Vitals

Googleは

ページ品質も確認しています。

見る項目

| 指標 | 内容 |
|------|------|
| LCP | 表示速度 |
| INP | 操作の反応速度 |
| CLS | レイアウト崩れ |

改善対象ページが一覧で表示されます。

---

# リンク

Search Consoleでは

被リンク

内部リンク

も確認できます。

例えば

```
他サイト

↓

自社サイト
```

どこから紹介されているか

確認できます。

# SEO改善の進め方

例えば

```
順位

15位

↓

CTR

15%

↓

アクセス少ない
```

なら

順位改善

が必要です。

---

逆に

```
順位

2位

↓

CTR

2%
```

なら

タイトル改善

説明文改善

を行います。

---

また

```
順位

4位

↓

アクセス増

↓

CV少ない
```

なら

SEOではなく

Webサイト改善

が必要です。

つまり

Search Consoleだけではなく

GA4も合わせて見ることが重要です。

---

# Search ConsoleとGA4を組み合わせる

実務では

この2つを同時に見ます。

```text
Search Console

↓

検索順位

CTR

表示回数

↓

GA4

↓

予約率

購入率

離脱率
```

例えば

```
SEO成功

↓

アクセス増

↓

購入増
```

なら成功です。

逆に

```
アクセス増

↓

購入なし
```

なら

サイト改善

が必要になります。

# エンジニア視点で重要なこと

Search Consoleは

SEO担当だけのツールではありません。

エンジニアも

- sitemap.xml
- robots.txt
- canonicalタグ
- リダイレクト
- 404
- 構造化データ
- Core Web Vitals

などを改善するために利用します。

特にNext.jsでは

デプロイ後の確認として

Search Consoleを見ることが多くあります。

---

# この章のまとめ

- Search ConsoleはGoogle検索側を分析するツール
- 検索順位・表示回数・CTR・検索キーワードを確認できる
- インデックスやクロールエラーを管理する
- Core Web Vitalsなどページ品質も確認できる
- GA4と組み合わせることで、「検索 → サイト訪問 → コンバージョン」まで一連の流れを分析できる
- エンジニアもSEO担当も日常的に利用する重要なツールである
