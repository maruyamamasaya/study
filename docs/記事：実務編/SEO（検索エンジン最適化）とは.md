## 概要

SEO（Search Engine Optimization：検索エンジン最適化）とは、

**Googleなどの検索エンジンで、自社サイトを上位に表示させるための施策**です。

広告とは違い、検索結果から自然にアクセスしてもらうことを目的としています。

例えば

```
「バイクレンタル 東京」

↓

Google検索

↓

1位：A社

2位：B社

3位：自社サイト
```

SEOでは、この順位をできるだけ上げることを目指します。

---

# SEOが重要な理由

検索順位が上がるほど、多くのユーザーがサイトへ訪れます。

一般的に

```
1位
↓

クリック率 約30%

2位
↓

約15%

3位
↓

約10%

10位以下
↓

数％程度
```

となることが多く、上位表示されることが非常に重要です。

---

# Googleは何を見て順位を決めている？

Googleは数百以上の要素を総合的に評価しています。

大きく分けると

```
コンテンツ

＋

サイト品質

＋

ユーザー体験

＋

信頼性
```

で評価されています。

---

# SEOの全体像

SEOは大きく5つに分類できます。

```
SEO

├ コンテンツSEO
├ 内部SEO
├ 外部SEO
├ テクニカルSEO
└ ユーザー体験（UX）
```

---

# ① コンテンツSEO

一番重要なのが

**良い記事・良いページを作ること**

です。

Googleは

「検索した人の悩みを解決できるページ」

を高く評価します。

例

悪い記事

```
バイクレンタルです。
よろしくお願いします。
```

良い記事

```
料金

営業時間

予約方法

返却方法

保険

アクセス

よくある質問
```

ユーザーが知りたい情報を網羅しているほど評価されます。

---

# キーワード選定

SEOでは

「何を検索する人向けの記事か」

を決めます。

例

```
バイクレンタル

レンタルバイク 東京

大型バイク レンタル

品川 レンタルバイク
```

このキーワードに合わせてページを作ります。

---

# 検索意図（Search Intent）

SEOでは

「ユーザーが何を知りたいか」

を考えることが重要です。

例えば

```
バイクレンタル 東京
```

なら

ユーザーは

```
料金

場所

予約方法

営業時間

口コミ
```

を知りたい可能性があります。

これらをページへ掲載します。

---

# ② 内部SEO

サイトの構造を最適化することです。

例

```
トップ

↓

店舗一覧

↓

店舗詳細

↓

予約
```

Googleがページを理解しやすくなります。

---

## タイトル（title）

Google検索結果に表示されます。

例

```
東京のレンタルバイク｜Yasukari
```

---

## メタディスクリプション

検索結果の説明文です。

例

```
東京でレンタルバイクならYasukari。
24時間予約可能。
```

---

## 見出し（H1〜H6）

文章構造を整理します。

```
H1

↓

H2

↓

H3
```

---

## 内部リンク

ページ同士をつなぎます。

例

```
料金ページ

↓

予約ページ

↓

店舗ページ
```

Googleも巡回しやすくなります。

---

# ③ 外部SEO

他サイトから紹介されることです。

```
他サイト

↓

リンク

↓

自社サイト
```

良質なサイトから紹介されるほど評価されます。

これを

**被リンク（バックリンク）**

と言います。

---

# ④ テクニカルSEO

Googleが読みやすいサイトにします。

代表例

## sitemap.xml

Googleへ

```
このページがあります
```

と教えるファイル。

---

## robots.txt

Googleに

```
ここは見ないでください
```

と伝えるファイル。

---

## HTTPS

暗号化通信。

現在は必須です。

---

## モバイル対応

スマホでも見やすいこと。

Googleは

**モバイル版**

を基準に評価します。

---

## ページ速度

表示速度も重要です。

改善例

- 画像圧縮
- Lazy Load
- キャッシュ
- CDN
- 不要JavaScript削除

---

# Core Web Vitals

Googleが重視する

表示品質の指標です。

| 指標 | 内容 |
|------|------|
| LCP | 表示速度 |
| INP | 操作への反応速度 |
| CLS | レイアウト崩れ |

---

# ⑤ ユーザー体験（UX）

Googleは

「ユーザーが満足したか」

も評価します。

例えば

- 見やすい
- 読みやすい
- 操作しやすい
- スマホ対応

などです。

---

# E-E-A-T

Googleが重視する品質評価です。

| 要素 | 内容 |
|------|------|
| Experience | 実体験 |
| Expertise | 専門性 |
| Authoritativeness | 権威性 |
| Trustworthiness | 信頼性 |

例えば

実際の店舗写真や利用経験、運営会社情報などが信頼性につながります。

---

# 構造化データ（Schema.org）

検索エンジンへ

```
これは商品です

これはFAQです

これは店舗です
```

と伝えるデータです。

検索結果がリッチになります。

---

# GA4との関係

SEOは

```
順位を上げる
```

だけでは終わりません。

GA4で

```
どのページが見られているか

離脱率

コンバージョン率

滞在時間
```

などを分析し、

改善を繰り返します。

---

# Search Consoleとの関係

Google Search Consoleでは

- 検索順位
- 表示回数
- クリック数
- CTR
- インデックス状況
- エラー

を確認できます。

SEOでは必須ツールです。

---

# SEO改善の流れ

```
① キーワード選定

↓

② コンテンツ作成

↓

③ 内部SEO

↓

④ 公開

↓

⑤ Search Consoleで順位確認

↓

⑥ GA4でユーザー行動分析

↓

⑦ コンテンツ改善

↓

①へ戻る
```

SEOは一度作って終わりではなく、継続的に改善することが重要です。

---

# 実務でよく行う施策

- タイトル改善
- 見出し整理
- FAQ追加
- 内部リンク追加
- 画像最適化
- 表示速度改善
- 構造化データ追加
- Search Consoleでエラー修正
- GA4で離脱分析
- 人気ページのリライト

---

# まとめ

- SEOは検索エンジンで上位表示を目指す施策
- 「コンテンツ・内部SEO・外部SEO・テクニカルSEO・UX」の5つが基本
- Googleはユーザーにとって価値のあるページを評価する
- Search Consoleで検索状況を確認し、GA4でユーザー行動を分析する
- SEOは公開して終わりではなく、「分析 → 改善」を繰り返すことが成果につながる
