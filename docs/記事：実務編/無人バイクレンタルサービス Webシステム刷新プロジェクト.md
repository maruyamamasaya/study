# プロジェクト背景

顧客はバイク販売を主業務とする法人であり、既存事業として無人バイクレンタルサービスを展開していた。

しかし、既存システムは予約管理・在庫管理・顧客管理などの機能が限定的で、UI/UXも十分ではなく、利用者・運営者双方にとって操作性が低い状態であった。また、システム障害や運用トラブルが断続的に発生し、予約受付や店舗運営へ影響を及ぼすなど、事業継続性にも課題を抱えていた。

さらに、アクセス解析やマーケティング基盤も整備されておらず、Webサイトからの集客やコンバージョン分析が十分に行えない状況であった。

これらの課題を解決するため、既存システムを全面刷新し、予約・決済・顧客管理・在庫管理・マーケティング基盤までを含めた新システムの開発プロジェクトを受注した。

---

# プロジェクト目的

- Webサイトの全面リニューアル
- UI/UX改善
- 予約機能の刷新
- 車両在庫管理の一元化
- 顧客管理の強化
- オンライン決済導入
- スマートロック連携による無人運営
- マーケティング基盤整備
- サービス品質・運営効率の向上

---

# システム構成

利用者がWebサイトから予約・決済を行い、スマートロックと連携することで店舗スタッフを介さず貸出・返却まで完結する無人レンタルシステムを構築。

AWSを中心としたクラウド構成を採用し、フロントエンド・バックエンド・認証・決済・通知・分析基盤まで一貫して設計・構築した。

---

# 開発方針

顧客はシステムに関する専門知識を持たないため、技術選定・アーキテクチャ設計については開発側へ一任された。

保守性・拡張性・可用性を考慮し、AWSクラウドを採用。

また、生成AI（OpenAI Codex）を積極的に取り入れ、設計品質を維持したまま開発効率を向上させる開発プロセスを構築した。

開発はスクラムに近いアジャイル開発を採用し、短期間で実装・レビュー・改善を繰り返しながら、お客様と継続的に仕様調整を実施した。

- 老朽化した既存システムを全面刷新し、予約・決済・在庫管理・顧客管理を一元化

- 2025年12月に既存システムから新システムへの本番移行を完了し、現在も安定運用を継続
- 要件定義から設計・開発・AWS構築・本番移行・運用改善まで一貫して担当し、事業成長を技術面から支援
