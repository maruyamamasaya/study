# 第1章 Webマーケティング基礎編
## Webマーケティング全体像 〜「集客から売上まで」の仕組みを理解する〜

---

# 概要

Webマーケティングとは、

**インターネットを活用して、お客様を集め、商品やサービスを販売し、その結果を分析・改善して成果を最大化する活動**です。

Webサイトを作ることが目的ではなく、

**「売上」「問い合わせ」「会員登録」「予約」などの成果（コンバージョン）を増やすこと**が最終的な目的になります。

---

# Webマーケティングの全体像

まず最初に覚えてほしいのが、この流れです。

```text
認知
   ↓
興味・比較
   ↓
Webサイト訪問
   ↓
コンバージョン（CV）
   ↓
分析
   ↓
改善
```

この流れを何度も繰り返すことで、サイトやサービスを成長させます。

---

# Webマーケティングは「お店」と同じ

実店舗で考えると理解しやすくなります。

| お店 | Web |
|------|-----|
| 看板 | SEO・広告・SNS |
| 店舗 | Webサイト |
| 店員 | コンテンツ・デザイン・UI |
| レジ | 購入・予約フォーム |
| 売上分析 | GA4 |
| 改善 | PDCA・A/Bテスト |

つまり、Webサイトは**24時間働く営業マン**とも言えます。

---

# ステップ① 認知（まず知ってもらう）

どんなに良いサービスでも、存在を知られなければ利用されません。

まずは「知ってもらう」ことが重要です。

主な集客方法

| 集客方法 | 特徴 |
|-----------|------|
| SEO | Google検索から集客 |
| Google広告 | 検索結果へ広告表示 |
| SNS | Instagram・X・TikTokなど |
| MEO | Googleマップ検索 |
| YouTube | 動画による認知拡大 |
| LINE | リピーター育成 |
| メール | 継続的な情報発信 |

これらを**集客チャネル**と呼びます。

---

# ステップ② 興味・比較

ユーザーはサイトへ来ても、すぐ購入するわけではありません。

例えばレンタルバイクなら

```
料金は？

保険は？

口コミは？

営業時間は？

他社との違いは？
```

この疑問を解決できるサイトほど、予約されやすくなります。

つまり

**「ユーザーが知りたい情報を十分に提供すること」**

が重要です。

---

# ステップ③ コンバージョン（CV）

CV（Conversion）とは、

**サイトの目的となる成果**

を意味します。

例えば

| サイト | コンバージョン |
|----------|---------------|
| ECサイト | 商品購入 |
| 採用サイト | 応募 |
| コーポレートサイト | お問い合わせ |
| レンタルサイト | 予約 |
| 会員サイト | 会員登録 |

アクセス数ではなく、

**CV数を増やすこと**

がマーケティングの目的になります。

---

# ステップ④ 分析

成果が出たら終わりではありません。

GA4などを利用して

数字を分析します。

例

```
1000人訪問

↓

200人商品ページ

↓

80人予約画面

↓

20人予約完了
```

これを見ることで

「どこで離脱しているか」

が分かります。

---

# ステップ⑤ 改善

分析結果から改善します。

例えば

```
予約ボタンが分かりにくい

↓

ボタンを大きくする
```

```
スマホ表示が遅い

↓

画像を圧縮する
```

```
入力項目が多い

↓

フォームを短くする
```

このような改善を繰り返します。

---

# Webマーケティングで使われる主な施策

Webマーケティングにはさまざまな施策があります。

## SEO（検索エンジン最適化）

Google検索からユーザーを集めます。

特徴

- 長期的に効果が続く
- 広告費が不要
- 上位表示まで時間がかかる

---

## Google広告

検索結果へ広告を表示します。

特徴

- 即効性がある
- 広告費が必要
- 細かくターゲット設定できる

---

## SNSマーケティング

Instagram

X

TikTok

Facebook

などを利用します。

特徴

- 拡散されやすい
- ブランド認知に強い
- ファンを増やせる

---

## MEO（Googleマップ対策）

Googleマップで上位表示を目指します。

例えば

```
品川 ラーメン

新宿 美容室

渋谷 カフェ
```

のような地域検索で効果があります。

店舗ビジネスではSEO以上に重要になることもあります。

---

## LINEマーケティング

一度来店したお客様へ

- クーポン
- キャンペーン
- お知らせ

などを配信できます。

リピーター育成に効果があります。

---

## メールマーケティング

メールを利用して

- 新商品
- セール情報
- お役立ち情報

を届けます。

既存顧客との関係を維持する施策です。

---

# オウンド・ペイド・アーンドメディア

マーケティングでは、集客チャネルを3つに分類します。

| 種類 | 内容 | 例 |
|------|------|----|
| オウンドメディア | 自社が保有する媒体 | Webサイト・ブログ |
| ペイドメディア | お金を払って利用する媒体 | Google広告・Meta広告 |
| アーンドメディア | 第三者から評価される媒体 | SNS・口コミ・レビュー |

実務では、この3つを組み合わせて運用します。

---

# Webサイトは「営業マン」

Webサイトは

「会社案内」

ではありません。

役割は

```
集客

↓

商品の説明

↓

不安を解消

↓

予約・購入

↓

サポート
```

つまり、

営業担当が行う仕事を24時間365日自動で行う存在です。

---

# Webマーケティングで重要な考え方

初心者がよく勘違いするのは

```
アクセス数が増えた

＝成功
```

ではないことです。

例えば

```
1万人アクセス

↓

購入5件
```

より

```
1000人アクセス

↓

購入100件
```

の方が成果は高いと言えます。

重要なのは

**「集客」ではなく「成果」**

です。

---

# 実際の業務ではどう考える？

例えば、レンタルバイクサービスの場合

```
Google検索

↓

「東京 レンタルバイク」

↓

Webサイト

↓

料金確認

↓

予約

↓

決済

↓

利用

↓

レビュー投稿

↓

リピーター
```

この一連の流れ全体を改善するのが、Webマーケティングの仕事です。

---

# エンジニアとの関係

エンジニアは

「画面を作る」

だけではなく、

- ページ表示速度
- SEO対応
- GA4実装
- GTM実装
- フォーム改善
- スマホ対応
- A/Bテスト対応

などを通じて、マーケティング成果に大きく貢献します。

そのため、近年では

**「ビジネス視点を持ったエンジニア」**

の価値が高まっています。

---

# この章のまとめ

- Webマーケティングの目的は「成果（CV）」を増やすこと
- 基本の流れは「認知 → 興味・比較 → コンバージョン → 分析 → 改善」
- SEO・広告・SNS・MEOはすべて集客手段
- Webサイトは成果を生み出す営業マンの役割を持つ
- GA4などで分析し、改善を繰り返すことで成果を伸ばす
- エンジニアもマーケティングを理解することで、より価値の高いシステムを開発できる
