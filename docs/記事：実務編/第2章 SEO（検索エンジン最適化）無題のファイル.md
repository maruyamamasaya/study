## Google検索で選ばれるサイトを作るための考え方

---

# 概要

SEO（Search Engine Optimization：検索エンジン最適化）とは、

**Googleなどの検索エンジンで、自社サイトを上位に表示させるための施策**です。

広告とは異なり、検索結果から自然にアクセスを集めることを目的としています。

例えば

```
「レンタルバイク 東京」

↓

Google検索

↓

1位 A社

2位 B社

3位 Yasukari
```

SEOでは、この検索順位を上げることで、より多くのユーザーにサイトを見てもらいます。

---

# SEOの目的

SEOの目的は

**検索順位を上げることではありません。**

本当の目的は

```
検索

↓

サイト訪問

↓

予約・購入

↓

売上
```

です。

順位が上がっても成果につながらなければ意味がありません。

そのため、

**「検索順位」ではなく「ユーザーに価値を提供すること」**

を意識することが重要です。

---

# Googleは何を評価しているのか？

Googleの使命は

> **「ユーザーにとって最も役立つ情報を届けること」**

です。

そのため、

「Google向けのサイト」

ではなく、

**「ユーザー向けのサイト」**

が結果的にSEOにも強くなります。

評価されるポイントは、大きく4つあります。

```
コンテンツ

＋

技術的な品質

＋

サイトの信頼性

＋

ユーザー体験（UX）
```

---

# SEOの全体像

SEOは大きく4つの分野に分けられます。

```
SEO

├ コンテンツSEO
├ 内部SEO
├ 外部SEO
└ テクニカルSEO
```

---

# ① コンテンツSEO

最も重要なのがコンテンツです。

Googleは

**「検索した人の疑問を解決できるページ」**

を高く評価します。

例えば

```
東京 バイクレンタル
```

と検索する人は

- 料金
- 保険
- 営業時間
- 店舗
- 予約方法
- 必要な持ち物

などを知りたいと考えています。

これらを丁寧に説明したページほど評価されます。

---

# キーワード選定

SEOは

「どんな人に読んでもらいたいか」

を決めるところから始まります。

例えば

```
レンタルバイク
```

だけでは競争が激しいため、

```
品川 レンタルバイク

大型バイク レンタル 東京

初心者 レンタルバイク
```

など、より具体的なキーワードを狙うこともあります。

これを

**キーワード選定**

と言います。

---

# 検索意図（Search Intent）

SEOでは

キーワードよりも

**検索意図**

が重要です。

例えば

```
バイク 保険
```

という検索でも

人によって

```
加入方法を知りたい

料金を知りたい

おすすめを知りたい
```

など目的が違います。

Googleは

検索意図に合ったページ

を上位表示します。

---

# ② 内部SEO

内部SEOとは、

サイトの構造を分かりやすく整理することです。

例えば

```
トップ

↓

料金

↓

車両一覧

↓

予約
```

のように、ページ同士が適切につながっていると、Googleもユーザーも迷いません。

---

## titleタグ

検索結果で最も重要な要素です。

例

```
東京のレンタルバイク｜Yasukari
```

タイトルだけでクリック率が大きく変わります。

---

## meta description

検索結果に表示される説明文です。

順位には直接影響しませんが、

クリック率（CTR）に影響します。

---

## 見出し（H1〜H6）

見出しはページの構造を整理します。

```
H1

↓

H2

↓

H3
```

ユーザーにもGoogleにも内容が伝わりやすくなります。

---

## 内部リンク

ページ同士を適切につなぐことも重要です。

例えば

```
車両紹介

↓

料金

↓

予約方法
```

のように関連ページへ誘導することで、

回遊率が向上し、Googleもサイトを巡回しやすくなります。

---

# ③ 外部SEO

外部SEOとは、

他のサイトから紹介されることです。

```
他サイト

↓

リンク

↓

自社サイト
```

このリンクを

**被リンク（バックリンク）**

と言います。

信頼できるサイトから紹介されるほど評価が高くなります。

一方で、お金でリンクを大量購入するような行為はペナルティの対象になります。

---

# ④ テクニカルSEO

テクニカルSEOは、

Googleがサイトを正しく読み取れるようにする施策です。

---

## sitemap.xml

Googleへ

```
このページがあります
```

と伝える地図のようなファイルです。

---

## robots.txt

Googleに

```
このページは巡回しないでください
```

と伝える設定です。

---

## HTTPS

現在では必須です。

通信を暗号化し、安全性を確保します。

---

## モバイル対応

Googleは現在

**モバイル版**

を基準に評価しています。

そのため、

スマホで見やすいデザインが重要です。

---

## 表示速度

表示が遅いサイトは離脱率が高くなります。

改善方法

- 画像圧縮
- キャッシュ
- CDN
- JavaScript削減
- Lazy Load

などがあります。

---

# Core Web Vitals

Googleが重視する表示品質の指標です。

| 指標 | 内容 |
|------|------|
| LCP | ページが表示される速度 |
| INP | ボタンなどへの反応速度 |
| CLS | レイアウト崩れ |

SEOだけでなく、ユーザー体験にも大きく影響します。

---

# E-E-A-T

Googleが品質評価で重視する考え方です。

| 項目 | 内容 |
|------|------|
| Experience | 実際の体験 |
| Expertise | 専門性 |
| Authoritativeness | 権威性 |
| Trustworthiness | 信頼性 |

例えば、

- 実際の利用写真
- 運営会社情報
- お客様のレビュー
- 専門家による監修

などは信頼性向上につながります。

---

# Search Consoleとの関係

SEOで必須となるツールが

Google Search Console

です。

確認できること

- 検索順位
- 表示回数
- クリック数
- CTR
- インデックス状況
- クロールエラー
- Core Web Vitals

SEO担当者は毎日のように確認します。

---

# SEO改善の流れ

実務では、この流れを繰り返します。

```
① キーワード調査

↓

② コンテンツ作成

↓

③ 内部SEO

↓

④ 公開

↓

⑤ Search Consoleで順位確認

↓

⑥ GA4でユーザー行動分析

↓

⑦ コンテンツ改善
```

SEOは一度作って終わるものではなく、

**継続的に改善する活動**です。

---

# 実務でよく行うSEO施策

### コンテンツ改善

- 記事を最新情報へ更新
- FAQ追加
- 画像追加
- 関連情報を充実させる

---

### 内部SEO改善

- タイトル変更
- 見出し整理
- 内部リンク追加
- パンくずリスト設置

---

### テクニカルSEO改善

- sitemap.xml更新
- robots.txt修正
- 表示速度改善
- 構造化データ追加

---

### Search Console改善

- インデックスエラー修正
- クリック率が低いページのタイトル改善
- 順位が11〜20位のページを優先改善

---

# エンジニア視点で重要なSEO

エンジニアは

コンテンツを書くことだけがSEOではありません。

実際には

- SSR（サーバーサイドレンダリング）
- SSG（静的サイト生成）
- 構造化データ（Schema.org）
- canonicalタグ
- OGP設定
- sitemap.xml自動生成
- robots.txt管理
- ページ速度改善
- Core Web Vitals改善

など、技術的なSEOを担当することが多くあります。

特にNext.jsでは、

SEOに有利な機能が多く用意されており、

開発時にSEOを意識した設計が重要です。

---

# この章のまとめ

- SEOの目的は「検索順位」ではなく「成果（予約・購入・問い合わせ）」を増やすこと
- Googleは「ユーザーに価値を提供するページ」を高く評価する
- SEOは「コンテンツSEO・内部SEO・外部SEO・テクニカルSEO」の4つで構成される
- Search Consoleを活用して順位やクリック率、インデックス状況を確認し、継続的に改善する
- エンジニアは表示速度や構造化データ、SSRなど技術面からSEOに大きく貢献できる
