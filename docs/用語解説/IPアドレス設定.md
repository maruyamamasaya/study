## 概要

**IPアドレス設定**とは、**サーバーにネットワーク上の「住所」を割り当てる作業**です。

人間が家の住所で郵便を受け取るように、サーバーもIPアドレスを持つことで他の機器と通信できます。

例えば、

```
PC
192.168.10.100
```

から

```
Webサーバー
192.168.10.20
```

へ通信できるようになります。

---

# IPアドレス設定の流れ

実際の案件では、OSインストール・ホスト名設定の後に行うことが多いです。

```
① ネットワーク情報を確認
        ↓
② IPアドレスを決める
        ↓
③ IPアドレスを設定
        ↓
④ DNS・ゲートウェイ設定
        ↓
⑤ 通信確認
```

---

# ① ネットワーク情報を確認

まず設計書を確認します。

例えば

|項目|値|
|---|---|
|IPアドレス|192.168.10.20|
|サブネットマスク|255.255.255.0|
|デフォルトゲートウェイ|192.168.10.1|
|DNS|192.168.10.2|

構築作業では、この値をそのまま設定することがほとんどです。

---

# ② IPアドレスを決める

例えば社内ネットワークが

```
192.168.10.xxx
```

なら、

サーバーごとに違うIPを割り当てます。

```
Web01
192.168.10.20

App01
192.168.10.21

DB01
192.168.10.22
```

重複しないように管理します。

---

# ③ IPアドレスを設定

## Windows Server

GUIから設定することが多いです。

```
Server Manager

↓

Network Adapter

↓

IPv4

↓

Manual
```

入力例

```
IP
192.168.10.20

Subnet
255.255.255.0

Gateway
192.168.10.1
```

PowerShellでも設定できます。

---

## Linux

設定ファイルや `nmcli` コマンドを利用します。

設定後に確認

```
ip addr
```

結果

```
192.168.10.20
```

---

# ④ DNS・ゲートウェイ設定

IPだけでは十分ではありません。

### デフォルトゲートウェイ

他のネットワークへ通信するときの出口です。

例

```
Server
192.168.10.20

↓

Gateway

192.168.10.1

↓

Internet
```

---

### DNS

名前からIPアドレスを調べる仕組みです。

例えば

```
www.example.com

↓

192.168.10.50
```

に変換してくれます。

---

# ⑤ 通信確認

設定後は必ず確認します。

IP確認

### Windows

```
ipconfig
```

### Linux

```
ip addr
```

---

Ping確認

```
ping 192.168.10.1
```

成功すると

```
Reply from 192.168.10.1
```

となります。

---

DNS確認

```
nslookup google.com
```

名前解決できればOKです。

---

# IPアドレスを設定する理由

サーバーにIPアドレスがないと

```
PC

×

Webサーバー
```

通信できません。

IPアドレスを設定することで

```
PC

↓

192.168.10.20

↓

Webサーバー
```

という通信が可能になります。

---

# IPアドレスの種類

|種類|説明|例|
|---|---|---|
|固定IP（Static IP）|常に同じIPを使用|192.168.10.20|
|動的IP（DHCP）|自動で割り当てられる|192.168.10.105 → 192.168.10.108|

**サーバーでは固定IPを使うのが一般的**です。IPアドレスが変わると、他のサーバーやアプリケーションが接続できなくなるためです。

---

# ホスト名との違い

|項目|ホスト名|IPアドレス|
|---|---|---|
|役割|サーバーの名前|ネットワーク上の住所|
|例|web01|192.168.10.20|
|人が使う場面|管理・運用|通信・接続|

例えば、

```
ホスト名：web01
IPアドレス：192.168.10.20
```

という組み合わせで管理されます。

---

# 実務でのポイント

実際の構築案件では、IPアドレスは設計書にあらかじめ決められており、エンジニアはその値をサーバーへ設定して通信確認を行います。

設定後は必ず以下を確認します。

- `ipconfig` や `ip addr` でIPが正しいか
- `ping` でゲートウェイや他サーバーへ通信できるか
- `nslookup` や `dig` でDNSが正常に動作するか

この確認まで行って、初めて「IPアドレス設定完了」となります。
