**RDS（Relational Database Service）**とは、

> **AWSが提供する「データベースを簡単に使えるようにしたマネージドサービス」**です。

簡単に言うと、

**「AWSがデータベースの運用を代わりにやってくれるサービス」**です。

---

## データベースとの違い

普通にデータベースを使う場合は、

```
自分でサーバーを用意
      ↓
MySQLをインストール
      ↓
バックアップ設定
      ↓
アップデート
      ↓
障害対応
```

すべて自分で管理する必要があります。

RDSを使うと、

```
AWSでRDSを作成
      ↓
すぐにMySQLが使える
```

となり、面倒な運用をAWSが担当してくれます。

---

## RDSで使えるデータベース

RDSでは、さまざまなデータベースエンジンを選べます。

|データベース|用途|
|---|---|
|MySQL|最もよく使われる|
|PostgreSQL|高機能で人気|
|MariaDB|MySQL互換|
|Oracle Database|大企業向け|
|SQL Server|Microsoft製|
|Amazon Aurora|AWS独自の高速DB|

つまり、**RDSはデータベースそのものではなく、それらを運用するためのサービス**です。

---

## RDSがやってくれること

- データベースの作成
- バックアップ
- 障害時の復旧
- ソフトウェアアップデート
- ストレージ管理
- 監視（CloudWatchなど）

開発者は、**SQLを書いてデータを操作すること**に集中できます。

---

## イメージ

```
アプリ（Next.js）
        │
        │ SQL
        ▼
      RDS
 (MySQL / PostgreSQL)
        │
AWSが運用・管理
```

---

## 実務での使われ方

例えば、レンタサイクル予約システムなら、

RDSには

- ユーザー情報
- 予約情報
- 商品情報
- 決済情報

などを保存します。

アプリからは、

```
SELECT *
FROM reservations
WHERE user_id = 100;
```

のようなSQLを実行してデータを取得します。

---

## RDSのメリット

- サーバー管理が不要
- バックアップが簡単
- 高可用性（障害に強い構成を組みやすい）
- スケールアップ・スケールアウトしやすい
- AWSサービスとの連携が容易

---

## EC2との違い

|EC2|RDS|
|---|---|
|仮想サーバー|データベースサービス|
|自由にソフトを入れられる|DB専用|
|MySQLを自分でインストールする|最初からDBが使える|
|運用も自分で行う|AWSが運用を支援する|

---

## 一言でいうと

**RDS = 「AWSが管理してくれるデータベースサービス」**です。

MySQLやPostgreSQLなどのデータベースを**自分で運用せず、安全・簡単に利用できる**ため、多くのWebサービスで利用されています。
