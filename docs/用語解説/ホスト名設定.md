## 概要

**ホスト名（Hostname）**とは、**サーバーに付ける名前**のことです。

人間でいう「名前」のようなもので、ネットワーク上でサーバーを識別するために使われます。

例えば、会社に100台のサーバーがあるとき、すべて「Server」では区別できません。

そのため、

```
web01
db01
app01
file01
```

のように名前を付けます。

---

# ホスト名設定の流れ

実際の案件では、OSをインストールした後の初期設定で行うことが一般的です。

```
① OSインストール
        ↓
② ホスト名を決める
        ↓
③ ホスト名を設定
        ↓
④ 再起動（必要に応じて）
        ↓
⑤ 設定確認
```

---

# ① OSインストール

Windows ServerやLinuxをインストールします。

例

```
Windows Server 2025

または

Rocky Linux 9
```

---

# ② ホスト名を決める

会社では命名ルール（ルールブック）があることが多いです。

例えば

```
web01
web02
web03
```

Webサーバー

```
db01
db02
```

データベース

```
app01
```

アプリケーションサーバー

---

# 命名例

|サーバー|ホスト名|
|---|---|
|Webサーバー|web01|
|Webサーバー2号機|web02|
|DBサーバー|db01|
|ファイルサーバー|file01|
|バックアップ|backup01|

一目で役割が分かる名前にするのが一般的です。

---

# ③ ホスト名を設定

## Windows Server

GUIで設定することが多いです。

```
Server Manager

↓

Local Server

↓

Computer Name

↓

Change

↓

web01
```

PowerShellでも変更できます。

```
Rename-Computer -NewName "WEB01"
```

---

## Linux

コマンドで設定します。

```
hostnamectl set-hostname web01
```

設定後

```
hostname
```

結果

```
web01
```

---

# ④ 再起動

Windowsでは通常再起動します。

```
Rename

↓

Restart

↓

完了
```

Linuxも環境によっては再起動する場合がありますが、`hostnamectl`では再起動不要なこともあります。

---

# ⑤ 設定確認

Windows

```
hostname
```

Linux

```
hostname
```

結果

```
web01
```

となれば成功です。

# エンジニアが実際に行う作業

例えば構築手順書には次のように書かれています。

```
① ホスト名をWEB01へ変更

② 再起動

③ hostnameコマンドで確認
```

実際の作業時間は数分ですが、**サーバー管理の基本となる重要な設定**です。

---

# ホスト名を設定する理由

例えばログを見ると

```
Error

Server:web01
```

と表示されます。

もし全サーバーが

```
localhost
```

のままだと、

**「どのサーバーでエラーが起きたのか分からない」**

という問題が起きます。

---

# 実務でのポイント

ホスト名は、**監視・ログ・ネットワーク・運用管理など、あらゆる場面で利用される識別情報**です。

そのため、企業では「`web01`」「`db01`」「`app01`」のように役割が分かる命名規則を定め、すべてのサーバーで統一して管理しています。

---

# IPアドレスとの違い

|項目|ホスト名|IPアドレス|
|---|---|---|
|役割|サーバーの名前|ネットワーク上の住所|
|例|`web01`|`192.168.10.20`|
|人にとって|覚えやすい|数字なので覚えにくい|
|用途|管理・識別|通信|

例えば、

```
ホスト名：web01
IPアドレス：192.168.10.20
```

という組み合わせで管理されます。

つまり、**ホスト名は「サーバーの名前」、IPアドレスは「サーバーの住所」**と考えるとイメージしやすいです。
