# 時刻同期とは？

## 概要

**時刻同期（Time Synchronization）**とは、**サーバーの時計を正しい時刻に合わせる設定**です。

サーバーの時刻がずれていると、

- ログの時刻がバラバラになる
- Active Directory認証に失敗する
- SSL証明書エラーになる
- ジョブ（JP1など）が予定どおり動かない

など、さまざまな問題が発生します。

そのため、**企業ではすべてのサーバーで時刻同期を行う**のが一般的です。

---

# 時刻同期の流れ

実際の案件では、OSインストール・ネットワーク設定後に行います。

```
① NTPサーバーを確認
        ↓
② 時刻同期を設定
        ↓
③ 同期開始
        ↓
④ 時刻確認
        ↓
⑤ 動作確認
```

---

# ① NTPサーバーを確認

時刻を合わせる相手（NTPサーバー）を決めます。

例

```
社内NTPサーバー

192.168.10.5
```

または

```
ntp.nict.jp
```

（日本標準時を提供）

企業では通常、**社内NTPサーバー**を利用します。

---

# ② 時刻同期を設定

## Windows Server

GUIまたはPowerShellで設定します。

GUI

```
時刻と言語

↓

インターネット時刻

↓

NTPサーバー指定
```

PowerShell

```
w32tm /config /manualpeerlist:"192.168.10.5" /syncfromflags:manual /update
```

---

## Linux

Rocky Linuxなどでは

```
timedatectl
```

現在の状態確認

```
timedatectl status
```

NTP有効化

```
timedatectl set-ntp true
```

---

# ③ 同期開始

Windows

```
w32tm /resync
```

Linux

```
systemctl restart chronyd
```

または

```
chronyc makestep
```

これで時刻を同期します。

---

# ④ 時刻確認

Windows

```
w32tm /query /status
```

Linux

```
timedatectl
```

結果例

```
Local time

Thu Jul 30 13:00:00 JST

NTP service

active

System clock synchronized

yes
```

---

# ⑤ 動作確認

最後に同期できているか確認します。

Windows

```
w32tm /query /source
```

結果

```
192.168.10.5
```

Linux

```
chronyc sources
```

同期元が表示されれば成功です。

---

# 時刻同期のイメージ

```
NTPサーバー
      │
      │ 正しい時刻
      ▼
──────────────
Web01
App01
DB01
File01
──────────────
```

すべてのサーバーが同じ時刻になります。

---

# 実際の案件例①

## Active Directory

```
DC01

↓

NTPサーバー

↓

各サーバー
```

ドメイン内の全サーバーが同じ時刻になります。

---

# 実際の案件例②

## Webシステム

```
Web01

App01

DB01
```

ログを確認すると

```
13:00:01

13:00:02

13:00:03
```

時系列が正しく並びます。

---

# 実際の案件例③

## JP1ジョブ

```
23:00

↓

バックアップ開始
```

時刻がずれていると

```
22:57

↓

開始
```

のような問題が起きる可能性があります。

---

# エンジニアが実際に行う作業

構築手順書には例えば

```
NTP

192.168.10.5

↓

同期設定

↓

同期確認
```

と書かれています。

設定後

```
timedatectl

↓

chronyc sources
```

または

```
w32tm /query /status
```

で確認します。

---

# 時刻同期をしないとどうなる？

例えば

```
Webサーバー

13:00
```

```
DBサーバー

12:55
```

となっていると

ログは

```
13:00

↓

12:55

↓

13:01
```

となり、

**「どの順番で問題が起きたのか」が分からなくなります。**

---

# 実務でのポイント

時刻同期は、**システム全体の時刻を揃えるための基本設定**です。

特に以下のようなシステムでは必須です。

- Active Directory
- Oracle・SQL Server・PostgreSQL
- Webサーバー
- JP1・Zabbixなどの監視ツール
- SSL/TLS証明書を利用するシステム

そのため、構築時には

- NTPサーバーが正しく設定されているか
- 同期が有効になっているか
- 実際に時刻が一致しているか

を確認して「時刻同期完了」とします。

# WindowsとLinuxの比較

|項目|Windows Server|Linux|
|---|---|---|
|時刻同期サービス|Windows Time（W32Time）|Chrony / NTP|
|状態確認|`w32tm /query /status`|`timedatectl status`|
|手動同期|`w32tm /resync`|`chronyc makestep`|
|用途|Active Directory、Windowsサーバー|Webサーバー、DBサーバー、クラウド環境|
