マーケティングファネルとは、**「お客様が商品やサービスを知ってから購入・利用するまでの流れ」を漏斗（ファネル）の形で表した考え方**です。

```
      認知
       ↓
      興味
       ↓
      比較・検討
       ↓
      購入・申込み
       ↓
   リピート・ファン化
```

上に行くほど人数が多く、下に行くほど人数が少なくなるため、漏斗（ファネル）の形になります。

例えば、レンタサイクルサービスなら、

|段階|ユーザーの行動|施策例|
|---|---|---|
|認知|「こんなサービスあるんだ」|SEO、Google広告、SNS、MEO|
|興味|「便利そう」|サイトを見る、料金を見る|
|比較・検討|「他社と比べよう」|レビュー、料金比較、FAQ|
|購入|「予約しよう」|予約フォーム、クーポン|
|ファン化|「また使おう」|メール配信、LINE、ポイント|

### なぜ重要？

ファネルを見ることで、

- 認知が少ない → 広告やSEOを強化する
- 興味はあるが申し込みが少ない → サイト改善（LPO）
- 一度利用した人が戻らない → LINEやメールで再利用を促す

というように、**どこでユーザーが離脱しているか**を分析できます。

### 一言でいうと

**マーケティングファネル =「お客様が認知から購入・ファンになるまでの流れを可視化したもの」**です。

Webマーケティングでは、この各段階に合わせてSEO・広告・SNS・GA4分析・CVR改善などの施策を考えていきます。
