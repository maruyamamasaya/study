# 保育園見学チェックリスト
## 🏠 基本情報

- [ ] 自宅から通いやすい
- [ ] 職場への動線が良い
- [ ] 開園時間・延長保育が勤務時間に合っている
- [ ] 希望する月齢から入園できる

---

## 👶 子どもの様子（最重要）

- [ ] 子どもたちが笑顔で過ごしている
- [ ] のびのび遊んでいる
- [ ] 子ども同士の雰囲気が良い
- [ ] 泣いている子への対応が丁寧
- [ ] 子どもの話をきちんと聞いている
- [ ] 子どもの自主性を尊重している

---

## 👩‍🏫 保育士

- [ ] 優しい言葉遣い
- [ ] 子どもの目線で話している
- [ ] 笑顔で接している
- [ ] 怒鳴ったり乱暴な対応がない
- [ ] 保育士同士の雰囲気が良い

**確認したいこと**

- 担任は全員常勤か
- 保育士は有資格者か
- 看護師は常勤か
- ベテラン保育士はいるか

---

## 🧸 保育内容

- [ ] 外遊びを十分行っている
- [ ] 室内遊びが充実している
- [ ] 絵本やおもちゃが充実している
- [ ] 子どもが自由に遊べる環境になっている

**確認したいこと**

- 保育で大切にしていること
- 一日の流れ
- 雨の日の過ごし方
- 散歩はどのくらい行くか

---

## 🍙 給食・食育

- [ ] 献立表を見せてもらった
- [ ] 食事がおいしそう
- [ ] 食育に力を入れている

**確認したいこと**

- 離乳食の進め方
- アレルギー対応
- 食材へのこだわり

---

## 🏢 施設・設備

- [ ] 園内が清潔
- [ ] 保育室が広い
- [ ] 日当たり・換気が良い
- [ ] お昼寝スペースが確保されている
- [ ] トイレ・シャワー設備がきれい

---

## 👶 0・1歳児の環境

- [ ] 乳児室が分かれている
- [ ] ハイハイできるスペースがある
- [ ] ベビーベッドが安全

**確認したいこと**

- 授乳スペース
- SIDS（乳幼児突然死症候群）対策
- 午睡チェックの方法
- 呼吸確認の頻度

---

## 🛡️ 安全対策

- [ ] 指はさみ防止
- [ ] 家具が固定されている
- [ ] 危険物が手の届かない場所にある
- [ ] 消毒用品がある
- [ ] 避難訓練を実施している
- [ ] 防犯対策がある

---

## 🌳 園庭・外遊び

- [ ] 園庭がある
- [ ] 遊具が安全
- [ ] 砂場がある
- [ ] 水遊びができる
- [ ] 毎日外遊びをしている

## 👨‍👩‍👧 保護者との連携

- [ ] 保護者面談がある
- [ ] 園だよりがある
