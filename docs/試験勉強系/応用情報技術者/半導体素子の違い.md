
| 種類                | 主な役割         | 覚え方     |
| ----------------- | ------------ | ------- |
| MOSトランジスタ（MOSFET） | 電流のON/OFF・増幅 | 電気のスイッチ |
| フォトダイオード          | 光を電気信号に変換    | 光 → 電気  |
| ツェナーダイオード         | 電圧を一定に保つ     | 電圧の安定化  |
| 発光ダイオード（LED）      | 電気を光に変換      | 電気 → 光  |

## MOSトランジスタ（MOSFET）
- 電圧によって電流を制御する半導体
- **スイッチング（ON/OFF）や増幅**に使われる
- CPUやメモリなどのデジタル回路で大量に使用される

**覚え方：電気のスイッチ**

---

## フォトダイオード
- **光を受けると電気信号を発生**させる
- 光センサーや光通信の受信などに使われる

**光 → 電気**

---

## ツェナーダイオード
- 一定以上の逆方向電圧で電流を流す
- **電圧を一定に保つ（定電圧化）**ために使われる

**覚え方：電圧を安定させる**

---

## 発光ダイオード（LED）
- 電流を流すと**光を発する**
- 照明、ディスプレイ、表示ランプなどに使われる

**電気 → 光**

---

## 試験向けの覚え方

- **MOSFET** → スイッチ
- **フォトダイオード** → 光を受ける
- **ツェナーダイオード** → 電圧を安定
- **LED** → 光を出す

特に、

**フォトダイオード：光 → 電気**  
**LED：電気 → 光**

は逆の関係として覚える。
