## PMBOKでは、脅威となるリスクへの代表的な対応として、

* 回避
* 転嫁
* 軽減
* 受容

がある。

---

# 1. 回避

**リスクの原因そのものをなくす。**

## 例

新技術を使うと障害リスクが高いので、
**その技術の採用自体をやめる。**

```text
危険な方法
  ↓
使わない
  ↓
リスクをなくす
```

> **回避 = やらない・避ける**

---

# 2. 転嫁

**リスクによる損失や責任を第三者へ移す。**

## 例

* 保険に加入する
* 一部作業を専門業者へ委託する

```text
自社で負うリスク
   ↓
保険会社・外部業者へ
```

ただし、**リスクそのものが消えるわけではない**。

> **転嫁 = 他者に負担してもらう**

---

# 3. 軽減

**リスクの発生確率や影響を小さくする。**

## 例

サーバ障害に備えて、

* 冗長化する
* バックアップを取得する
* 事前テストを増やす

```text
リスク
 ↓
対策する
 ↓
発生確率・影響を小さくする
```

> **軽減 = 起きにくくする・被害を小さくする**

---

# 4. 受容

**リスクがあることを認識した上で、あえて受け入れる。**

## 例

発生確率が非常に低く、
対策費用の方が高いため、特別な対策を行わない。

```text
リスクあり
 ↓
でも対策コストが高い
 ↓
受け入れる
```

必要に応じて、発生時の対応費用などを準備することもある。

> **受容 = 分かった上で受け入れる**

---

# 試験用まとめ

| 対応 | 意味          | 例           |
| -- | ----------- | ----------- |
| 回避 | リスク原因をなくす   | 危険な方式を採用しない |
| 転嫁 | 第三者へ負担を移す   | 保険、外部委託     |
| 軽減 | 発生確率・影響を下げる | 冗長化、バックアップ  |
| 受容 | リスクを受け入れる   | あえて対策しない    |

---

# 見分け方

```text
「その方法をやめる」
→ 回避

「保険・外部委託」
→ 転嫁

「発生確率や被害を小さくする」
→ 軽減

「対策せず受け入れる」
→ 受容
```

## 一言で覚える

**回避 = やめる
転嫁 = 渡す
軽減 = 小さくする
受容 = 受け入れる**
