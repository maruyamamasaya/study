## ファウンドリ・ファブレス・デザインハウス・IPプロバイダー

半導体は、**「設計する会社」「設計を支援する会社」「設計部品を提供する会社」「製造する会社」**のように分業されています。

## 1. 全体像

```text
IPプロバイダー
   ↓ 設計部品（IP）を提供

ファブレスメーカー
   ↓ 半導体を企画・設計
   │
   ├── デザインハウス
   │      設計作業を支援・受託
   ↓
ファウンドリ
   ↓ 半導体を製造
完成した半導体
```

覚え方は、

> **IPを部品として使い、ファブレスが設計し、デザインハウスが設計を手伝い、ファウンドリが製造する。**

---

## 2. それぞれの違い

| 種類            | 主な仕事         | 工場     | イメージ     |
| ------------- | ------------ | ------ | -------- |
| **ファウンドリ**    | 半導体の製造       | ○ 持つ   | 製造工場     |
| **ファブレスメーカー** | 半導体の企画・設計・販売 | × 持たない | 製品メーカー   |
| **デザインハウス**   | 半導体設計を受託・支援  | ×      | 設計代行会社   |
| **IPプロバイダー**  | 半導体設計用のIPを提供 | ×      | 設計部品メーカー |

### ファウンドリ（Foundry）

**半導体を実際に製造する会社。**

ファブレスメーカーなどから設計データを受け取り、半導体工場でチップを製造します。

```text
設計データ
   ↓
ファウンドリ
   ↓
半導体チップ
```

代表例：TSMCなど。

**ポイント：設計より「製造」が中心。**

---

### ファブレスメーカー（Fabless）

**自社工場（Fab）を持たず、半導体の企画・設計をするメーカー。**

```text
ファブレス
  ↓ 設計
ファウンドリ
  ↓ 製造
半導体
```

代表例：NVIDIA、Qualcommなど。

「Fab（工場）がLess（ない）」と覚えると分かりやすいです。

**ポイント：工場を持たない半導体メーカー。**

---

### デザインハウス（Design House）

**半導体の設計作業を専門的に請け負う会社。**

ファブレスメーカーなどに対して、

* 回路設計
* 論理設計
* レイアウト設計
* 設計検証

などを支援します。

```text
ファブレス
   ↓ 設計を依頼
デザインハウス
   ↓ 設計支援
ファウンドリ
```

**ポイント：「設計そのものを請け負う会社」。**

---

### IPプロバイダー（IP Provider）

ここでいうIPは、**Intellectual Property（知的財産）**です。

半導体設計で再利用できる**設計済みの回路・機能**を提供します。

例えば、

```text
CPUコア
GPU関連回路
メモリ制御回路
通信インターフェース
      ↓
これらの設計IPを提供
```

ARMのCPUコアなどが代表的なイメージです。

ファブレスメーカーは全部をゼロから設計するのではなく、

```text
自社設計
 ＋
購入・ライセンスしたIP
 ↓
SoCなどを設計
```

という方法を取れます。

**ポイント：「設計する」のではなく「再利用できる設計部品を提供する」。**

---

# 3. 応用情報で見られそうな観点

応用情報技術者試験では、会社名を覚えるよりも**「誰が何を担当するのか」**を判断できることが重要です。

### 「工場を持たずに半導体を設計する」

→ **ファブレスメーカー**

### 「他社が設計した半導体を製造する」

→ **ファウンドリ**

### 「半導体の設計業務を受託する」

→ **デザインハウス**

### 「CPUコアなどの設計資産をライセンス提供する」

→ **IPプロバイダー**

---

## 4. 特に間違えやすいところ

### ファブレス vs ファウンドリ

```text
ファブレス ＝ 設計する・工場なし
ファウンドリ ＝ 製造する・工場あり
```

この2つは**セット**で覚えると簡単です。

### ファブレス vs デザインハウス

両方とも設計に関わりますが、立場が違います。

```text
ファブレス
「自社の商品として半導体を企画・設計する」

デザインハウス
「他社から依頼されて設計を手伝う」
```

### デザインハウス vs IPプロバイダー

```text
デザインハウス
→ 設計という「作業・サービス」を提供

IPプロバイダー
→ 再利用可能な「設計部品」を提供
```

---

# 5. 試験用の最短暗記

```text
ファウンドリ
＝ 製造する

ファブレス
＝ 工場を持たず設計する

デザインハウス
＝ 設計を請け負う

IPプロバイダー
＝ 設計部品（IP）を提供する
```

### 一言で覚えるなら

**「IPを買う → 設計する → 設計を支援する → 工場で作る」**

| キーワード      | 答え       |
| ---------- | -------- |
| 製造受託       | ファウンドリ   |
| 工場を持たない    | ファブレス    |
| 設計受託       | デザインハウス  |
| 設計資産・ライセンス | IPプロバイダー |

応用情報では特に、**「ファブレス＝工場なし」「ファウンドリ＝製造受託」**の対比を押さえておけば得点しやすい分野です。
