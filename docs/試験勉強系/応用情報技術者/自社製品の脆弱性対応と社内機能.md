## PSIRT

**PSIRT（Product Security Incident Response Team）**

自社が開発・提供する**製品やサービスのセキュリティ・脆弱性に対応する組織**。

### 主な役割

- 自社製品の脆弱性情報を収集する
- 報告された脆弱性を調査する
- 脆弱性の影響範囲や深刻度を評価する
- 開発部門と修正方法を検討する
- パッチやアップデートの提供を調整する
- 顧客・利用者への脆弱性情報を公開する
- 外部のセキュリティ機関との調整を行う

---

## CSIRTとの違い

### CSIRT

**Computer Security Incident Response Team**

企業・組織内で発生する**セキュリティインシデントに対応する組織**。

例：

- 社内PCのマルウェア感染
- 不正アクセス
- 情報漏えい
- サーバへの攻撃
- フィッシング被害

### PSIRT

**Product Security Incident Response Team**

自社が提供している**製品・サービスの脆弱性に対応する組織**。

例：

- 自社アプリに脆弱性が発見された
- 自社製品にSQLインジェクションの問題が見つかった
- 自社製品のライブラリに重大な脆弱性が発見された

---

## CSIRTとPSIRTの覚え方

| 組織 | 主な対象 | 覚え方 |
|---|---|---|
| **CSIRT** | 自社・組織のセキュリティ事故 | 「会社を守る」 |
| **PSIRT** | 自社製品・サービスの脆弱性 | 「製品を守る」 |

### 試験対策

**社内でセキュリティ事故が発生**
→ **CSIRT**

**自社製品に脆弱性が発見**
→ **PSIRT**

「Product」という単語が入っているので、

**製品（Product）の脆弱性 → PSIRT**

と覚えると分かりやすい。
