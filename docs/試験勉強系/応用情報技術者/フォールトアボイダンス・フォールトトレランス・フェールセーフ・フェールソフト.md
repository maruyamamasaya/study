応用情報では、**「故障をどう扱うか」**で区別すると覚えやすい。

## 1. まずは4つを一言で

| 用語              | 意味              | 覚え方        |
| --------------- | --------------- | ---------- |
| **フォールトアボイダンス** | 故障を起こさない        | **避ける**    |
| **フォールトトレランス**  | 故障しても動かす        | **耐える**    |
| **フェールセーフ**     | 故障したら安全側へ       | **安全**     |
| **フェールソフト**     | 故障したら性能を落として動かす | **弱くして継続** |

```text
アボイダンス → 故障させない
トレランス   → 故障しても動く
セーフ       → 故障したら安全にする
ソフト       → 故障したら弱くして動く
```

---

# 2. フォールトアボイダンス

## 「そもそも故障させない」

**Avoidance = 避ける**

故障そのものを発生しにくくする考え方。

### 例

* 高品質な部品を使用する
* 十分なテストを行う
* 品質管理を徹底する
* 信頼性の高い設計をする

```text
高品質な部品・十分なテスト
          ↓
      故障を防ぐ
```

### 試験キーワード

> **高品質・高信頼性・故障を未然に防止**

---

# 3. フォールトトレランス

## 「故障しても動かす」

**Tolerance = 耐える**

一部が故障しても、システム全体としては処理を継続する考え方。

### 例

サーバを冗長化する。

```text
サーバA → 故障 ×
サーバB → 稼働 ○
             ↓
      サービス継続
```

RAIDやサーバの冗長化などが代表例。

### 試験キーワード

> **冗長化・予備系・故障しても継続**

---

# 4. フェールセーフ

## 「故障したら安全側へ」

**Safe = 安全**

故障した場合、サービス継続よりも**安全を優先する**。

### 例

```text
機械で異常発生
      ↓
   機械を停止
      ↓
 人間の安全を確保
```

信号機なども代表例。

### 試験キーワード

> **安全側・停止・事故防止**

### ポイント

**「止めること」が目的ではなく「安全な状態にすること」が目的。**

---

# 5. フェールソフト

## 「故障したら弱くして動かす」

故障時に全部停止するのではなく、**機能や性能を低下させて運転を継続する**。

これを**縮退運転**という。

### 例

```text
通常
■■■■■■■■■■
10台で稼働

↓ 2台故障

■■■■■■■■□□
8台で稼働

↓
性能は低下するがサービス継続
```

### 試験キーワード

> **縮退運転・機能低下・性能低下・最低限のサービス継続**

---

# 6. 一番間違えやすいところ

## フォールトトレランス vs フェールソフト

### フォールトトレランス

```text
故障
 ↓
予備系などでカバー
 ↓
サービスを継続
```

**故障に「耐える」ことがポイント。**

### フェールソフト

```text
故障
 ↓
一部機能・性能を諦める
 ↓
縮退してサービス継続
```

**性能を「落として」継続することがポイント。**

> **トレランス = 耐えて動く**
> **ソフト = 弱くなって動く**

---

# 7. 応用情報での見分け方

| 問題文のキーワード    | 答え              |
| ------------ | --------------- |
| 高品質な部品を使用    | **フォールトアボイダンス** |
| 故障を未然に防ぐ     | **フォールトアボイダンス** |
| 冗長化する        | **フォールトトレランス**  |
| 一部が故障しても処理継続 | **フォールトトレランス**  |
| 安全な状態に移行     | **フェールセーフ**     |
| 異常時に安全側へ制御   | **フェールセーフ**     |
| 機能を限定して運転    | **フェールソフト**     |
| 性能を低下させて継続   | **フェールソフト**     |
| 縮退運転         | **フェールソフト**     |

---

# 8. 最短暗記

```text
アボイダンス（Avoidance）
→ 避ける
→ 故障させない

トレランス（Tolerance）
→ 耐える
→ 故障しても動く

セーフ（Safe）
→ 安全
→ 故障したら安全側へ

ソフト（Soft）
→ 弱くする
→ 性能を落として動く
```

## 試験直前はこれだけ

> **アボイダンス = 故障させない**
> **トレランス = 故障しても動く**
> **セーフ = 故障したら安全**
> **ソフト = 故障したら縮退**

特に応用情報では、**「縮退運転 → フェールソフト」「高品質な部品 → フォールトアボイダンス」**を即答できるようにしておく。
