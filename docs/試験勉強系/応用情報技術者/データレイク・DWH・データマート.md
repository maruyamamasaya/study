## 全体像

企業では、様々なシステムから集めたデータを分析に利用する。

```text id="cnysj7"
業務システム
POS
Webログ
SNS
センサー
CSV
   ↓
【データレイク】
 生データを大量保存
   ↓
【DWH】
 分析しやすく整理・統合
   ↓
【データマート】
 部門・目的ごとに抽出
   ↓
 BI・OLAP・レポート
```

※実際のシステム構成は様々で、必ずこの順番になるとは限らない。

---

# データレイク

**様々な形式のデータを、加工前の状態に近い形で大量に保存する場所。**

## 保存するデータ

* CSV
* JSON
* 画像
* 動画
* ログ
* センサーデータ
* テキスト

など、**構造化・半構造化・非構造化データ**を扱える。

### 特徴

* 生データを保存
* 様々な形式を扱える
* 大量データの蓄積に向いている
* 将来どのように利用するか決まっていないデータも保存できる

### 覚え方

> **データレイク = とりあえず大量のデータをためる「湖」**

```text id="16fn27"
画像 ─┐
ログ ─┤
CSV  ─┼→ データレイク
JSON ─┤
動画 ─┘
```

---

# データウェアハウス（DWH）

**企業内の様々なシステムからデータを集め、分析しやすい形に整理・統合して蓄積する仕組み。**

DWH = **Data Warehouse**

## 例

```text id="cx68h7"
販売システム ─┐
顧客システム ─┼→ DWH
在庫システム ─┘
```

企業全体のデータを統合して、

* 売上分析
* 顧客分析
* 経営分析
* 意思決定

などに利用する。

### 特徴

* 複数システムのデータを統合
* 分析しやすい形に整理
* 長期間のデータを蓄積
* BIやOLAPなどで利用

### 覚え方

> **DWH = 分析用に整理された企業全体のデータ倉庫**

---

# データマート

DWHなどから、**特定の部門や目的に必要なデータだけを取り出したもの**。

## 例

```text id="ym9dx5"
             DWH
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
営業用      経理用      人事用
データ      データ      データ
マート      マート      マート
```

### 例

営業部なら、

```text id="j9uub2"
顧客
商品
売上
契約
```

など、営業分析に必要なデータだけを利用する。

### 特徴

* 特定部門・目的向け
* DWHより対象範囲が小さい
* 必要なデータに絞って分析しやすい

### 覚え方

> **データマート = 部門・目的別の小さなデータ売り場**

---

# 3つの違い

| 項目   | データレイク  | DWH         | データマート    |
| ---- | ------- | ----------- | --------- |
| データ  | 生データ中心  | 整理・統合されたデータ | 必要なデータ    |
| 対象   | 幅広い     | 企業全体        | 部門・目的別    |
| 形式   | 様々      | 分析しやすく構造化   | 分析目的に合わせる |
| 用途   | 保存・将来利用 | 全社的な分析      | 特定目的の分析   |
| イメージ | 湖       | 倉庫          | 売り場       |

## 一言で

```text id="kj6wgh"
データレイク
→ 生データをためる

DWH
→ 分析用に整理・統合する

データマート
→ 部門・目的ごとに取り出す
```

---

# ETL

**ETL**は、様々なシステムからデータを取り出して加工し、DWHなどへ格納する処理。

```text id="a3swu7"
Extract
↓
Transform
↓
Load
```

## Extract

**抽出**

業務システムなどからデータを取り出す。

## Transform

**変換・加工**

データ形式を統一したり、不要データを除去したりする。

## Load

**格納**

加工したデータをDWHなどへ格納する。

### 覚え方

```text id="2hw23b"
ETL

E = Extract   → 取り出す
T = Transform → 加工する
L = Load      → 入れる
```

---

# ELT

ETLと似た言葉として**ELT**もある。

```text id="hffb3q"
Extract
↓
Load
↓
Transform
```

先にデータを保存して、その後で加工する。

```text id="x6o0nh"
ETL
→ 加工してから格納

ELT
→ 格納してから加工
```

クラウド型のデータ基盤などで利用される。

---

# OLAP

**OLAP（Online Analytical Processing）**

蓄積されたデータを、様々な角度から分析する仕組み。

例えば売上を、

```text id="q8a2bk"
商品別
地域別
年月別
店舗別
```

など複数の視点から分析する。

### 覚え方

> **OLAP = データを多角的に分析する**

---

# OLTPとの違い

**OLTP（Online Transaction Processing）**は、日常業務のトランザクション処理。

例えば、

* 商品購入
* 銀行振込
* 予約登録
* 在庫更新

など。

|    | OLTP    | OLAP  |
| -- | ------- | ----- |
| 目的 | 日常業務    | 分析    |
| 処理 | 登録・更新など | 集計・分析 |
| 例  | 注文処理    | 売上分析  |

```text id="qf5uhd"
OLTP → 業務を処理する

OLAP → データを分析する
```

# BI

**BI（Business Intelligence）**

企業に蓄積されたデータを分析・可視化して、経営や業務上の意思決定に活用する考え方・仕組み。

```text id="7zvfs9"
DWH
 ↓
BIツール
 ↓
グラフ
ダッシュボード
レポート
 ↓
意思決定
```

### 覚え方

> **BI = データを見える化して意思決定に使う**

---

# 試験用まとめ

| 用語     | 覚え方              |
| ------ | ---------------- |
| データレイク | 生データを大量保存        |
| DWH    | 全社データを分析用に整理・統合  |
| データマート | 部門・目的別にデータを用意    |
| ETL    | 抽出 → 加工 → 格納     |
| ELT    | 抽出 → 格納 → 加工     |
| OLAP   | 多角的なデータ分析        |
| OLTP   | 日常業務のトランザクション処理  |
| BI     | データを分析・可視化して意思決定 |
