## 基本

**モジュール結合度**とは、モジュール同士が**どれくらい強く依存しているか**を表すもの。

> **結合度は弱いほど良い。**

結合度が弱いと、一方を変更しても他のモジュールへの影響が少なくなる。

---

# 結合度の順番

**弱い（良い） → 強い（悪い）**

```text
データ結合
   ↓
スタンプ結合
   ↓
制御結合
   ↓
外部結合
   ↓
共通結合
   ↓
内容結合

良い ←────────→ 悪い
```

覚える順番：

> **デ・ス・制・外・共・内**

---

## ① データ結合【最も弱い】

必要な**データだけ**を引数として渡す。

```text
モジュールA
   ↓
「金額 = 1000」
   ↓
モジュールB
```

### ポイント

> **必要なデータだけ渡す**

最も望ましい結合。

---

## ② スタンプ結合

**データ構造全体**を渡す。

```text
ユーザー情報
├─ 名前
├─ 年齢
├─ 住所
└─ 電話番号
      ↓
モジュールB
```

モジュールBが「名前」しか使わなくても、ユーザー情報全体を渡している。

> **構造体・レコードなどを丸ごと渡す**

---

## ③ 制御結合

相手の動作を決める**制御情報**を渡す。

```text
処理モード = 1
      ↓
モジュールB

1なら登録
2なら削除
```

> **フラグなどで相手の処理を制御**

---

## ④ 外部結合

複数のモジュールが、外部で決められた**データ形式やインターフェース**などを共有する。

```text
モジュールA ─┐
             ├→ 外部データ形式
モジュールB ─┘
```

### キーワード

> **外部仕様・外部データ形式・外部インターフェース**

---

## ⑤ 共通結合

複数のモジュールが**共通のデータ領域**を利用する。

代表例は**グローバル変数**。

```text
        グローバル変数
          ↑       ↑
          │       │
モジュールA     モジュールB
```

一方が変更すると、もう一方にも影響する可能性がある。

> **グローバル変数・共通領域**

---

## ⑥ 内容結合【最も強い】

あるモジュールが、別のモジュールの**内部を直接操作する**。

```text
モジュールA
     ↓
モジュールBの内部データを
直接変更
```

最も依存関係が強く、望ましくない。

> **他モジュールの内部を直接触る**

---

# 応用情報での見分け方

| 問題文            | 結合         |
| -------------- | ---------- |
| 必要なデータだけ渡す     | **データ結合**  |
| 構造体・レコードを丸ごと渡す | **スタンプ結合** |
| フラグで処理方法を指定    | **制御結合**   |
| 外部のデータ形式などを共有  | **外部結合**   |
| グローバル変数を共有     | **共通結合**   |
| 他モジュールの内部を直接操作 | **内容結合**   |

---

# 最短暗記

```text
弱い・良い
   ↓
データ    → 必要データだけ
スタンプ  → 構造体丸ごと
制御      → フラグで指示
外部      → 外部仕様を共有
共通      → グローバル変数
内容      → 内部を直接触る
   ↓
強い・悪い
```

## 試験直前

> **デ → ス → 制 → 外 → 共 → 内**

**「結合度は弱いほど良い」**とセットで覚える。
