# ソフトウェア保守の種類

ソフトウェア保守は、目的によって主に4種類に分類される。

| 種類    | 目的             | 例                    |
| ----- | -------------- | -------------------- |
| 是正保守  | **不具合を直す**     | バグ修正、障害対応            |
| 適応保守  | **環境変化に合わせる**  | OS変更、法改正、DB変更        |
| 完全化保守 | **機能や性能を良くする** | 機能追加、操作性改善、性能向上      |
| 予防保守  | **将来の障害を防ぐ**   | コード整理、老朽化対応、リファクタリング |

---

# 是正保守

発見された**不具合や障害を修正する保守**。

## 例

* バグ修正
* 計算結果の誤りを修正
* システム停止の原因を修正

```text
問題が起きた
↓
直す
↓
是正保守
```

> **覚え方：悪いところを是正する**

---

# 適応保守

ソフトウェアを、**外部環境の変化に適応させる保守**。

## 例

* OSのバージョンアップ対応
* 法律・制度変更への対応
* データベース変更
* ハードウェア変更への対応

```text
周囲の環境が変わった
↓
システムも合わせる
↓
適応保守
```

> **覚え方：環境に適応する**

---

# 完全化保守

利用者の要求などに応じて、**機能・性能・使いやすさを改善する保守**。

## 例

* 新機能を追加
* 画面を使いやすくする
* 処理速度を改善
* 検索機能を強化

```text
今でも動く
↓
もっと良くする
↓
完全化保守
```

> **覚え方：より完全なシステムに近づける**

---

# 予防保守

将来発生する可能性がある障害や問題を、**事前に防止するための保守**。

## 例

* 複雑なプログラムを整理
* 古いコードを修正
* 保守しにくい部分をリファクタリング
* 将来障害になりそうな箇所を改善

```text
今は問題ない
↓
将来問題になりそう
↓
先に直す
↓
予防保守
```

> **覚え方：問題が起きる前に予防する**

---

# 試験用まとめ

```text
是正保守
→ 起きた問題を直す

適応保守
→ 環境の変化に合わせる

完全化保守
→ 機能・性能を良くする

予防保守
→ 将来の問題を防ぐ
```

## 見分け方

```text
バグ・障害
→ 是正

OS・法改正・環境変更
→ 適応

機能追加・性能改善
→ 完全化

将来の障害防止・コード整理
→ 予防
```

## 一言で覚える

**是正＝直す
適応＝合わせる
完全化＝良くする
予防＝防ぐ**
