## 全体の違い

| 技法             | 何をする？       | キーワード    |
| -------------- | ----------- | -------- |
| **メタボール**      | 滑らかな形状を作る   | 球・融合・有機的 |
| **レイトレーシング**   | 光線を追跡して描画   | 反射・屈折・影  |
| **ラジオシティ法**    | 面同士の光の反射を計算 | 間接光・拡散反射 |
| **テクスチャマッピング** | 物体表面に画像を貼る  | 模様・質感    |

---

# 1. メタボール

**複数の球などを近づけたとき、互いに融合したような滑らかな形状を作る技法。**

例えば、

```text
○     ○

近づける
   ↓

○～～～○

さらに近づける
   ↓

 （   ）
（     ）
 （   ）
```

のように、物体同士が滑らかにつながる。

## 用途

* 液体
* 水滴
* 生物
* 粘土
* 有機的な形状

などの表現に向いている。

> **メタボール = 球などを滑らかに融合して形を作る**

---

# 2. レイトレーシング

**Ray Tracing（光線追跡法）**

視点から光線（レイ）を飛ばし、物体に当たった後の**反射・屈折・影などを計算して描画する方法**。

```text
カメラ・視点
     ↓
   光線
     ↓
   物体
    ／
   ／ 反射
  ↓
別の物体
```

例えば鏡なら、

```text
視点
 ↓
鏡
 ↓
反射
 ↓
別の物体
```

という光の経路を計算する。

## 得意な表現

* 鏡の反射
* ガラスの屈折
* 光沢
* 影
* 金属

> **レイトレーシング = 光線を追いかける**

---

# 3. ラジオシティ法

物体の**面と面の間で光がどのように反射するか**を計算する方法。

特に、拡散反射による**間接光**の表現が得意。

例えば、

```text
       光源
        ↓
   ┌─────────┐
   │         │
   │  壁 →→ 床
   │      光が反射
   │         │
   └─────────┘
```

光源から直接照らされていない場所でも、

```text
光源
 ↓
白い壁
 ↓
光が反射
 ↓
床を照らす
```

という光の回り込みを表現できる。

## 得意な表現

* 室内照明
* 柔らかい光
* 間接照明
* 壁や床からの反射光

> **ラジオシティ = 面から面へ反射する光を計算**

---

# レイトレーシングとラジオシティの違い

ここが試験では重要。

### レイトレーシング

```text
視点
 ↓
光線
 ↓
物体
 ↓
反射・屈折
```

→ **光線を追跡**

特に鏡面反射や屈折などの表現が得意。

### ラジオシティ

```text
光源
 ↓
壁
 ↓
床
 ↓
別の壁
```

→ **面同士の光エネルギーのやり取り**

拡散反射・間接光の表現が得意。

|      | レイトレーシング | ラジオシティ   |
| ---- | -------- | -------- |
| 基本   | 光線を追跡    | 面間の光を計算  |
| 得意   | 反射・屈折・影  | 拡散反射・間接光 |
| イメージ | 鏡・ガラス    | 室内照明     |

# 4. テクスチャマッピング

3Dモデルの表面に**画像・模様を貼り付ける技法**。

例えば、何もない球体に、

```text
白い球

  ○

 ↓ 地球の画像を貼る

 🌎
```

というように画像を貼り付ける。

3Dモデル自体を細かく作り込まなくても、表面に画像を貼ることでリアルに見せられる。

## 例

```text
3Dの壁
  ＋
レンガの画像

  ↓

レンガの壁に見える
```

## 用途

* 木目
* レンガ
* 地面
* キャラクターの服
* 顔
* 地球表面

など。

> **テクスチャマッピング = 3Dモデルの表面に画像を貼る**

---

# 4つを分類すると

## 形状を作る

```text
メタボール
→ 滑らかな形状を生成
```

## 光を計算する

```text
レイトレーシング
→ 光線・反射・屈折

ラジオシティ
→ 面同士・拡散反射・間接光
```

## 表面を表現する

```text
テクスチャマッピング
→ 画像・模様を貼る
```

# 試験での見分け方

```text
「球体を融合」
「滑らかな形状」
「液体のような形」

→ メタボール
```

```text
「光線を追跡」
「鏡面反射」
「屈折」

→ レイトレーシング
```

```text
「面と面」
「拡散反射」
「間接光」

→ ラジオシティ法
```

```text
「物体表面に画像」
「模様を貼り付ける」

→ テクスチャマッピング
```

| -------------- | ----------- |
