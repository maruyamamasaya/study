## 大きな分類

暗号方式は主に次の2種類。

| 種類      | 特徴                | 代表例          |
| ------- | ----------------- | ------------ |
| 共通鍵暗号方式 | 暗号化と復号に**同じ鍵**を使う | AES、DES、3DES |
| 公開鍵暗号方式 | **公開鍵と秘密鍵**の2つを使う | RSA、ECC      |

---

# 共通鍵暗号方式

## AES

**AES（Advanced Encryption Standard）**

現在広く利用されている代表的な**共通鍵暗号方式**。

* 暗号化と復号に同じ鍵を使用
* DESより安全性が高い
* 処理が高速
* 鍵長：128 / 192 / 256 bit
* ブロック暗号

```text
AES
→ 共通鍵
→ 高速
→ 現在の代表的な暗号方式
```

---

## DES

**DES（Data Encryption Standard）**

古い共通鍵暗号方式。

* 共通鍵暗号方式
* ブロック暗号
* 実質的な鍵長は56bit
* 現在では鍵長が短く、安全性が不足

```text
DES
→ 共通鍵
→ 56bit
→ 古くて安全性が低い
```

---

## 3DES

**Triple DES**

DESを複数回適用することで安全性を高めた方式。

* 共通鍵暗号方式
* DESより安全
* AESより処理効率が悪い
* 現在はAESへの移行が進んでいる

```text
DES
 ↓ 強化
3DES
 ↓ 後継
AES
```

---

# 公開鍵暗号方式

## RSA

代表的な**公開鍵暗号方式**。

* 公開鍵と秘密鍵を使用
* 大きな整数の**素因数分解の困難性**を安全性の根拠とする
* 暗号化だけでなくデジタル署名にも利用される
* 共通鍵暗号方式より処理が遅い

```text
RSA
→ 公開鍵暗号
→ 素因数分解
→ 暗号化・デジタル署名
```

---

## ECC（楕円曲線暗号）

**Elliptic Curve Cryptography**

楕円曲線上の数学的問題を利用した公開鍵暗号。

* 公開鍵暗号方式
* RSAより短い鍵長で高い安全性を実現できる
* 小さな鍵で高い安全性を確保しやすい

```text
ECC
→ 公開鍵暗号
→ 楕円曲線
→ 短い鍵でも高い安全性
```

---

# 共通鍵と公開鍵の違い

## 共通鍵暗号

```text
        同じ鍵
          ↓
平文 → 暗号化 → 暗号文
                 ↓
              同じ鍵
                 ↓
                復号
```

### メリット

* 高速
* 大量データの暗号化に向いている

### デメリット

* 相手に安全に鍵を渡す必要がある
* 相手が増えると鍵管理が大変

---

## 公開鍵暗号

```text
公開鍵 → 暗号化
           ↓
        暗号文
           ↓
秘密鍵 → 復号
```

### メリット

* 秘密鍵を相手に渡す必要がない
* 鍵配送問題を解決しやすい

### デメリット

* 共通鍵暗号より処理が遅い

---

# ハイブリッド暗号方式

実際の通信では、**共通鍵暗号と公開鍵暗号を組み合わせる**ことが多い。

例えば、

```text
公開鍵暗号
→ 共通鍵を安全に共有する

共通鍵暗号
→ 実際の大量データを高速に暗号化する
```

それぞれの長所を組み合わせる。

```text
RSAなど → 鍵の受け渡しに強い
AES     → データの暗号化が高速
```

---

# SHAは暗号方式ではない

## SHA

**SHA（Secure Hash Algorithm）**は暗号化ではなく、**ハッシュ関数**。

入力データから固定長のハッシュ値を生成する。

```text
データ
 ↓
SHA
 ↓
ハッシュ値
```

基本的に、

```text
元データ → ハッシュ値   ○
ハッシュ値 → 元データ   ×
```

一方向性を持つ。

代表例：

* SHA-256
* SHA-384
* SHA-512

データの**改ざん検知**やデジタル署名などに利用される。

# 試験用まとめ

| 名称       | 分類     | 特徴              |
| -------- | ------ | --------------- |
| **AES**  | 共通鍵暗号  | 高速・現在の代表格       |
| **DES**  | 共通鍵暗号  | 56bit・古い        |
| **3DES** | 共通鍵暗号  | DESを強化・現在は非推奨   |
| **RSA**  | 公開鍵暗号  | 素因数分解の困難性       |
| **ECC**  | 公開鍵暗号  | 楕円曲線・短い鍵でも高い安全性 |
| **SHA**  | ハッシュ関数 | 一方向・改ざん検知など     |

## 最低限覚える

```text
AES  → 共通鍵・高速
DES  → 共通鍵・古い・56bit
3DES → DESを強化したもの

RSA  → 公開鍵・素因数分解
ECC  → 公開鍵・楕円曲線

SHA  → 暗号ではなくハッシュ
```

## 試験での見分け方

```text
「同じ鍵で暗号化・復号」
→ 共通鍵暗号

「公開鍵・秘密鍵」
→ 公開鍵暗号

「素因数分解」
→ RSA

「楕円曲線」
→ ECC

「56bit」
→ DES

「128 / 192 / 256bit」
→ AES

「一方向」「ハッシュ値」「改ざん検知」
→ SHA
```
