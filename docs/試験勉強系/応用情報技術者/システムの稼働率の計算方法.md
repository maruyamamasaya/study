## 稼働率とは

**システムが正常に稼働している割合**。

例えば稼働率90%なら、

```text
稼働率 = 0.9
故障率 = 0.1
```

となる。

基本的に、

```text
故障率 = 1 - 稼働率
```

で求められる。

---

# 1. 直列システム

AとBの**両方が正常でないとシステムが動かない**構成。

```text
── A ── B ──
```

例えば、

```text
A：稼働率 0.9
B：稼働率 0.8
```

の場合、

```text
システム稼働率
= 0.9 × 0.8
= 0.72

→ 72%
```

## 直列の公式

```text
稼働率 = Aの稼働率 × Bの稼働率
```

3台なら、

```text
A × B × C
```

となる。

> **直列 = 全部動く必要がある → 稼働率を掛ける**

---

# 2. 並列システム

AとBの**どちらか一方でも動いていればシステムが動く**構成。

```text
     ┌─ A ─┐
─────┤     ├─────
     └─ B ─┘
```

例えば、

```text
A：稼働率 0.9
B：稼働率 0.8
```

まず故障率を求める。

```text
Aの故障率
= 1 - 0.9
= 0.1

Bの故障率
= 1 - 0.8
= 0.2
```

システム全体が停止するのは、

**AとBが両方故障した場合**。

```text
0.1 × 0.2
= 0.02
```

これは「システムが停止する確率」なので、

```text
システム稼働率
= 1 - 0.02
= 0.98

→ 98%
```

## 並列の公式

```text
稼働率
= 1 - (Aの故障率 × Bの故障率)
```

つまり、

```text
= 1 - {(1-Aの稼働率) × (1-Bの稼働率)}
```

> **並列 = 1 − 全部故障する確率**

---

# 直列と並列の違い

| 構成 | システムが動く条件 | 計算       |
| -- | --------- | -------- |
| 直列 | 全部動いている   | 稼働率を掛ける  |
| 並列 | どれかが動いている | 1 − 全部故障 |

## 覚え方

```text
直列
→ 全員出勤しないとダメ
→ 全員いる確率を掛ける

並列
→ 誰か1人出勤すればOK
→ 全員休む確率を1から引く
```

---

# 同じ機器を2台使った場合

1台の稼働率が90%とする。

## 直列

```text
── 90% ── 90% ──
```

計算：

```text
0.9 × 0.9
= 0.81

→ 81%
```

## 並列

```text
     ┌─ 90% ─┐
─────┤       ├─────
     └─ 90% ─┘
```

故障率は、

```text
1 - 0.9 = 0.1
```

両方故障する確率は、

```text
0.1 × 0.1
= 0.01
```

したがって、

```text
1 - 0.01
= 0.99

→ 99%
```

### 比較

```text
1台のみ
→ 90%

2台直列
→ 81%

2台並列
→ 99%
```

> **直列にすると稼働率は下がり、冗長化して並列にすると稼働率は上がる。**

---

# 3台並列の場合

全部の機器の稼働率が90%の場合、

```text
A 故障率 = 0.1
B 故障率 = 0.1
C 故障率 = 0.1
```

全部同時に故障する確率は、

```text
0.1 × 0.1 × 0.1
= 0.001
```

したがって、

```text
稼働率
= 1 - 0.001
= 0.999

→ 99.9%
```

# 直列＋並列の複合問題

例えば、

```text
          ┌─ B ─┐
── A ─────┤     ├─────
          └─ C ─┘
```

A：

```text
0.9
```

B、C：

```text
それぞれ0.8
```

まずB・Cの並列部分を計算する。

```text
Bの故障率 = 0.2
Cの故障率 = 0.2

並列部分
= 1 - (0.2 × 0.2)

= 0.96
```

次にAと並列部分は**直列**なので、

```text
0.9 × 0.96
= 0.864

→ 86.4%
```

## 複合問題のコツ

```text
① 並列部分を先に計算

② 1つの機器として考える

③ 最後に直列部分を掛ける
```

---

# 抵抗との違い

図としての**直列・並列という考え方は似ている**が、計算式は異なる。

|     | 直列  | 並列       |
| --- | --- | -------- |
| 稼働率 | 掛け算 | 1 − 全部故障 |
| 抵抗  | 足し算 | 逆数を足す    |

つまり、

> **構成図の「直列・並列」は似ているが、計算方法は別物。**

---

# 試験用まとめ

```text
【直列】

── A ── B ──

AもBも必要

↓

稼働率を掛ける

A × B
```

```text
【並列】

   ┌─ A ─┐
───┤     ├───
   └─ B ─┘

AかBが動けばOK

↓

全部故障する確率を求める

1 - {(1-A) × (1-B)}
```

# 超短縮版

**直列**

```text
全部動く必要がある
→ 稼働率を掛ける
```

**並列**

```text
どれかが動けばOK
→ 1 − 全部故障
```

## 最重要公式

```text
直列
= A × B

並列
= 1 - {(1-A) × (1-B)}

故障率
= 1 - 稼働率
```

**「直列＝掛ける」「並列＝1から全部故障を引く」**と覚える。
