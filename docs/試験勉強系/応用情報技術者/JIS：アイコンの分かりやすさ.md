アイコンや図記号の使いやすさを評価する際には、  
**識別性・判読性・認識性・習得性**などの観点がある。

## 4つの違い

| 項目 | 意味 | 簡単にいうと |
|---|---|---|
| **識別性** | 他のアイコンと区別できるか | 見分けられる？ |
| **判読性** | アイコンの形や表示を正確に読み取れるか | ちゃんと見える？ |
| **認識性** | アイコンが何を意味しているか理解できるか | 意味が分かる？ |
| **習得性** | アイコンの意味や使い方を覚えやすいか | 覚えやすい？ |

## 具体例：ゴミ箱アイコン

「ゴミ箱＝削除」のアイコンを例にすると、

- **判読性**
  - 小さく表示されても「ゴミ箱の形」だと読み取れる

- **識別性**
  - 保存・編集など、他のアイコンと見分けられる

- **認識性**
  - ゴミ箱を見て「削除する機能だ」と理解できる

- **習得性**
  - 一度使えば「ゴミ箱＝削除」と覚えられる

## 覚え方

アイコンを見る流れで考えると分かりやすい。

**判読性 → 識別性 → 認識性 → 習得性**

1. **判読**：形が見える
2. **識別**：他と区別できる
3. **認識**：意味が分かる
4. **習得**：意味・使い方を覚える

## 試験対策

- **識別性** ＝ 区別できるか
- **判読性** ＝ 読み取れるか
- **認識性** ＝ 意味が分かるか
- **習得性** ＝ 覚えやすいか
