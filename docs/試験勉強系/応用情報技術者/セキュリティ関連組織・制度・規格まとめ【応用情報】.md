## まず分類

| 用語 | 分類 | 一言でいうと |
|---|---|---|
| IPA | 組織 | IT・セキュリティ推進 |
| JPCERT/CC | 組織 | インシデント対応・調整 |
| NCO | 政府組織 | 国のサイバー政策 |
| JIPDEC | 組織 | Pマーク・個人情報 |
| JVN | 情報提供サイト | 脆弱性情報 |
| ISMS | 管理の仕組み | 情報セキュリティ管理 |
| JIS | 国内規格 | 日本の規格 |
| ISO | 国際規格 | 世界共通の規格 |
| CRYPTREC | 政府プロジェクト | 暗号技術の評価 |
| CSIRT | チーム | インシデント対応 |
| SOC | チーム・組織 | セキュリティ監視 |

---

# 1. JVN

**Japan Vulnerability Notes**

ソフトウェアなどの**脆弱性情報を公開するポータルサイト**。

- IPAとJPCERT/CCが共同運営
- ソフトウェアの脆弱性情報を公開
- 対策方法や修正版などの情報を提供

### 試験ポイント

> 「脆弱性情報を公開」→ JVN

### 関係

`IPA + JPCERT/CC → JVN`

---

# 2. ISMS

**Information Security Management System**

日本語では、

**情報セキュリティマネジメントシステム**

組織が情報セキュリティを継続的に管理するための仕組み。

### 基本となる考え方

情報セキュリティの3要素（CIA）

- **機密性（Confidentiality）**
- **完全性（Integrity）**
- **可用性（Availability）**

リスクを評価し、

`リスク評価 → 対策 → 運用 → 見直し`

という形で継続的に改善する。

### 関係する規格

**ISO/IEC 27001**

ISMSの要求事項を定めた国際規格。

### 試験ポイント

> 「情報セキュリティを組織的・継続的に管理」→ ISMS

---

# 3. ISO

**International Organization for Standardization**

国際標準化機構。

世界共通の規格を作る組織。

### 代表的な規格

| 規格 | 内容 |
|---|---|
| ISO 9001 | 品質マネジメント |
| ISO 14001 | 環境マネジメント |
| ISO/IEC 27001 | 情報セキュリティ（ISMS） |

### 試験ポイント

> 「国際規格」→ ISO

---

# 4. JIS

**Japanese Industrial Standards**

日本産業規格。

日本国内で利用される国家規格。

### ISOとの違い

ISO
→ **国際規格**

JIS
→ **日本国内の規格**

国際規格を基にJIS化されることも多い。

例：

`ISO/IEC 27001`
↓
`JIS Q 27001`

### 試験ポイント

> 「日本の国家規格」→ JIS

---

# 5. CRYPTREC

**Cryptography Research and Evaluation Committees**

電子政府などで利用する**暗号技術を評価・監視するプロジェクト**。

### 主な役割

- 暗号技術の安全性評価
- 暗号アルゴリズムの監視
- 電子政府推奨暗号の選定

### 関連する暗号

- AES
- RSA
- SHA系

など。

### 試験ポイント

> 「暗号技術の評価」「電子政府推奨暗号」→ CRYPTREC

---

# 6. CSIRT

**Computer Security Incident Response Team**

セキュリティインシデントが発生したときに対応するチーム。

### 主な仕事

- インシデント受付
- 原因調査
- 被害範囲確認
- 封じ込め
- 復旧支援
- 再発防止
- 外部組織との連携

### 例

企業でマルウェア感染発生

↓

`CSIRTが対応`

↓

原因調査・隔離・復旧

### 試験ポイント

> 「インシデント発生後の対応」→ CSIRT

---

# 7. SOC

**Security Operation Center**

組織のシステムやネットワークを**常時監視する組織・チーム**。

### 主な仕事

- ログ監視
- ネットワーク監視
- 不審な通信の検知
- SIEMによる分析
- アラート確認
- サイバー攻撃の早期発見

### SOCとCSIRTの違い

SOC
→ **監視・検知**

CSIRT
→ **インシデント対応**

イメージ：

`SOC`
↓
怪しい通信を発見
↓
`CSIRT`
↓
調査・封じ込め・復旧

### 試験ポイント

> 「常時監視」「ログ分析」「攻撃検知」→ SOC

---

# SIEMとの関係

**SIEM**
= Security Information and Event Management

様々な機器のログを集めて分析する仕組み。

SOCがSIEMを使って監視するイメージ。

`サーバ`
`FW`
`IDS/IPS`
`PC`
   ↓
 `SIEM`
   ↓
ログを集約・分析
   ↓
 `SOC`
   ↓
異常を検知
   ↓
 `CSIRT`
   ↓
インシデント対応

# 特に混同しやすいところ

## SOC / CSIRT / SIEM

SOC
→ **監視する人・組織**

CSIRT
→ **事故対応するチーム**

SIEM
→ **ログを集めて分析する仕組み・製品**

---

## IPA / JPCERT/CC / JVN

IPA
→ **IT・セキュリティ全般を推進**

JPCERT/CC
→ **インシデント対応・調整**

JVN
→ **脆弱性情報を公開**

JVNは、

`IPA + JPCERT/CC`

によって共同運営されている。

---

## ISMS / ISO / JIS

ISMS
→ **情報セキュリティを管理する仕組み**

ISO/IEC 27001
→ **ISMSの国際規格**

JIS Q 27001
→ **日本版の規格**
