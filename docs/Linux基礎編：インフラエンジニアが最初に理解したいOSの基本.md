## Linuxとは

Linuxは、WindowsやmacOSと同じ**OS（オペレーティングシステム）**の一つです。

OSは、コンピュータのハードウェアとアプリケーションの間に入り、

- CPU
    
- メモリ
    
- ディスク
    
- ファイル
    
- ネットワーク
    
- プロセス
    
- ユーザー
    

などを管理する役割を持っています。

普段使うパソコンではWindowsやmacOSを見ることが多いですが、Webサーバーやクラウド環境ではLinuxが非常によく利用されています。

---

## なぜインフラエンジニアにLinuxが必要なのか

インフラエンジニアは、サーバーを構築したり、運用したり、障害対応を行ったりします。

そして、そのサーバーのOSとしてLinuxが使われていることが多いため、Linuxの知識が必要になります。

例えばWebサイトにつながらない場合には、

```text
サーバーに接続
    ↓
Webサーバーは動いているか
    ↓
アプリは動いているか
    ↓
CPUやメモリは正常か
    ↓
ディスク容量は足りているか
    ↓
ログにエラーが出ていないか
```

といった確認をLinux上で行います。

そのためLinuxは、

**サーバーの中で何が起きているのかを確認するための基本技術**

と考えると分かりやすいです。

---

## Linuxはサーバーでよく使われる

例えばAWSでEC2を作ると、

```text
AWS
 ↓
EC2
 ↓
Linux
 ↓
nginx
 ↓
Webアプリ
```

のような構成になることがあります。

つまりクラウドを使っていても、その中ではLinuxが動いていることが多いです。

そのため、

```text
Linux
 ↓
ネットワーク
 ↓
サーバー
 ↓
クラウド
```

という順番で理解すると、AWSなども理解しやすくなります。

# Linuxではコマンドを使う

Linuxサーバーでは、マウス操作よりも**コマンドライン**を使って操作することが多いです。

例えば、

```bash
ls
```

と入力すると、現在いる場所のファイル一覧を確認できます。

```bash
pwd
```

では、今どのディレクトリにいるか確認できます。

```bash
cd /var/log
```

では、別のディレクトリへ移動できます。

つまりLinuxでは、

```text
コマンドを入力
      ↓
OSへ指示
      ↓
結果が表示される
```

という形で操作します。

---

# 1. ファイルとディレクトリ

Linuxでは、ファイルとディレクトリの操作が非常に重要です。

代表的なコマンドには、

```text
ls   → ファイル一覧
cd   → ディレクトリ移動
pwd  → 現在地確認
cp   → コピー
mv   → 移動・名前変更
rm   → 削除
cat  → ファイル内容確認
```

などがあります。

例えば、

```bash
cd /var/log
ls
```

とすれば、ログが保存されているディレクトリへ移動して、中身を確認できます。

---

# 2. Linuxのディレクトリ構成

Linuxでは、ファイルが一定のルールに沿って配置されています。

代表的なものには、

```text
/
├── etc
├── var
├── home
├── tmp
├── usr
└── root
```

などがあります。

### `/etc`

設定ファイルが置かれることが多い場所です。

### `/var`

ログや変化するデータが置かれることが多い場所です。

### `/home`

一般ユーザーのホームディレクトリです。

### `/tmp`

一時ファイルを置くための場所です。

特にインフラエンジニアは、

```text
/etc
/var/log
/home
```

あたりを見ることが多くなります。

---

# 3. ユーザーと権限

Linuxでは、

**誰が何を操作できるのか**

を細かく管理できます。

例えば、

```text
一般ユーザー
→ ファイルを見るだけ

管理者
→ 設定変更可能
```

といった制御です。

Linuxには、特に強い権限を持つ

```text
root
```

という管理者ユーザーがあります。

また、

```bash
sudo
```

を使うことで、一時的に管理者権限でコマンドを実行できます。

---

## ファイル権限

Linuxでは、ファイルに対して、

```text
読み取り
書き込み
実行
```

の権限を設定できます。

代表的なものとして、

```text
r = read
w = write
x = execute
```

があります。

例えば、

```text
rwx
```

なら、

```text
読む
書く
実行する
```

すべて可能という意味です。

権限変更には、

```bash
chmod
```

などを使います。

---

# 4. プロセス

Linux上で実行されているプログラムを**プロセス**と呼びます。

例えば、

```text
Linux
├── nginx
├── Node.js
├── MySQL
├── SSH
└── その他
```

のように、複数のプロセスが同時に動いています。

現在のプロセスを確認するときは、

```bash
ps
```

などを使います。

CPUやメモリの使用状況も含めて見る場合は、

```bash
top
```

を使うことがあります。

---

# 5. サービス

サーバーでは、Webサーバーやデータベースなどを継続的に動かします。

こうしたものは、Linuxでは**サービス**として管理されることがあります。

例えばnginxの状態を確認する場合、

```bash
systemctl status nginx
```

起動する場合、

```bash
sudo systemctl start nginx
```

停止する場合、

```bash
sudo systemctl stop nginx
```

といった操作を行います。

障害調査では、

```text
サービスが止まっていないか
```

を確認することがよくあります。

---

# 6. CPU・メモリ・ディスク

サーバーが正常に動いているか確認するときは、リソースの状態を見る必要があります。

主に確認するのは、

- CPU
    
- メモリ
    
- ディスク
    

です。

例えば、

```bash
top
```

でCPUやメモリ使用率を確認できます。

ディスク容量は、

```bash
df -h
```

で確認できます。

もしディスク使用率が100%になると、

```text
ログを書けない
ファイルを保存できない
アプリが停止する
```

といった問題につながることがあります。

---

# 7. ログ

Linuxを使ううえで非常に重要なのが**ログ**です。

ログには、

- エラー
    
- アクセス情報
    
- サービスの起動・停止
    
- システム情報
    

などが記録されます。

例えばWebサービスで障害が発生した場合、

```text
ユーザー
   ↓
エラー発生
   ↓
LinuxへSSH接続
   ↓
ログ確認
   ↓
原因調査
```

という流れで確認します。

よく使うコマンドには、

```bash
cat
```

```bash
less
```

```bash
tail
```

```bash
grep
```

などがあります。

例えば、

```bash
tail -f app.log
```

とすると、ログをリアルタイムで確認できます。

---

# 8. SSH

サーバーは、自分の目の前にあるとは限りません。

AWSやデータセンターにあるLinuxサーバーへ接続するために使われる代表的な仕組みが、

**SSH**

です。

```text
自分のPC
   ↓
SSH
   ↓
Linuxサーバー
```

SSHを使うことで、遠隔地にあるLinuxサーバーを操作できます。

例えば、

```bash
ssh user@example-server
```

のように接続します。

---

# 9. Linuxとネットワーク

Linuxサーバーは、他のサーバーやユーザーとネットワーク通信を行います。

そのためLinuxを扱う場合、

- IPアドレス
    
- ポート
    
- DNS
    
- HTTP / HTTPS
    
- TCP / UDP
    

などの知識も必要になります。

例えば、

```text
ユーザー
   ↓
HTTPS :443
   ↓
Linux
   ↓
nginx
   ↓
Webアプリ
```

という構成があります。

Linuxとネットワークは別々の知識ではなく、実務ではかなり密接につながっています。

---

# 10. Linuxでネットワークを確認する

Linux上では、ネットワーク状態もコマンドで確認できます。

IPアドレスを確認する場合、

```bash
ip addr
```

通信確認では、

```bash
ping
```

HTTP通信を確認する場合は、

```bash
curl
```

DNSを確認する場合は、

```bash
dig
```

や、

```bash
nslookup
```

などを使用します。

ポートの状態を見る場合は、

```bash
ss -tuln
```

などがあります。

---

# 11. Linuxの種類

Linuxには、いくつか種類があります。

これを**Linuxディストリビューション**と呼びます。

代表的なものには、

- Ubuntu
    
- Debian
    
- Red Hat Enterprise Linux
    
- Rocky Linux
    
- Amazon Linux
    

などがあります。

AWSのEC2ではAmazon LinuxやUbuntuなどを選択することがあります。

細かい違いはありますが、

- ファイル
    
- ユーザー
    
- 権限
    
- プロセス
    
- ネットワーク
    

などの基本的な考え方は共通しています。

# Linuxで障害対応するイメージ

例えばWebサイトにつながらなくなったとします。

Linuxサーバーでは、

```text
Webサイトにつながらない
       ↓
サーバーへSSHできる？
       ↓
CPU・メモリは正常？
       ↓
ディスク容量は正常？
       ↓
nginxは動いている？
       ↓
アプリは動いている？
       ↓
ポートは開いている？
       ↓
ログにエラーはある？
```

というように、順番に確認していきます。

ここで重要なのは、

**コマンドを暗記することではなく、何を確認するためにそのコマンドを使うのか**

を理解することです。

---

# LinuxとDocker

DockerもLinuxと深く関係しています。

例えば、

```text
Linux
 ↓
Docker
 ↓
コンテナ
 ↓
Webアプリ
```

という構成になります。

Dockerコンテナは、Linuxの機能を使ってプロセスやネットワークなどを分離しています。

そのためLinuxの基本が分かると、Dockerも理解しやすくなります。

---

# LinuxとAWS

AWSでもLinuxは非常によく使われます。

例えば、

```text
AWS
 ↓
EC2
 ↓
Amazon Linux
 ↓
Docker
 ↓
Webアプリ
```

という構成があります。

AWSを学ぶときも、

```text
EC2の作り方
```

だけ覚えるのではなく、

```text
EC2の中ではLinuxが動いている
```

ということを理解することが重要です。

# Linuxで最初に覚えたいコマンド

最初は、次のコマンドを使えるようになれば十分です。

|コマンド|用途|
|---|---|
|`pwd`|現在地確認|
|`ls`|ファイル一覧|
|`cd`|ディレクトリ移動|
|`cat`|ファイル内容確認|
|`cp`|コピー|
|`mv`|移動|
|`rm`|削除|
|`grep`|文字検索|
|`ps`|プロセス確認|
|`top`|CPU・メモリ確認|
|`df -h`|ディスク確認|
|`systemctl`|サービス管理|
|`curl`|HTTP通信確認|
|`ssh`|サーバー接続|

すべてのコマンドを暗記する必要はありません。

**何を確認したいのかを理解して、必要なコマンドを使えること**

の方が重要です。

# Linuxの学習順序

Linuxを勉強するなら、

```text
Linuxとは何か
    ↓
ファイル・ディレクトリ
    ↓
ユーザー・権限
    ↓
プロセス
    ↓
サービス
    ↓
CPU・メモリ・ディスク
    ↓
ログ
    ↓
SSH
    ↓
ネットワーク
```

の順番で学ぶと理解しやすくなります。

これまでの内容をつなげると、

```text
Linux
 ↓
サーバーの中を管理する

ネットワーク
 ↓
サーバー同士をつなぐ

Docker
 ↓
アプリの実行環境をまとめる

AWS
 ↓

CI/CD
 ↓
アプリのテスト・デプロイを自動化する
```

という関係になります。

つまりLinuxは、

**インフラ技術全体の土台**

になる知識の一つです。

---

# まとめ

Linuxは、

**サーバーを動かし、管理するためによく使われるOS**

です。

インフラエンジニアはLinuxを使って、

- ファイルを管理する
    
- ユーザーや権限を管理する
    
- プロセスを確認する
    
- サービスを起動・停止する
    
- CPUやメモリを確認する
    
- ディスク容量を確認する
    
- ログから障害原因を調査する
    
- ネットワーク状態を確認する
    

といった作業を行います。

Linuxを勉強するときに最も大切なのは、

**「コマンドを何個知っているか」ではなく、「サーバーの中で何が起きているかを理解できるか」**

という点です。

この基礎が身につくと、ネットワーク、Docker、AWS、CI/CD、監視などのインフラ技術も理解しやすくなります。
