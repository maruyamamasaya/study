## 1. 全体像

Webサイトへアクセスするときは、大きく次の3つが関係する。

- **DNS**：ドメイン名からIPアドレスを調べる
- **IPアドレス**：接続先のサーバーを特定する
- **ポート番号**：サーバー上のどのサービスに接続するかを特定する

イメージすると、

```text
IPアドレス = 建物の住所
ポート番号 = 建物の入口・窓口
DNS        = 建物の名前から住所を調べる仕組み
```

---

# 2. Webサイトへアクセスする流れ

例えば、以下のWebサーバーがあるとする。

```text
ドメイン名：sample.com
IPアドレス：123.456.123.456
```

ユーザーがChromeなどのブラウザから、

```text
https://sample.com
```

へアクセスする。

流れは次のようになる。

```text
ユーザー（Chrome）
        ↓
https://sample.com
        ↓
DNSでIPアドレスを調べる
        ↓
sample.com
    ↓
123.456.123.456
        ↓
Webサーバーへアクセス
```

---

# 3. DNSとは

DNS（Domain Name System）は、

> **ドメイン名からIPアドレスを調べる仕組み**

である。

例えば、

```text
sample.com
    ↓ DNS
123.456.123.456
```

のように名前解決を行う。

人間にとって、

```text
https://sample.com
```

の方が、

```text
https://123.456.123.456
```

より覚えやすいため、ドメイン名が利用されている。

DNSは1台のサーバーですべてを管理しているわけではなく、世界中に多数のDNSサーバーが存在し、階層的・分散的に名前解決を行っている。

---

# 4. ポート番号とは

IPアドレスだけでは、

> 「そのサーバーのどのサービスを利用したいのか」

までは判断できない。

1台のサーバーで複数のサービスを動かすことができるため、**ポート番号**を使って接続先のサービスを区別する。

例えば、

```text
Webサーバー
123.456.123.456
      │
      ├── 22番  → SSH
      │
      ├── 80番  → HTTP
      │
      └── 443番 → HTTPS
```

となる。

つまり、

```text
IPアドレス
↓
どのサーバー？

ポート番号
↓
そのサーバーのどのサービス？
```

という関係になる。

---

# 5. Webで使われる代表的なポート番号

| ポート番号 | プロトコル | 主な用途 |
|---:|---|---|
| 80 | HTTP | 暗号化されていないWeb通信 |
| 443 | HTTPS | 暗号化されたWeb通信 |
| 22 | SSH | サーバーのリモート管理 |

---

# 6. HTTPの場合

ブラウザで、

```text
http://sample.com
```

へアクセスした場合、ポート番号を指定していなくても、HTTPの標準ポートである**80番**が使用される。

つまり、

```text
http://sample.com
        ↓
DNS
        ↓
123.456.123.456
        ↓
123.456.123.456:80
```

というイメージになる。

明示的に書けば、

```text
http://sample.com:80
```

となる。

通常はブラウザが自動的に判断するため、`:80`を書く必要はない。

---

# 7. HTTPSの場合

HTTPSの場合は、標準で**443番ポート**が使用される。

```text
https://sample.com
        ↓
DNS
        ↓
123.456.123.456
        ↓
123.456.123.456:443
```

明示的に書けば、

```text
https://sample.com:443
```

となる。

HTTPSではTLSによって通信が暗号化される。

そのため、現在のWebサイトでは基本的にHTTPSが利用されている。

---

# 8. HTTPからHTTPSへのリダイレクト

Webサイトでは、

```text
http://sample.com
```

へアクセスされた場合でも、

```text
https://sample.com
```

へ自動的に移動させる構成がよく使われる。

例えば、

```text
ユーザー
   ↓
http://sample.com
   ↓
80番ポート
   ↓
Webサーバー
   ↓
HTTPSへリダイレクト
   ↓
https://sample.com
   ↓
443番ポート
   ↓
Webページを表示
```

となる。

この場合、

```text
80番
→ HTTPを受け付けてHTTPSへリダイレクト

443番
→ 実際のWebサイトを提供
```

という役割になる。

そのため、WebサーバーでHTTP→HTTPSのリダイレクトを行う場合は、**80番ポートも通信を受け付けられる必要がある。**

---

# 9. サーバー管理者が利用する22番ポート

Linuxサーバーなどを管理するときには、SSHがよく利用される。

SSHの標準ポートは、

```text
22番
```

である。

例えば、

```text
サーバー管理者
      ↓
SSH
      ↓
123.456.123.456:22
      ↓
サーバー
```

という形で接続する。

ただし、SSHを一般ユーザーに公開する必要はない。

例えばFirewallなどで、

```text
443番
→ インターネットから接続可能

22番
→ 管理者のIPアドレスや社内ネットワークからのみ接続可能
```

といった制限を行うことができる。

---

# 10. IPアドレスを直接入力した場合

例えば、

```text
http://123.456.123.456
```

と入力した場合でも、技術的にはWebサーバーへアクセスできる場合がある。

```text
http://123.456.123.456
        ↓
123.456.123.456:80
```

ただし、

- Webサーバーがドメイン名によってサイトを振り分けている
- HTTPS証明書がドメイン名に対して発行されている
- IPアドレスからのアクセスを許可していない

などの理由で、正常にWebサイトが表示されない場合もある。

そのため、

> 「IPアドレスならWebサイトを見られない」

というわけではない。

サーバー側の設定によって異なる。

---

# 11. メールでもポート番号を使用する

ポート番号はWebだけでなく、メールなどでも利用される。

例えば、

```text
aaa@findix.co.jp
```

というメールアドレスを使用している場合、

```text
メールアプリ
     ↓
メールサーバー
```

の間で通信が行われる。

メールの場合、

- メールを送信する
- メールを受信する

で使用するプロトコルが異なる。

---

# 12. メールで使われる代表的なポート

| ポート番号 | プロトコル | 用途 |
|---:|---|---|
| 587 | SMTP Submission | メール送信 |
| 993 | IMAPS | メール受信 |
| 995 | POP3S | メール受信 |

## メール送信

メールを送信するときはSMTPが利用される。

例えば、

```text
メールアプリ
     ↓
SMTP
587番
     ↓
メールサーバー
     ↓
相手へメールを送信
```

---

## メール受信

メールを受信するときには、IMAPやPOP3などが利用される。

### IMAPS

```text
メールサーバー
     ↓
IMAPS
993番
     ↓
メールアプリ
```

### POP3S

```text
メールサーバー
     ↓
POP3S
995番
     ↓
メールアプリ
```

現在では、複数端末でメールを同期しやすい**IMAP系がよく利用される**。

なお、GmailなどのWebメールや専用アプリでは、必ずしもこれらのポートを直接利用するとは限らず、HTTPSや専用APIなどが使われる場合もある。

---

# 13. Webとメールを合わせた全体像

```text
【Web】

ユーザー
  │
  │ https://sample.com
  ↓
DNS
  │
  │ sample.com
  │      ↓
  │ 123.456.123.456
  ↓
Webサーバー
123.456.123.456
  │
  ├── 22番  → SSH
  ├── 80番  → HTTP
  └── 443番 → HTTPS


【メール】

メールアプリ
  │
  ├── 587番 → SMTP（送信）
  │
  ├── 993番 → IMAPS（受信）
  │
  └── 995番 → POP3S（受信）
  ↓
メールサーバー
```

# 14. 重要ポイント

## DNS

```text
sample.com
    ↓
123.456.123.456
```

**ドメイン名からIPアドレスを調べる。**

---

## IPアドレス

```text
123.456.123.456
```

**どのサーバーに接続するのかを特定する。**

---

## ポート番号

```text
22  → SSH
80  → HTTP
443 → HTTPS
587 → SMTP Submission
993 → IMAPS
995 → POP3S
```

**サーバー上のどのサービスに接続するのかを特定する。**

---

# 15. 覚え方

```text
DNS
「サーバーの住所を調べる」

        ↓

IPアドレス
「どのサーバー？」

        ↓

ポート番号
「そのサーバーのどのサービス？」

        ↓

HTTP / HTTPS / SSH / SMTP / IMAP / POP3 など
```

つまり、

> **DNSでドメイン名からIPアドレスを調べ、IPアドレスで接続先のサーバーを特定し、ポート番号でそのサーバー上のサービスを特定する。**

という流れを理解しておけばよい。
