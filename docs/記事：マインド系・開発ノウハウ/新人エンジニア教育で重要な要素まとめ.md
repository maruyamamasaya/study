# Sランク（最重要）
「これが身につけば成長速度が大きく変わる」

---

## 1. 自ら質問・調査・提案する力（プロアクティブ）

最も多くの企業が重要視している項目。

受け身ではなく、

- 分からないことを整理する
- 自分で調査する
- 仮説を持つ
- 質問する
- 改善提案する

までを一連の流れとして行える人は成長が非常に速い。

### 例

❌
「分かりません」

↓

⭕
「ここまで調べましたが、
AとBの違いが分からないので教えてください。」

---

## 2. フィードバックをもらう力

仕事は
レビューを受ける回数
＝成長速度

と言われる。

重要なのは

- レビューを待たない
- 自分から見てもらう
- 小さい単位で提出する

ことである。

## 3. 人を頼る力（ネットワーク活用）

- 他部署にも相談する

など

「誰に聞けば早いか」

を覚えることが重要。

# 共通していた育成の考え方

複数企業の技術ブログで共通していたことは

「技術を教える」

よりも

「自走できる人を育てる」

ことを目的としている。

そのため

- 自分で調べる
- 自分で質問する
- 自分で改善する
- 小さくアウトプットする
- フィードバックをもらう

このサイクルを早く回せる人ほど
成長が速いという結論になっている。
