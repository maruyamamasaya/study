## 西川計測ってどんな会社？

[西川計測株式会社](https://www.nskw.co.jp/?utm_source=chatgpt.com)は1951年設立、従業員403名、2025年6月期の売上高は約387億円の会社です。事業は「制御・計測・理化学」を中心に、機器販売だけではなく、**システム設計→構築→導入→保守まで行う技術商社・SIer**です。

特に重要なのがここです。

> 国内外1,000社以上のメーカーからハードウェアを調達し、**自社でソフトウェアを開発してシステムを構築する**

という会社です。横河電機などの製品を扱いつつ、自分たちでもシステムを作っています。

なので、

**「横河電機製品を売っている専門商社」だけではない**

という理解が大事です。

社員構成もエンジニアが約80%で、ソフトエンジニア約11%、システムエンジニア約20%、セールスエンジニア約33%となっています。かなり技術寄りです。

# 「複数プロジェクト並行」が結構ポイント

ここは確認した方がいいです。

例えば、

```
WeLS
 ├─ A製薬向け改修
 ├─ B化学メーカー向け改修
 └─ C研究所向け改修

NEXS
 ├─ Dメーカー向け
 └─ E研究所向け
```

みたいになっていて、

```
月：A社 要件確認
火：B社 設計
水：A社 実装
木：C社 テスト
金：B社 顧客レビュー
```

という働き方になる可能性があります。

西川計測自身も、制御・情報システムについて「基本設計→詳細設計→システム構築→施工管理→スタートアップ」まで一貫対応すると説明しています。

したがって、**開発工程だけ切り出したSESとは少し性質が違う**可能性があります。

## ただし、参画前に絶対確認したいところ

今回の案件説明だけだと、ここがまだ曖昧です。

|確認項目|なぜ重要？|
|---|---|
|使用言語・FW|Java/.NET/React/Vue等でキャリアが全然違う|
|WeLS/NEXS/AFASのどれ担当か|業務内容が変わる|
|新規開発 or 保守改修|開発経験の濃さが変わる|
|要件定義の担当範囲|本当に顧客と話すのか|
|実装割合|上流だけなのかコードも書くのか|
|プロパー/BPの役割分担|BPがどこまで任されるのか|
|1人何案件並行か|2案件と5案件では全然違う|
|チーム人数|一人常駐に近いのかチーム参画なのか|
|顧客との直接MTG有無|上流経験としてかなり重要|
|ソース管理・CI/CD・テスト|開発環境のモダンさを見る|
|出社/リモート|実際の働き方|
|長期的な役割|開発→PL/PMまで行けるのか|

特に営業には、**「Web開発案件です」だけではなく、「実装・設計・要件定義がそれぞれ何割くらいなのか」「どの技術を使うのか」「西川計測プロパーとBPの役割分担」**を確認してもらいたいです。

現時点では、僕ならこの案件を **「西川計測の研究・品質管理系パッケージを顧客ごとにカスタマイズする、上流寄りWebシステム開発」** と見ます。

技術スタックと担当工程がちゃんとWeb開発寄りなら、かなり良い経験になりそうです。逆に「要望整理・Excel仕様書・テストが8割、実装ほぼなし」もあり得るので、そこを面談で見極めるのが一番重要です。
