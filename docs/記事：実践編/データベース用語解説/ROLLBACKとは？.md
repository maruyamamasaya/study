## トランザクションで行った変更を「元に戻す」命令

---

# 概要

**ROLLBACK（ロールバック）**とは、

**トランザクション内で行ったデータの変更を取り消し、開始前の状態に戻す命令**です。

簡単に言うと、

> **「エラーが起きたので、今回の変更はなかったことにしてください！」**

とデータベースに伝える命令です。

---

# なぜ必要なの？

データベースでは、複数の更新処理を行う途中でエラーが発生することがあります。

例えば銀行の送金。

```
BEGIN

↓

Aさん -1000円

↓

Bさん +1000円

↓

エラー発生
```

もしこのまま終了すると、

```
Aさんだけ残高が減った

Bさんは増えていない
```

という壊れたデータになってしまいます。

そこで

```sql
ROLLBACK;
```

を実行すると、

```
Aさんの残高

↓

元に戻る

Bさんの残高

↓

元のまま
```

となり、**何も変更されなかった状態**に戻ります。

---

# 基本的な仕組み

トランザクションの流れ

```
BEGIN

↓

UPDATE

↓

UPDATE

↓

エラー発生

↓

ROLLBACK
```

ROLLBACKが実行されると、

```
BEGINより前の状態
```

まで戻ります。

つまり、

**途中まで成功していた処理もすべて取り消されます。**

# 具体例

銀行送金の例です。

```sql
BEGIN;

UPDATE account
SET balance = balance - 1000
WHERE id = 1;

UPDATE account
SET balance = balance + 1000
WHERE id = 2;

ROLLBACK;
```

結果

```
Aさんの残高

変更前

↓

変更後

↓

ROLLBACK

↓

変更前へ戻る
```

Bさんも同様に元へ戻ります。

---

# 実務ではどんな時に使う？

例えばECサイト。

```
注文登録

↓

在庫更新

↓

決済

↓

ポイント付与
```

ここで

```
決済に失敗
```

した場合、

注文だけ残ってしまうと困ります。

そのため

```
ROLLBACK
```

を実行して

```
注文登録

↓

削除

在庫

↓

元に戻す
```

という状態にします。

↓

# COMMITとの違い

| COMMIT | ROLLBACK |
|---------|----------|
| 変更を確定する | 変更を取り消す |
| 成功時に実行 | エラー時に実行 |
| データが保存される | データが元に戻る |

---

# よくあるイメージ

Wordで資料を作っているとします。

```
文章を書く
```

途中で

```
やっぱり全部やり直したい…
```

となったら

```
保存せず閉じる
```

を選びます。

この

**「保存せず閉じる」**

に近い役割がROLLBACKです。

一方、

```
保存する
```

がCOMMITになります。

---

# COMMITとROLLBACKの流れ

```
BEGIN

↓

データ更新

↓

成功？

├── Yes → COMMIT（保存）
│
└── No → ROLLBACK（元に戻す）
```

この流れが、トランザクションの基本です。

---

# まとめ

- ROLLBACKは**変更内容を取り消して元に戻す命令**
- エラーが発生したときに実行する
- BEGIN時点の状態まで戻る
- 途中まで成功した更新もすべて取り消される
- データの整合性を保つために欠かせない機能

> **一言で覚えるなら**
>
> **「ROLLBACK = 今回の変更をなかったことにする命令」**
