## 同じデータをグループごとにまとめて集計するSQL

---

# 概要

**GROUP BY（グループ バイ）**とは、

**同じ値を持つデータをグループ化し、件数や合計などを集計するためのSQL**です。

簡単に言うと、

> **「同じ種類ごとにまとめる」**

ための機能です。

例えば、

- 商品ごとの売上
- 部署ごとの社員数
- 都道府県ごとの会員数

などを集計するときによく使われます。

---

# なぜ必要なの？

例えば注文データがあるとします。

| 注文ID | 商品名 |
|--------|--------|
| 1 | パソコン |
| 2 | マウス |
| 3 | パソコン |
| 4 | キーボード |
| 5 | パソコン |

このままだと

```
パソコンは何個売れた？

マウスは？

キーボードは？
```

が分かりません。

そこでGROUP BYを使います。

---

# 基本的な仕組み

GROUP BYは

```
同じ値

↓

まとめる

↓

集計する
```

という流れになります。

例えば

```
パソコン

パソコン

パソコン

マウス

マウス
```

↓

GROUP BY

↓

```
パソコン　3件

マウス　2件
```

このようにグループ化できます。

---

# イメージ図

```
注文データ

パソコン
パソコン
マウス
パソコン
キーボード
マウス

        │
        │ GROUP BY
        ▼

パソコン     3件

マウス       2件

キーボード   1件
```

---

# SQLではどう書く？

商品ごとの注文数を数える例です。

```sql
SELECT
    product_name,
    COUNT(*)
FROM orders
GROUP BY product_name;
```

---

結果

| 商品 | 件数 |
|------|------|
| パソコン | 3 |
| マウス | 2 |
| キーボード | 1 |

---

# COUNTと組み合わせる

GROUP BYは

```
COUNT
```

と一緒に使うことが非常に多いです。

```sql
SELECT
    department,
    COUNT(*)
FROM employee
GROUP BY department;
```

結果

| 部署 | 人数 |
|------|------:|
| 営業 | 18 |
| 開発 | 25 |
| 総務 | 5 |

---

# SUMとも組み合わせる

商品ごとの売上合計。

```sql
SELECT
    product_name,
    SUM(price)
FROM orders
GROUP BY product_name;
```

結果

| 商品 | 売上 |
|------|------:|
| パソコン | 300,000円 |
| マウス | 20,000円 |

---

# AVGとも組み合わせる

部署ごとの平均給与。

```sql
SELECT
    department,
    AVG(salary)
FROM employee
GROUP BY department;
```

結果

| 部署 | 平均給与 |
|------|---------:|
| 開発 | 520万円 |
| 営業 | 480万円 |

---

# GROUP BYでよく使う集計関数

| 関数 | 意味 |
|------|------|
| COUNT() | 件数を数える |
| SUM() | 合計を求める |
| AVG() | 平均を求める |
| MAX() | 最大値を求める |
| MIN() | 最小値を求める |

これらはGROUP BYとセットで覚えることが多いです。

---

# 実務ではどこで使われる？

GROUP BYは、**データを分析・集計する場面**でよく使われます。

例えば、

### ECサイト

```
商品ごとの売上

カテゴリーごとの注文数
```

---

### 会員管理

```
年代別会員数

都道府県別ユーザー数
```

---

### 社内システム

```
部署ごとの社員数

プロジェクトごとの工数
```

---

### アクセス解析

```
日別アクセス数

ページごとのPV

国ごとのユーザー数
```

ダッシュボードやレポート画面では、ほぼ必ずと言っていいほど使われます。

---

# HAVINGとの違い

GROUP BYは

**「グループを作る」**

ための機能です。

例えば

```
商品ごとにまとめる
```

だけならGROUP BYで十分です。

一方、

```
10件以上売れた商品だけ表示したい
```

という条件を付ける場合は、

**HAVING**

を使います。

つまり、

```
GROUP BY

↓

HAVING
```

という流れになります。

---

# まとめ

- GROUP BYは**同じ値を持つデータをグループ化するSQL**
- 商品ごと・部署ごと・都道府県ごとなどにまとめられる
- COUNT・SUM・AVGなどの集計関数と一緒によく使う
- 売上分析やダッシュボード、管理画面で頻繁に使われる
- 集計した結果をさらに絞り込む場合はHAVINGを使う

> **一言で覚えるなら**
>
> **「GROUP BY = 同じデータを種類ごとにまとめて集計する機能」**
