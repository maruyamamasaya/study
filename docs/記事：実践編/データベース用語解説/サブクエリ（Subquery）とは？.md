# サブクエリ（Subquery）とは？
## SQLの中にSQLを書く仕組み

---

# 概要

**サブクエリ（Subquery）**とは、

**SQL文の中に、別のSQL文を書くこと**です。

簡単に言うと、

> **「あるSQLの実行結果を、別のSQLで利用する仕組み」**

です。

サブクエリを使うことで、

「まず○○を調べて、その結果を使って△△を取得する」

というような、少し複雑な検索ができるようになります。

---

# なぜ必要なの？

例えば社員テーブルがあるとします。

| 社員 | 給与 |
|------|------:|
| 山田 | 300万円 |
| 田中 | 450万円 |
| 鈴木 | 600万円 |
| 佐藤 | 700万円 |

ここで、

> **平均給与より高い社員だけ表示したい**

とします。

しかし、平均給与は分かりません。

まず

```
平均給与を求める
```

↓

その結果を使って

```
平均以上の社員を表示する
```

という2段階の処理が必要です。

このような場合にサブクエリを使います。

---

# 基本的な仕組み

サブクエリは

```
SQL①

↓

結果を取得

↓

SQL②で利用
```

という流れになります。

イメージ

```
SELECT *

FROM 社員

WHERE 給与 >

（平均給与を求めるSQL）
```

つまり、

**「先に内側のSQLが実行され、その結果を外側のSQLが利用する」**

という仕組みです。

---

# 一番シンプルな例

平均給与を取得するSQLです。

```sql
SELECT AVG(salary)
FROM employee;
```

結果

```
512万円
```

これを使って

```sql
SELECT *
FROM employee
WHERE salary > 5120000;
```

と書くこともできます。

しかし、

平均給与は毎日変わるかもしれません。

そこでサブクエリを使います。

```sql
SELECT *
FROM employee
WHERE salary >
(
    SELECT AVG(salary)
    FROM employee
);
```

これなら、

毎回最新の平均給与を取得して検索できます。

---

# イメージ図

```
外側のSQL

社員を取得

       ↑

平均給与はいくら？

       ↑

内側のSQL
```

実際の流れ

```
① 平均給与を計算

↓

512万円

↓

② 給与が512万円以上の社員を取得
```

---

# 他にもこんな使い方ができる

## 一番高い給与の社員

```sql
SELECT *
FROM employee
WHERE salary =
(
    SELECT MAX(salary)
    FROM employee
);
```

---

## 一番高い商品の取得

```sql
SELECT *
FROM products
WHERE price =
(
    SELECT MAX(price)
    FROM products
);
```

---

## 注文が1件以上ある会員

```sql
SELECT *
FROM users
WHERE id IN
(
    SELECT user_id
    FROM orders
);
```

このように、

「別のテーブルの検索結果」を条件にすることもできます。

---

# サブクエリはどこに書ける？

サブクエリはさまざまな場所に書けます。

### WHERE句

```sql
WHERE salary >
(
    SELECT AVG(salary)
    FROM employee
)
```

一番よく使われます。

---

### FROM句

```sql
FROM
(
    SELECT ...
)
```

一時的なテーブルとして使えます。

---

### SELECT句

```sql
SELECT
    name,
    (
        SELECT COUNT(*)
        FROM orders
    )
```

取得する値を計算できます。

---

# 実務ではどこで使われる？

サブクエリは、

**「他のデータを基準に検索したい」とき**によく使われます。

例えば、

### ECサイト

- 一番売れている商品
- 平均価格より高い商品
- 購入履歴がある会員

---

### 社員管理

- 平均給与以上の社員
- 最も勤続年数が長い社員

---

### 在庫管理

- 在庫が最も少ない商品
- 発注が必要な商品

---

### ダッシュボード

- 前月平均以上の売上
- 全体平均との比較

---

# JOINとの違い

初心者がよく迷うのが

**JOINとの違い**です。

| サブクエリ | JOIN |
|------------|------|
| SQLの結果を利用する | テーブル同士を結合する |
| 「平均以上」「最大値」などの条件検索が得意 | 関連するデータをまとめて取得するのが得意 |

例えば、

```
平均給与より高い社員
```

はサブクエリが自然です。

一方、

```
社員と部署名を一緒に表示
```

ならJOINを使います。

---

# まとめ

- サブクエリは**SQLの中にSQLを書く仕組み**
- 内側のSQLが先に実行され、その結果を外側のSQLが利用する
- 「平均以上」「最大値」「最小値」などの検索によく使われる
- WHERE句・FROM句・SELECT句など、さまざまな場所で利用できる
- JOINとは役割が異なり、「検索条件を動的に作る」場面で特に活躍する

> **一言で覚えるなら**
>
> **「サブクエリ = SQLの結果を別のSQLで利用する仕組み」**
